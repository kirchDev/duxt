---
title: Dependency security
description: Review dependency advisories without hiding affected paths.
icon: lucide:shield-check
---

`pnpm check:security` runs the registry audit and prints every advisory. `security-advisories.json` records each affected version and dependency path, the reachable operation, the blocked parent update and a review deadline.

A review covers only those paths and versions. New findings, higher severity, new paths and expired reviews fail CI. An audit that cannot reach the registry fails too. Fix compatible dependencies first; an upstream constraint needs an explicit assessment rather than an untested override. The three-day release cooldown remains in force.

Direct Actions and reusable workflows use immutable commit SHAs with version comments. Dependabot maintains the pairs. `action-pins.test.ts` prevents floating references from returning. Central workflow bodies belong to the workflows repository; a pinned caller does not make their floating transitive Actions immutable.
