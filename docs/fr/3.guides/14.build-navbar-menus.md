Une entrée de `navigation` ou de `sections` devient un menu dès qu’elle a des
`children`. Le reste est de la configuration sur les mêmes objets de lien : la
profondeur du menu, liste ou panneau, et le rendu de chaque entrée. La
[démo](/demo) en montre un de chaque dans sa rangée de sections.

## Étapes

::steps

1. **Imbriquez les liens.** Une entrée avec `children` ouvre un menu déroulant,
   et un enfant avec `children` ouvre un autre menu à côté, aussi profond que les
   données :

   ```ts [app/app.config.ts]
   export default defineAppConfig({
     duxt: {
       navigation: [
         {
           label: 'Platform',
           icon: 'lucide:layers',
           children: [
             { label: 'Overview', to: '/platform' },
             {
               label: 'API',
               children: [
                 { label: 'REST', to: '/api/rest' },
                 { label: 'Webhooks', to: '/api/webhooks' }
               ]
             }
           ]
         }
       ]
     }
   });
   ```

2. **Faites-en un panneau.** `menu: 'mega'` dispose les enfants sur une grille
   de `columns`. Un enfant qui a ses propres enfants est une colonne sous son nom ;
   un enfant sans enfants est une cellule à part :

   ```ts
   {
     label: 'Platform',
     menu: 'mega',
     columns: 3,
     divided: true,
     children: [
       {
         label: 'Highlights',
         hideLabel: true,
         children: [
           {
             label: 'Editor',
             to: '/editor',
             image: '/editor.svg',
             display: 'feature',
             description: 'Write and preview'
           }
         ]
       },
       {
         label: 'API',
         children: [
           { label: 'REST', to: '/api/rest' },
           { label: 'Webhooks', to: '/api/webhooks', badge: 'New' },
           { label: 'All of the API', to: '/api', display: 'more' }
         ]
       },
       { label: 'New here?', to: '/start', display: 'callout' }
     ]
   }
   ```

3. **Choisissez la disposition.** Les mêmes options donnent des panneaux très
   différents :

   | Vous voulez | Définissez |
   | :-- | :-- |
   | Des colonnes de liens à côté d’une liste mise en avant | Une première colonne avec `hideLabel` et des entrées `display: 'feature'`, et `divided` sur la deuxième |
   | Une grille de produits | `columns: 3`, des entrées avec `icon`, `description` et `display: 'feature'`, et un `display: 'callout'` final |
   | Un large panneau avec introduction | `width: 'full'`, `columns: 6`, `divided` et une première colonne avec `span: 2`, `image` et `description` |
   | Une image au-dessus de chaque colonne | `width: 'full'` et `image` sur chaque colonne |

4. **Ajoutez votre propre cellule si les formes ne suffisent pas.** `component`
   nomme un composant enregistré globalement, qui remplace le contenu de l’entrée,
   occupe sa cellule et reçoit l’entrée en tant que `link`. Nommez le fichier
   `.global.vue`, car `app.config` ne peut le désigner que par son nom. Un
   composant opaque masque la mise en évidence que le menu peint derrière une
   entrée : dessinez donc la vôtre :

   ```vue [app/components/MenuPromo.global.vue]
   <script setup lang="ts">
   defineProps<{ link: DuxtLink }>();
   </script>

   <template>
     <span
       class="flex h-full p-3 in-data-highlighted:ring-2"
     >
       {{ link.label }}
     </span>
   </template>
   ```

5. **Utilisez la seconde rangée de la même façon.** `sections` a la même forme.
   Une section avec un menu appartient à la zone de son premier lien, et lorsque
   deux entrées revendiquent une page, la première reste active : les entrées
   simples passent donc avant les menus qui répètent leurs liens.

6. **Vérifiez sur un téléphone.** Sous le point de rupture `lg`, le panneau
   latéral affiche le premier niveau, et chaque menu glisse comme un niveau à part
   sous un bouton de retour. Les colonnes d’un méga-menu restent sur un niveau,
   sous leur nom.

::

## Pourquoi cela fonctionne ainsi

Un méga-menu est centré sur la page et non sur son entrée. Un panneau aussi
large n’a pas de position sensée par rapport à une entrée de la rangée :
accroché à elle, le même menu se plaçait ailleurs pour chaque entrée et chaque
largeur de fenêtre.

Le panneau latéral change de niveau au lieu d’indenter, car chaque niveau
imbriqué prend de la largeur au précédent et un téléphone n’en a pas à revendre.
Un seul niveau à la fois garde aussi chaque lien en pleine largeur, quelle que
soit la profondeur.

Toutes les options figurent dans la [référence de
configuration](/reference/configuration), et les composants sont
[DuxtNavigationMenu](/reference/components/navigation/duxt-navigation-menu) et
[DuxtSheetDrill](/reference/components/navigation/duxt-sheet-drill).

## Liste de contrôle

- [ ] Chaque entrée qui ouvre un menu a des `children`, et un `to` seulement si sa propre page doit mener ce menu
- [ ] Les `columns` d’un méga-menu correspondent aux valeurs `span` des cellules
- [ ] Les entrées simples de `sections` précèdent les menus qui répètent leurs liens
- [ ] Le menu a été ouvert en largeur téléphone jusqu’à son niveau le plus profond
