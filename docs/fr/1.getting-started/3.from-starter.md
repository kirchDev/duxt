---
title: Démarrer avec le starter
description: Créez avec Nuxi un site de documentation duxt prêt à démarrer.
icon: lucide:rocket
---

Le [starter duxt](https://github.com/kirchDev/duxt-starter) est un petit site
de documentation avec une page d’accueil et une section de démarrage. Nuxi le
copie, installe ses dépendances et crée son dépôt Git :

```bash
npx nuxi@latest init -t github:kirchDev/duxt-starter
cd <répertoire-du-projet>
pnpm dev
```

Ouvrez l’adresse affichée par Nuxt, puis modifiez les fichiers dans `docs/`.
La navigation et l’aperçu de la page d’accueil se mettent à jour avec vos
pages. Pour un projet existant, utilisez plutôt [Installation](/getting-started/installation).
