---
title: Référence de l’API
description: Un document OpenAPI, publié en pages de référence avec un client qui envoie de vraies requêtes.
icon: lucide:plug
---

Pointez une source vers un document OpenAPI et duxt en construit une référence —
une vue d’ensemble, une page par étiquette, une page par opération — avec sur
chaque page d’opération un client qui envoie la requête depuis le navigateur du
lecteur lui-même.

Les pages sont une collection ordinaire, et c’est tout l’intérêt : la recherche
les trouve, `llms.txt` les liste, le sitemap les porte, le sélecteur de versions
circule entre elles. Rien ici n’est un second chemin de rendu.
