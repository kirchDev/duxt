## Deux axes, pas un

Une traduction n’est pas une version, et les comparer comme si elles l’étaient
dessine une grille de colonnes identiques. Le panneau fixe donc un axe à la fois :

- **Les versions d’une langue** — `v2` contre `v1.9`, toutes deux en anglais.
- **Les langues d’une version** — `en` contre `de`, toutes deux en `v2`.

Un site à deux versions en deux langues obtient donc quatre grilles, chacune avec
une question. Un dépôt publié une fois, en une langue, n’en obtient aucune : une
seule colonne ne compare rien.

Les dépôts ne sont jamais mélangés. `/sdk/guides` et `/cli/guides` sont deux
projets qui partagent par hasard un nom de dossier, et les mettre dans une grille
inventerait un écart qui n’en est pas un.

## La lire

`✓` veut dire que la collection a cette page ; `·` qu’elle ne l’a pas. Le `*` à
côté d’un en-tête marque la colonne servie sans segment propre — la version par
défaut, ou la langue qui vit dans le dossier source lui-même.

Un `·` dans une colonne de langue est une page qui attend sa traduction. Un `·`
dans la colonne d’une version plus ancienne est le plus souvent correct : le guide
n’existait pas encore.
