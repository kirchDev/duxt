title: <page>.md
description: La source de n’importe quelle page, à son URL suivie de .md.
icon: lucide:file-code
---

Ajoutez `.md` à n’importe quelle URL de documentation et la réponse est le
Markdown à partir duquel cette page a été rendue.

```
/duxt/getting-started      → la page
/duxt/getting-started.md   → sa source
```

## Remarques

C’est un **middleware, pas une route**, car `.md` est un suffixe du dernier
segment plutôt qu’un segment à part — un fichier de route ne peut pas le
capturer.

C’est ce que [`DuxtCopyPage`](/reference/components/page/duxt-copy-page) remet à
un modèle : la source, pas la page rendue.
