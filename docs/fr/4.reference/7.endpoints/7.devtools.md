::callout{type="danger" title="Jamais enregistré dans un build"}
Le panneau expose la configuration résolue, les chemins de fichiers qui sont
derrière et un bouton qui supprime un répertoire de cache. Rien de tout cela ne
regarde qui que ce soit en production, et c’est pourquoi le module retourne avant
d’enregistrer quoi que ce soit hors d’un serveur de développement.
::

## Réponse

`text/html`, un document par panneau : `/_duxt/devtools` est le panneau Sources et
chacun des autres s’y accroche — `/_duxt/devtools/paths`, `/_duxt/devtools/pages`
et ainsi de suite, dans l’ordre de la rangée d’onglets.

Ce sont les mêmes documents que Nuxt Devtools encadre dans son onglet **duxt** : la
route existe donc pour être ouverte dans une fenêtre à part — un tableau large se
lit mieux hors d’un tiroir.

## Notes

Ce à quoi chaque panneau répond, avec chaque panneau montré tel qu’il apparaît,
forme une section à part : [Devtools](/reference/devtools).
