La superposition qui liste chaque touche que le thème associe, ouverte avec
<kbd>?</kbd> ou avec
[`DuxtShortcutsTrigger`](/reference/components/controls/duxt-shortcuts-trigger),
le bouton clavier de l'en-tête.

## Utilisation

```vue
<DuxtShortcuts />
```

## API

Aucune prop.

## Remarques

Sa liste est `duxtShortcuts` — le même tableau auquel les gestionnaires se
réfèrent — si bien que la fiche ne peut pas finir par annoncer une touche que
rien n’associe. Voir
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).

Son état d'ouverture est `useDuxtShortcutSheet()` et non un `ref` à elle, car le
déclencheur doit atteindre le même booléen — et sur un site en
`shortcuts.singleCharacter: false` le déclencheur est la seule chose capable de
l'ouvrir, puisqu'il ne reste aucune association de `?`. Montez-la une fois par
layout ; une seconde instance serait une seconde boîte de dialogue répondant à la
même touche. Voir [Raccourcis clavier](/concepts/keyboard-shortcuts).
