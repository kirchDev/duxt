La superposition qui liste chaque touche que le thème associe, ouverte avec
<kbd>?</kbd>.

## Utilisation

```vue
<DuxtShortcuts />
```

## API

Aucune prop.

## Remarques

Sa liste est `duxtShortcuts` — le même tableau auquel les gestionnaires se
réfèrent — si bien que la fiche ne peut pas finir par annoncer une touche que
rien n’associe. Voir
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).
