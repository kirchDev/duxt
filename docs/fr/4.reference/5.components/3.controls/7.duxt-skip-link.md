« Aller au contenu », invisible jusqu’à ce qu’il reçoive le focus.

## Utilisation

```vue
<DuxtSkipLink />
```

## API

Aucune prop.

## Remarques

Sans lui, chaque changement de page oblige à parcourir à la tabulation l’en-tête,
la rangée des sections et toute la barre latérale avant le premier mot du texte.
`sr-only` le réduit à un seul pixel, et l’état de focus le remet à l’écran
au-dessus de tout le reste.

Le clic est géré plutôt que laissé au hash, parce que le navigateur ne déplace le
focus pour un lien de hash que dans certains navigateurs — le gestionnaire le
déplace dans tous.
