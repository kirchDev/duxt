Un filet de deux pixels sous l’en-tête.

## Utilisation

```vue
<DuxtProgress />
```

## API

Aucune prop.

## Remarques

Un filet plutôt qu’un nombre : sur une longue page de référence, la question
utile est « suis-je près de la fin », et un pourcentage y répond moins bien
qu’une ligne. Il est `aria-hidden`, parce qu’il ne dit rien qu’un lecteur d’écran
ne puisse déjà demander au document.

Mesuré par rapport au document plutôt qu’à un conteneur de défilement, si bien
qu’il reste juste aussi bien sur la mise en page de la documentation que sur la
page d’accueil.
