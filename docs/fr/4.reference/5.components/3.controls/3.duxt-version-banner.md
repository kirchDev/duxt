Affiché au-dessus de la page quand la version lue n’est pas celle par défaut.

## Utilisation

```vue
<DuxtVersionBanner />
```

## API

Aucune prop. Lit
[`useDuxtVersion()`](/reference/composables/paths-and-versions/use-duxt-version).

## Remarques

La moitié visible du problème des versions. `canonical` et `noindex` disent à un
robot quelle version servir ; au lecteur, ils ne disent rien. Quelqu’un arrivé
sur la v0.7.0 depuis un résultat de recherche, ou depuis un lien dans un vieux
ticket, voit une documentation qui ressemble exactement à celle de la version
courante. Chaque moitié prise seule laisse un public dans l’erreur : les balises
du head et ce bandeau sont donc livrés ensemble.

Sur une version `upcoming`, on dit au lecteur que la documentation peut encore
changer, et on ne lui dit **pas** de mettre à jour — c’est le seul état qu’on ne
doit jamais atteindre en devinant.
