Un seul élément à côté du titre : un badge quand il n’y a rien à choisir, le
même badge en déclencheur de menu déroulant quand il y a de quoi choisir.

## Utilisation

```vue
<DuxtVersion />
```

## API

Aucune prop. Lit `versions`, ou le manifeste de sources résolu quand `versions`
n’est pas défini.

## Remarques

Auparavant, la version du projet tenait en badge à côté du titre pendant que les
versions de la documentation vivaient dans un menu déroulant séparé tout à
droite — deux contrôles qui disaient des choses différentes, et celui de droite
n’apparaissait que sur les sources qui ont des versions, si bien que les icônes
à côté de lui se déplaçaient quand vous passiez d’un dépôt à l’autre.

Changer de version conserve la page : c’est le préfixe qui est échangé, et non
le lecteur qui est renvoyé à la racine de la version. Chaque entrée porte son
cycle de vie, parce qu’une liste où trois entrées se ressemblent ne dit rien de
celles qu’on peut encore lire sans risque.
