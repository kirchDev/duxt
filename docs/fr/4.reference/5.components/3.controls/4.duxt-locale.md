Rien du tout quand le site sert une seule langue, une liste déroulante quand il
en sert plusieurs.

## Utilisation

```vue
<DuxtLocale />
```

## API

Aucune prop. Lit `locales`.

## Remarques

Construit comme [`DuxtVersion`](/reference/components/controls/duxt-version) à
côté de lui, si bien qu’un consommateur à une seule locale ne voit jamais que
duxt parle sept langues.

Il utilise `switchLocalePath` plutôt qu’un lien vers la racine de la locale :
changer de langue sur une page traitant du déploiement doit atterrir sur cette
même page dans la nouvelle langue, pas renvoyer le lecteur à la porte d’entrée.
