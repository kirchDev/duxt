La barre en haut de chaque page — le titre du site, les entrées de navigation, la
recherche, les sélecteurs de version et de locale, et la bascule de thème.

## Utilisation

```vue
<DuxtHeader />
```

## API

Aucune prop. Tout vient de la configuration : `title`, `navigation`, `links`,
`version` et `locales`.

## Remarques

Une entrée sans `to` ni `children` signifie « la documentation ». L’entrée
« Docs » de la couche est livrée sans `to` à dessein : où vit la documentation
dépend des préfixes du consommateur, que la couche ne peut pas connaître. Elle se
résout vers la première section, et c’est ce qui fait fonctionner la barre de
navigation par défaut aussi bien sur un site versionné que sur un site plat.
