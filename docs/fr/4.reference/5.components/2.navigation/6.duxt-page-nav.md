Les deux liens au pied d’une page.

## Utilisation

```vue
<DuxtPageNav :path="path" />
```

## API

### Props

| Prop   | Type     | Remarques                                             |
| :----- | :------- | :---------------------------------------------------- |
| `path` | `string` | Obligatoire — le chemin de documentation, sans préfixe |

## Remarques

La navigation s’arrête à la frontière de la section à dessein : passer dans une
autre partie de la documentation est le travail de la rangée des sections, pas
celui d’un lien qui dit « suivant ».

Les groupes sont aplatis dans leurs enfants, si bien que « suivant » est la page
suivante qu’un lecteur lirait, pas le dossier suivant.
