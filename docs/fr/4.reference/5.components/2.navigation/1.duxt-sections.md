La rangée de sections sous l’en-tête, sur les pages de documentation seulement.

## Utilisation

```vue
<DuxtSections />
```

## API

Aucune prop. Lit `sections` ; ne rend rien quand cette liste est vide.

## Remarques

Elle se tient avec la documentation plutôt que dans l’en-tête global, parce que
la page d’accueil n’a aucune section à montrer.

Une section est rarement la page elle-même — c’est la branche dans laquelle la
page se trouve. La correspondance exacte annonce donc `aria-current="page"` et un
ancêtre annonce `true`, ce qui est justement la distinction que `aria-current`
existe pour faire.
