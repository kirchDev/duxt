Une entrée seule, avec son icône, son état actif et — pour une branche — ses
enfants.

## Utilisation

```vue
<DuxtNavigationLink :item="item" />
```

## API

### Props

| Prop   | Type                     | Remarques                          |
| :----- | :----------------------- | :--------------------------------- |
| `item` | `ContentNavigationItem`  | Obligatoire — un nœud de l’arbre    |

## Remarques

Vaut la peine d’être remplacé à lui seul quand seule l’apparence d’une entrée ne
va pas : le remplacer laisse l’arbre, l’état actif et le repliement à
[`DuxtNavigation`](/reference/components/navigation/duxt-navigation).
