Les titres de la page courante, suivis au fil du défilement du lecteur, plus les
liens `aside` configurés en dessous.

## Utilisation

```vue
<DuxtToc :links="page?.body?.toc?.links ?? []" />
```

## API

### Props

| Prop    | Type        | Remarques                                      |
| :------ | :---------- | :--------------------------------------------- |
| `links` | `TocLink[]` | Obligatoire — les liens de sommaire de Content  |

## Remarques

Quel titre est le courant vient de
[`useActiveHeading()`](/reference/composables/reading/use-active-heading), qui
observe les titres plutôt que le décalage de défilement — une dernière section
courte est quand même signalée comme atteinte.

Le bloc `aside.links` en dessous est livré **vide** : un lien de dépôt, un
gestionnaire de tickets ou une communauté appartiennent à qui exploite le site.
