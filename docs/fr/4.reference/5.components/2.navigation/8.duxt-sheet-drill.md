Garde le premier niveau du panneau dans son slot et dessine chaque menu ouvert
depuis celui-ci comme un niveau au-dessus, pour qu’un menu de toute profondeur
conserve toute la largeur du panneau.

## Utilisation

```vue
<DuxtSheetDrill ref="levels">
  <!-- Le premier niveau -->
</DuxtSheetDrill>
```

## API

### Slot

`default`: Le premier niveau.

### Exposé

| Nom | Type | Description |
| :-- | :-- | :-- |
| `drill` | `(link: DuxtLink, event: Event) => void` | Ouvre le menu de `link` comme un nouveau niveau. Au retour, le focus revient à l’élément d’où provenait `event` |

## Remarques

`DuxtHeader` le dessine dans le panneau, et `DuxtSheetLinks` dessine les liens
d’un niveau. Au niveau d’un méga-menu, une colonne n’est pas un niveau de plus :
elle se tient sous son nom, comme dans le panneau. Les niveaux disparaissent à
la fermeture du panneau, qui se rouvre donc toujours au premier.
