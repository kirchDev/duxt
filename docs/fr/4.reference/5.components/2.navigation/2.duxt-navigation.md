La liste imbriquée des pages de la section courante.

## Utilisation

```vue
<script setup lang="ts">
const { data: navigation } = await useDuxtNavigation();
const { items } = useDuxtSection(navigation);
</script>

<template>
  <DuxtNavigation :items="items" />
</template>
```

## API

### Props

| Prop    | Type                       | Remarques                                       |
| :------ | :------------------------- | :---------------------------------------------- |
| `items` | `ContentNavigationItem[]`  | Obligatoire — une branche de l’arbre de Content  |

## Remarques

L’arbre vient de [`useDuxtNavigation()`](/reference/composables/config-and-content/use-duxt-navigation),
qui interroge la collection servant la route courante — un site versionné obtient
donc l’arbre de cette version, pas celui de la version par défaut.
