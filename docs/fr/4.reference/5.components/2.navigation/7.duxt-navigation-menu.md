title: DuxtNavigationMenu
description: Le menu qu’ouvre une entrée de la barre, dans l’une ou l’autre rangée.

---

Ce qui s’ouvre depuis une entrée avec `children` : un menu déroulant aussi
imbriqué que les données, ou un panneau de méga-menu. La rangée dessine son
propre déclencheur dans le slot, car les deux rangées ne se ressemblent pas.

## Utilisation

```vue
<DuxtNavigationMenu :link="entry" align="start">
  <button type="button">{{ entry.label }}</button>
</DuxtNavigationMenu>
```

## API

### Props

| Nom | Type | Par défaut | Description |
| :-- | :-- | :-- | :-- |
| `link` | `DuxtLink` | | L’entrée à laquelle ce menu appartient |
| `align` | `start` \| `center` \| `end` | `center` | L’alignement d’un menu déroulant sur son déclencheur. Un méga-menu est toujours centré sur la page |

### Slot

`default`: Le déclencheur, en un seul élément.

## Remarques

La configuration d’un menu est décrite dans [Créer des menus de
barre](/guides/build-navbar-menus). Pour restyler toutes les entrées d’un coup,
remplacez `DuxtNavigationMenuEntry`, qui dessine le contenu d’une entrée ;
`component` sur le lien fait de même pour une seule.
