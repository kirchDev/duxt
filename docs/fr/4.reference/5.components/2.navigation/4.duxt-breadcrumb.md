La section, puis les groupes éventuels entre elle et la page.

## Utilisation

```vue
<DuxtBreadcrumb :path="path" />
```

## API

### Props

| Prop   | Type     | Remarques                                             |
| :----- | :------- | :---------------------------------------------------- |
| `path` | `string` | Obligatoire — le chemin de documentation, sans préfixe |

## Remarques

`breadcrumb: false` dans la configuration le retire sur tout le site : un arbre
de documentation plat obtient un fil qui ne fait que répéter le nom de sa propre
section.
