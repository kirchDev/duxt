Un contrôle scindé à côté du titre de la page : copier le Markdown, le consulter,
ou l’ouvrir dans un modèle conversationnel.

## Utilisation

```vue
<DuxtCopyPage :path="path" :title="page?.title" :rawbody="page?.rawbody" />
```

## API

### Props

| Prop      | Type     | Remarques                                       |
| :-------- | :------- | :---------------------------------------------- |
| `path`    | `string` | Obligatoire — le chemin de la documentation     |
| `title`   | `string` | Utilisé dans l’invite remise à un modèle        |
| `rawbody` | `string` | La source Markdown, pour le bouton de copie     |

## Remarques

Un contrôle scindé plutôt que quatre boutons — le cas courant est « copier », et
les trois autres sont la même intention par une autre porte.

Ce qu’ils remettent tous, c’est le **Markdown**, pas la page rendue : un modèle à
qui l’on donne du HTML doit défaire une mise en page pour trouver un titre, et un
modèle à qui l’on donne la source lit ce que l’auteur a écrit. Le frontmatter est
retiré, si bien que ce qui est copié se lit comme la page plutôt que comme le
fichier.

Les liens externes ont besoin d’une URL absolue, et l’origine est lue depuis le
navigateur au moment du clic plutôt que depuis la configuration — la seule valeur
qui soit certainement juste, y compris sur un déploiement de prévisualisation
dont personne n’a noté le domaine.
