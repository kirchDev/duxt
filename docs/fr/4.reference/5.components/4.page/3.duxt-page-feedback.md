Le bloc au pied de chaque page.

## Utilisation

```vue
<DuxtPageFeedback @feedback="(helpful) => track(helpful)" />
```

## API

### Emits

| Événement  | Payload             | Quand                      |
| :--------- | :------------------ | :------------------------- |
| `feedback` | `helpful: boolean`  | Le lecteur répond           |

### Slots

| Slot      | Props                  | Ce qu’il remplace          |
| :-------- | :--------------------- | :------------------------- |
| `default` | `{ answered, answer }` | La question et les boutons |

## Remarques

Un slot avec un événement et pas de backend, et c’est là tout le design. La
couche ne stocke rien et n’envoie rien : ce n’est pas son affaire de savoir où
vit l’analytique d’un consommateur, et un thème de documentation qui fait
remonter des données par défaut n’est pas un thème à publier. La réponse vit dans
l’état propre du composant le temps de la visite et nulle part ailleurs — un
changement de route la réinitialise, car une nouvelle page est une nouvelle
question.
