
## API

### Props

| Prop   | Type     | Remarques                                            |
| :----- | :------- | :--------------------------------------------------- |
| `page` | `object` | Obligatoire — le document Content en cours de rendu   |

## Remarques

Pas au pied de l’article, où il se trouvait d’abord et où il se lisait comme une
pensée après coup, sous les liens précédent/suivant. « Modifier cette page », la
date du dernier changement et qui l’a écrite ne font qu’une seule question — la
provenance — et la colonne de droite est déjà celle qui répond à ce qu’une page
EST plutôt qu’à ce qu’elle dit.

Tout ici est dérivé. Le lien d’édition pointe vers le dépôt de la source et la
ref d’où la page a été lue, si bien qu’une page venant d’un tag renvoie vers sa
source plutôt que vers un formulaire d’édition qui modifierait la mauvaise
branche. « Dernière mise à jour » et les contributeurs nécessitent
`history: true` sur la source.
