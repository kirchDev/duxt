Le cadre dans lequel chaque bloc délimité est dessiné : nom de fichier, icône de
langage, bouton de copie.

## Utilisation

Appelé par [`ProsePre`](/reference/mdc-components/prose/prose-pre) plutôt qu’à la
main, mais utilisable directement :

```vue
<DuxtCodeBlock code="pnpm add -D @kirchdev/duxt" language="bash" />
```

## API

### Props

| Prop       | Type     | Remarques                                                |
| :--------- | :------- | :------------------------------------------------------- |
| `code`     | `string` | La source brute, pour le bouton de copie et comme corps   |
| `language` | `string` | Choisit l’icône                                           |
| `filename` | `string` | Le libellé dans l’en-tête                                 |

### Slots

| Slot      | Ce qu’il contient                       |
| :-------- | :-------------------------------------- |
| `default` | Le balisage colorisé, quand il y en a   |

## Remarques

Sans nom de fichier, le bouton de copie flotte dans le coin et apparaît au
survol ; avec un nom, il siège dans l’en-tête, où il est toujours visible. Un
bloc qui affiche en permanence un bouton dans le coin de la page fait plus de
bruit qu’un bloc qui le montre quand un lecteur va le chercher.
