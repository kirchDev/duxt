Une section à l’intérieur de [`::accordion`](/reference/mdc-components/accordion).

## Utilisation

```mdc
:::accordion
  ::accordion-item{label="Pourquoi une couche et pas un module ?" icon="lucide:layers"}
  Un module ne peut livrer ni pages, ni thème, ni valeur par défaut d’app.config.
  ::
:::
```

## API

### Props

| Prop    | Type     | Par défaut | Remarques                           |
| :------ | :------- | :--------- | :---------------------------------- |
| `label` | `string` | —          | Le texte du trigger                 |
| `icon`  | `string` | —          | Tout nom Iconify, avant l’étiquette |

### Slots

| Slot      | Ce qu’il contient        |
| :-------- | :----------------------- |
| `default` | La réponse, en Markdown  |
