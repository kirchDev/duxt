title: Surcharges de prose
description: Ce que la couche change au Markdown ordinaire — liens, titres, images, code et tableaux.
icon: lucide:type
---

Ces composants ne sont jamais appelés par leur nom. Content rend le Markdown
ordinaire à travers eux : en remplacer un change donc l’allure d’un paragraphe,
d’un lien ou d’un bloc de code ordinaires sur toutes les pages.

Ils sont listés ici pour la même raison que les blocs voisins : un nom documenté
fait partie de la surface publique de la couche, et votre propre fichier du même
nom remplace le nôtre.
