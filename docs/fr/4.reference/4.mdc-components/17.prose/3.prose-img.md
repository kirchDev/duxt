Chaque image d’une page Markdown.

## Ce qu’il ajoute

**Deux variantes.** La capture d’un éditeur sombre sur une page blanche — ou
l’inverse — est la chose la plus laide qu’une documentation produise
couramment, et le CSS n’y peut rien parce que ce sont les pixels qui sont faux,
pas le cadre. Une page peut nommer un second fichier :

```md
![La barre latérale](/shots/sidebar.png){dark="/shots/sidebar-dark.png"}
```

**Cliquer pour zoomer**, sauf si l’image demande le contraire :

```md
![Un schéma](/diagram.svg){zoom="false"}
```

## API

### Props

| Prop   | Type      | Par défaut | Remarques                                     |
| :----- | :-------- | :--------- | :-------------------------------------------- |
| `src`  | `string`  | —          | Tel qu’écrit                                  |
| `alt`  | `string`  | —          | Tel qu’écrit                                  |
| `dark` | `string`  | —          | Un second fichier, servi sous le thème sombre |
| `zoom` | `boolean` | `true`     | `false` laisse l’image inerte                 |

## Remarques

La variante sombre est nommée explicitement plutôt que devinée par convention.
Dériver `-dark` d’un nom de fichier fait qu’un fichier manquant devient une
image cassée, et l’auteur ne l’apprend jamais.
