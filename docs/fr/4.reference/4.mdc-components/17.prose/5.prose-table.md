Chaque tableau Markdown.

## Ce qu’il ajoute

Un conteneur de défilement autour du tableau, pour qu’un tableau large défile
dans sa propre boîte au lieu de faire défiler toute la page latéralement.

## API

### Slots

| Slot      | Ce qu’il contient |
| :-------- | :---------------- |
| `default` | Le tableau        |
