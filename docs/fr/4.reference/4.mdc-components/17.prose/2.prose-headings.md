Trois composants, un seul comportement : `ProseH2`, `ProseH3` et `ProseH4`
rendent les titres à partir desquels est construit le sommaire d’une page.

## Ce qu’ils ajoutent

Une ancre de permalien à côté du titre, visible au survol et atteignable au
clavier. L’`id` est le slug de Content lui-même, si bien que l’ancre, le
sommaire et la navigation dans la page s’accordent tous.

## API

### Props

| Prop | Type     | Remarques                                  |
| :--- | :------- | :----------------------------------------- |
| `id` | `string` | Le slug que Content a généré pour le texte |

### Slots

| Slot      | Ce qui y va       |
| :-------- | :---------------- |
| `default` | Le texte du titre |

## Remarques

`ProseH1` n’est délibérément pas surchargé : le titre de la page est rendu par
la page, pas par le Markdown, si bien qu’un titre `#` dans le corps serait un
deuxième `h1` sur la page.
