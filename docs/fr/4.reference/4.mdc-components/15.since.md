En ligne. Marque la version dans laquelle une chose est arrivée — utilisable à
l’intérieur d’un titre.

## Utilisation

### Réessais :since{version="v2.0.0"}

```mdc
### Réessais :since{version="v2.0.0"}
```

## API

### Props

| Prop      | Type     | Par défaut | Remarques        |
| :-------- | :------- | :--------- | :--------------- |
| `version` | `string` | —          | Affiché tel quel |

## Remarques

Il se rattache au modèle de versions au lieu de le répéter : ce que dit le badge,
c’est la version dans laquelle une chose est ARRIVÉE, et c’est un fait sur l’API,
pas sur la page où elle est documentée — il reste donc juste dans chaque version
de la documentation qui porte la phrase.

Pour tout le reste, `:badge[…]` appelle directement le Badge du thème lui-même ;
MDC résout par son nom n’importe quel composant enregistré globalement.
