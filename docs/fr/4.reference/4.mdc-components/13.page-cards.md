Les enfants d’une section, dessinés en cartes avec leur icône, leur titre et
leur description — ce par quoi se termine chaque `index.md` de cette
documentation.

## Utilisation

```mdc
::page-cards
::
```

Sans prop, il liste les enfants de la page courante, et c’est pourquoi il est
montré ici par son nom plutôt que rendu : cette page n’en a aucun.

## API

### Props

| Prop   | Type     | Par défaut       | Remarques                              |
| :----- | :------- | :--------------- | :------------------------------------- |
| `path` | `string` | la page courante | Lister les enfants d’une autre section |

## Remarques

Le titre, la description et l’icône viennent du frontmatter de chaque enfant :
une carte ne peut donc pas dériver de la page qu’elle désigne.
