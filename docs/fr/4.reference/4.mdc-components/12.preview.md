L’exemple est le vrai composant dans le vrai thème — mêmes tokens, même mode
sombre — si bien qu’un lecteur voit ce que fait un bloc plutôt qu’une
description de celui-ci. Cette page, et toutes les autres pages de ce dossier,
sont construites avec lui.

## API

Aucune prop.

### Slots

| Slot      | Ce qu’il contient                                             |
| :-------- | :------------------------------------------------------------ |
| `default` | L’exemple, rendu                                               |
| `code`    | La source, dans un bloc de code. Omettez-le et aucune barre d’onglets n’apparaît |

## Remarques

La source dans `#code` est écrite à la main plutôt que dérivée de l’exemple
au-dessus, et c’est le seul vrai coût du bloc. Quand le composant s’exécute, ses
enfants sont des nœuds rendus et le Markdown qui les a produits a disparu ; les
re-sérialiser reviendrait à deviner une syntaxe d’où ils ne sont jamais venus.

::callout{type="warning" title="Deux copies divergent"}
Rien ne vérifie que l’onglet source correspond à ce qui est rendu à côté. Gardez
l’exemple assez court pour que modifier l’un sans l’autre saute aux yeux.
::
