Enveloppe une **liste ordonnée** dans une mise en page à étapes. Il numérote la
liste qu’il enveloppe, quelle qu’elle soit, si bien que le Markdown reste une
liste ordinaire.

## Utilisation

::preview
:::steps
1. Ajoutez la dépendance.
2. Étendez la couche.
3. Écrivez du Markdown.
:::

#code
```mdc
::steps
1. Ajoutez la dépendance.
2. Étendez la couche.
3. Écrivez du Markdown.
::
```
::

## API

Aucune prop. Le bloc met en forme son `<ol>` enfant.

### Slots

| Slot      | Ce qu’il contient                     |
| :-------- | :------------------------------------ |
| `default` | Une liste ordonnée, éléments Markdown |

## Remarques

À sortir dès qu’une étape porte un bloc de code : dans une liste ordonnée
ordinaire, le bloc écarte le texte de son propre numéro, et cette mise en page
garde le numéro épinglé à côté.

Les marqueurs sont un compteur CSS sur les éléments de liste, pas du contenu —
un lecteur qui copie les étapes obtient le texte sans la numérotation dessinée
deux fois.
