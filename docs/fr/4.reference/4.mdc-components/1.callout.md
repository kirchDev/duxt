Un encadré, dans l’une de quatre variantes. Le corps est du Markdown : les
liens, le `code` et les listes fonctionnent tous à l’intérieur.

## Types

::preview
:::callout{type="info"}
`info` — la valeur par défaut, pour le contexte que la page suppose acquis.
:::

:::callout{type="tip"}
`tip` — quelque chose qui rend la tâche plus facile.
:::

:::callout{type="warning"}
`warning` — une manière de se tromper.
:::

:::callout{type="danger"}
`danger` — perte de données, ou un changement qui ne peut pas être annulé.
:::

#code
```mdc
::callout{type="info"}
`info` — la valeur par défaut, pour le contexte que la page suppose acquis.
::
```
::

## API

### Props

| Prop    | Type                                  | Par défaut | Remarques                                           |
| :------ | :------------------------------------ | :--------- | :-------------------------------------------------- |
| `type`  | `info` · `tip` · `warning` · `danger` | `info`     | Choisit la couleur, l’icône et le rôle               |
| `title` | `string`                              | —          | Première ligne en gras ; le corps suit               |
| `icon`  | `string`                              | par type   | Tout nom Iconify, surchargeant la valeur par défaut  |

### Slots

| Slot      | Ce qu’il contient      |
| :-------- | :--------------------- |
| `default` | Le corps, en Markdown  |

## Remarques

Un callout `danger` porte `role="alert"` ; les autres non. Une alerte interrompt
un lecteur d’écran au milieu d’une phrase, ce qui est juste pour « ceci supprime
vos données » et faux pour une astuce.
