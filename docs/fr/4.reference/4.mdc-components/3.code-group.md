Plusieurs blocs de code délimités affichés comme un seul bloc, avec un onglet
chacun. L’étiquette de chaque onglet est le nom de fichier du bloc lui-même,
parce que c’est entre cela que le lecteur choisit et que c’est déjà écrit.

## API

Aucune prop. Un bloc sans nom de fichier reçoit son langage comme étiquette.

### Slots

| Slot      | Ce qu’il contient          |
| :-------- | :------------------------- |
| `default` | Une suite de blocs de code |

## Remarques

Les enfants sont lus dans les VNodes du slot `default` plutôt qu’enregistrés par
un composant enfant : un bloc de code est un `ProsePre`, pas quelque chose à qui
ce bloc peut demander de s’annoncer, et son nom de fichier est une prop de ce
nœud.

Pour tout ce qui n’est pas du code, utilisez [Tab group](/reference/mdc-components/tab-group).
