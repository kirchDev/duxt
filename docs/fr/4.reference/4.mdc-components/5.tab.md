Un panneau à l’intérieur de [`::tab-group`](/reference/mdc-components/tab-group).
Il n’a aucun sens à lui seul.

## Utilisation

```mdc
:::tab-group
  ::tab{label="pnpm"}
  La couche est une dépendance de développement.
  ::
:::
```

## API

### Props

| Prop    | Type     | Par défaut | Remarques                       |
| :------ | :------- | :--------- | :------------------------------ |
| `label` | `string` | —          | Le texte du trigger de l’onglet |

### Slots

| Slot      | Ce qu’il contient       |
| :-------- | :---------------------- |
| `default` | Le panneau, en Markdown |

## Remarques

Le composant enregistre sa propre étiquette auprès du parent au moment du setup,
et c’est ce qui permet de construire la liste des triggers à partir d’enfants
que MDC n’a pas encore rendus.
