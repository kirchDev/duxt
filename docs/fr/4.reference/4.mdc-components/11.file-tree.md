Un listing de répertoire sous forme d’arborescence, avec l’icône de chaque type
de fichier déduite de son extension.

## Utilisation

::preview
:::file-tree{title="your-project/"}
---
tree:
  - name: docs/
    children:
      - name: index.md
      - name: 1.getting-started/
        children:
          - name: index.md
          - name: 1.installation.md
  - name: app/
    children:
      - name: app.config.ts
  - name: nuxt.config.ts
---
:::

## API

### Props

| Prop    | Type      | Par défaut | Remarques                                  |
| :------ | :-------- | :--------- | :----------------------------------------- |
| `tree`  | `Entry[]` | —          | Fourni en YAML dans le corps du bloc        |
| `title` | `string`  | —          | L’étiquette racine au-dessus de l’arborescence |

Une entrée est `{ name, children? }`. Un nom qui se termine par `/`, ou qui
porte des enfants, est un répertoire.

## Remarques

Construit sur l’arborescence de reka-ui : il a donc le focus glissant (roving
focus), la navigation aux flèches et les rôles ARIA. La clé d’un nœud est son
chemin plutôt que son nom : les noms se répètent d’une branche à l’autre, les
chemins non.
