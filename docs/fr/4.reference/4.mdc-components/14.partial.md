En ligne, et le seul composant qui sort de la source de la page elle-même :
`_partials/` dans **n’importe quelle** source alimente une seule collection
partagée.

## Utilisation

```mdc
:partial{name="install"}
```

## API

### Props

| Prop   | Type     | Par défaut | Remarques                                |
| :----- | :------- | :--------- | :--------------------------------------- |
| `name` | `string` | —          | Le fichier dans `_partials/`, sans `.md` |

## Remarques

Content ne livre aucune directive d’inclusion, et d’un dépôt à l’autre c’est un
manque sans contournement : une note d’installation qui doit se lire à
l’identique dans trois projets est copiée dans trois projets et dérive. Un bloc
défini dans un dépôt est appelable depuis les pages d’un autre.

Traduit comme une page. Une source qui déclare `locales` obtient une collection
de fragments par langue — `docs/de/_partials/install.md` est le `install`
allemand — et le composant se replie exactement comme la page qui l’entoure,
jusqu’à l’original non traduit. N’écrivez que les langues dont vous disposez ;
le reste se résout vers le haut.
