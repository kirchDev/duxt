---
title: Groupe de champs
description: Une liste de champs, en un seul bloc.

Regroupe des blocs [`::field`](/reference/mdc-components/field) pour qu’ils se
lisent comme une seule liste à séparateurs plutôt que comme des cartes
distinctes.

## Utilisation

::preview
::::field-group
:::field{name="path" type="string" required}
Dossier contenant le Markdown, relatif à la racine du dépôt.
:::

:::field{name="history" type="boolean" default="false"}
Lire l’historique git de cette source pour « Dernière mise à jour » et les
contributeurs.
:::
::::

#code
```mdc
:::field-group
  ::field{name="path" type="string" required}
  Dossier contenant le Markdown, relatif à la racine du dépôt.
  ::
:::
```
::

## API

Aucune prop.

### Slots

| Slot      | Ce qu’il contient   |
| :-------- | :------------------ |
| `default` | Des blocs `::field` |
