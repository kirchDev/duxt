Une commande affichée pour chaque gestionnaire de paquets que le site propose,
avec le choix du lecteur mémorisé pour tout le site.

## Utilisation

Écrivez la commande **sans** le gestionnaire — `add -D pkg`, `run build`,
`dlx create-nuxt`. L’orthographe propre à chaque gestionnaire est substituée.

## Verbes

| Écrit | pnpm | npm | yarn | bun |
| :------- | :------- | :------- | :------- | :------- |
| `add` | `add` | `install` | `add` | `add` |
| `install` | `install` | `install` | `install` | `install` |
| `remove` | `remove` | `uninstall` | `remove` | `remove` |
| `run` | `run` | `run` | `run` | `run` |
| `exec` | `exec` | `exec` | `exec` | `exec` |
| `create` | `create` | `create` | `create` | `create` |
| `dlx` | `pnpm dlx` | `npx` | `yarn dlx` | `bunx` |
| `update` | `update` | `update` | `up` | `update` |
| `outdated` | `outdated` | `outdated` | — | `outdated` |
| `audit` | `audit` | `audit` | `npm audit` | `audit` |
| `link` | `link` | `link` | `link` | `link` |
| `why` | `why` | `why` | `why` | `why` |
| `patch` | `patch` | — | `patch` | `patch` |

`yarn` désigne **Berry (≥ 2)**. Berry n’a ni `outdated` ni installation globale, et
npm n’a `patch` sous aucune orthographe — un tiret ci-dessus signifie que ce
gestionnaire **n’obtient pas d’onglet** pour cette commande, plutôt qu’un
quasi-équivalent qui fait autre chose. Le build indique quelle page l’a demandé.

Un `-g` ou `--global` n’importe où dans la commande est une installation globale,
et retire l’onglet `yarn` pour la même raison.

`i`, `rm`, `un`, `uninstall`, `up` et `upgrade` sont acceptés et repliés sur la
ligne qui les porte. Un verbe absent du tableau est imprimé tel quel pour chaque
gestionnaire, et le build le signale — le tableau est toujours en retard sur la
sous-commande la plus récente d’un gestionnaire, et refuser un mot inconnu serait
pire que de l’afficher.

## API

### Props

| Prop       | Type       | Par défaut             | Remarques                                    |
| :--------- | :--------- | :--------------------- | :------------------------------------------- |
| `command`  | `string`   | requis                 | Sans le gestionnaire — `add -D pkg`           |
| `managers` | `DuxtPackageManager[]` | `duxt.packageManagers` | Surcharge la liste du site pour un seul bloc  |

## Remarques

Le choix est un cookie, et non un stockage navigateur, et c’est délibéré : le
stockage est lu après l’hydratation, si bien que le bloc afficherait un
gestionnaire puis basculerait vers un autre sous les yeux du lecteur. Il vient
du site lui-même, n’identifie personne et porte une valeur que le lecteur a
choisie — voir
[`usePackageManager()`](/reference/composables/reading/use-package-manager).

Un bloc peut lister moins de gestionnaires que le choix du lecteur n’en couvre ;
il retombe sur son propre premier onglet plutôt que de ne rien afficher.
