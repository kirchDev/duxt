## Signature

```ts
const notify = useDuxtToast();

notify.success(t('duxt.code.copiedToast'));
```

## Retour

`{ success, info, warning, error, loading, dismiss }`.

## Remarques

L’enveloppe est la jointure : un consommateur qui veut un autre système de
notifications remplace ce seul composable plutôt que chaque site d’appel, et les
composants propres à la couche continuent de fonctionner.
