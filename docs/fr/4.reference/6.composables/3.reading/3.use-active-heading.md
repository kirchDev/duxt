## Signature

```ts
const active = useActiveHeading(ids);
```

## Retour

L’id du titre où le lecteur se trouve actuellement.

## Remarques

Il observe les titres plutôt que le décalage de défilement, si bien qu’une
dernière section courte est tout de même signalée comme atteinte — l’échec
habituel d’une table des matières fondée sur la position de défilement.

`duxt.toc.scrollOffset` fixe la ligne d’activation sous le haut de la fenêtre.
`toc.depth` en est indépendant et choisit les titres présents dans la table.
