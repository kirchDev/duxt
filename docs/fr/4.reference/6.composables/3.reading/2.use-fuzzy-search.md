## Signature

```ts
const { search } = useFuzzySearch(collection, {
  ignoredTags: ['table'], threshold: 0.35, minMatchCharLength: 3, limit: 20
});
```

## Retour

Une fonction de recherche qui note les approximations.

## Remarques

Elle ne s’exécute que lorsque la recherche exacte ne renvoie rien, et
l’interface le dit — un lecteur qui a fait une faute de frappe doit obtenir la
page, mais doit aussi savoir que c’est bien ce qui s’est passé.

`collection` vaut `docs` par défaut. `ignoredTags` est transmis aux sections de
recherche Content ; seuil et longueur minimale règlent Fuse, et `limit` borne
les résultats. Les valeurs du site vivent dans `duxt.search.fuzzy`.
