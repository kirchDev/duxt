## Signature

```ts
const { search } = useFuzzySearch(items);
```

## Retour

Une fonction de recherche qui note les approximations.

## Remarques

Elle ne s’exécute que lorsque la recherche exacte ne renvoie rien, et
l’interface le dit — un lecteur qui a fait une faute de frappe doit obtenir la
page, mais doit aussi savoir que c’est bien ce qui s’est passé.
