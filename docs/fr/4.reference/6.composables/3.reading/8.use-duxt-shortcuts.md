## Signature

```ts
const shortcuts = useDuxtShortcuts();

onDuxtShortcut('k', () => open());
```

## Remarques

Le seul endroit qui sait quelles touches sont associées, si bien que la
superposition sur `?` et les gestionnaires ne peuvent pas se contredire.
`onDuxtShortcut()`, à côté, associe une touche avec les garde-fous dont toute
association a besoin — dont celui de ne jamais se déclencher pendant que le
lecteur écrit.
