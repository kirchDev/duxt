---
title: useDuxtPageFocus()
description: Déplace le focus vers le titre après une navigation côté client.
icon: lucide:focus
---

## Signature

```ts
useDuxtPageFocus();
```

## Remarques

Un changement de route côté client remplace le document sans déplacer le focus,
si bien qu’un lecteur d’écran continue de lire l’ancienne page et qu’une
tabulation clavier reprend là où la page précédente s’était arrêtée. Ceci place
le focus sur le titre de la nouvelle page.
