---
title: useDuxtSearch()
description: La recherche sur toutes les sources, classées ensemble.
icon: lucide:search
---

## Signature

```ts
const { search, init, labelled } = useDuxtSearch();
```

## Retour

| Valeur     | Ce que c’est                                                               |
| :--------- | :------------------------------------------------------------------------- |
| `search`   | Lancer une requête, sur toutes les sources                                 |
| `init`     | Construire l’index, appelé à la première ouverture de la boîte de dialogue |
| `labelled` | Les résultats portant la source d’où ils viennent                          |

## Remarques

L’index est construit à la première utilisation, pas au chargement de la page :
un lecteur qui ne cherche jamais ne le paie jamais.
