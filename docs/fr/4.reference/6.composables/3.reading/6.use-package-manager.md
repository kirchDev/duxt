description: Le gestionnaire de paquets qu’un lecteur a choisi.
icon: lucide:package
---

## Signature

```ts
const manager = usePackageManager();
```

## Remarques

Un cookie plutôt qu’un stockage navigateur, et c’est délibéré : le stockage est
lu après l’hydratation, si bien qu’un bloc de commande afficherait un
gestionnaire puis basculerait vers un autre sous les yeux du lecteur. Il vient
du site lui-même, n’identifie personne et porte une valeur que le lecteur a
choisie.
