---
title: useRecentPages()
description: Les pages ouvertes le plus récemment, jusqu’à la limite configurée.
icon: lucide:history
---

## Signature

```ts
const { recent, remember, load } = useRecentPages(limit);
```

## Remarques

Conservées dans le navigateur, et non dans un cookie : elles ne servent jamais
au rendu serveur, elles ne voyagent donc avec aucune requête.

La limite vaut cinq par défaut. La recherche utilise
`duxt.search.recentPages` ; `0` masque la liste et ne conserve aucune nouvelle
page.
