---
title: useDuxtSection()
description: La partie de la documentation dans laquelle se trouve cette page.
icon: lucide:folder-open
---

## Signature

```ts
const { section, items } = useDuxtSection(navigation);
```

## Retour

| Valeur    | Type     | Ce que c’est                                          |
| :-------- | :------- | :---------------------------------------------------- |
| `section` | `object` | La section configurée sous laquelle se trouve la page  |
| `items`   | `array`  | La branche de l’arbre correspondant à cette section    |

## Remarques

Sans `sections` configurées, c’est l’arbre entier qui revient, ce qui est la
bonne forme pour une documentation qui n’est pas découpée en parties.
