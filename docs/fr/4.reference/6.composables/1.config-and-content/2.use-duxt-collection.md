## Signature

```ts
const { collection, source, sources } = useDuxtCollection();
```

## Retour

| Valeur       | Type     | Ce que c’est                                      |
| :----------- | :------- | :------------------------------------------------ |
| `collection` | `string` | Le nom de la collection servant la route courante  |
| `source`     | `object` | La source résolue derrière elle                    |
| `sources`    | `array`  | Toutes les sources résolues                        |

## Remarques

`collection` est une **chaîne**, pas un type littéral — les noms de collections
d’un site sont générés à partir de ses propres sources, si bien que rien dans la
couche ne peut les nommer. Passez-la à `queryCollection` plutôt que d’écrire
`'docs'`.
