## Signature

```ts
const { data: navigation } = await useDuxtNavigation();
```

## Retour

Un handle `useAsyncData` sur l’arbre de navigation de la collection qui sert la
route courante.

## Remarques

Demander par route plutôt qu’une fois pour le site est ce qui rend correct un
arbre versionné : lire `v0.7.0` donne les pages de cette version-là, pas celles
de la version par défaut.
