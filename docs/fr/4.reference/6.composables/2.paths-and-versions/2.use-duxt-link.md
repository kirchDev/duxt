L’inverse de [`useDuxtPath()`](/reference/composables/paths-and-versions/use-duxt-path).

## Signature

```ts
const localeLink = useDuxtLink();

localeLink('/getting-started');
```

## Retour

Une fonction qui remet le préfixe de locale sur un chemin de documentation, et
laisse une URL absolue telle quelle.

## Remarques

Utilisez-la pour chaque `to` que rend un composant remplacé. Un chemin écrit à
la main dans un composant est correct dans une langue et faux dans les six
autres.
