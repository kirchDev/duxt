## Signature

```ts
const version = useDuxtVersion();
```

## Retour

| Valeur          | Ce à quoi elle répond                           |
| :-------------- | :---------------------------------------------- |
| `sources`       | Toutes les versions du dépôt lu                 |
| `current`       | La version à laquelle appartient cette page     |
| `preferred`     | La version sur laquelle un lecteur devrait être |
| `isPreferred`   | Si ces deux-là sont la même                     |
| `status`        | Son cycle de vie — upcoming, current, eol …     |
| `kind`          | Branche ou tag                                  |
| `shouldIndex`   | Si la page demande à être indexée               |
| `shouldWarn`    | Si la bannière s’affiche                        |
| `preferredPath` | Cette même page, dans la version préférée       |

## Remarques

Trois questions au même endroit — ce que montre le sélecteur, ce que dit la
bannière, et si la page demande à être indexée — parce que c’est la même
question à propos de la même version.
