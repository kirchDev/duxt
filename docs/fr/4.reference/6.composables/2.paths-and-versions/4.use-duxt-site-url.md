## Signature

```ts
const { origin, absolute } = useDuxtSiteUrl();
```

## Retour

| Valeur     | Type       | Ce que c’est                               |
| :--------- | :--------- | :----------------------------------------- |
| `origin`   | `string`   | L’origine configurée du site               |
| `absolute` | `function` | Un chemin, rendu absolu par rapport à elle |

## Remarques

Nécessaire partout où une URL quitte la page — un élément de flux, une balise
canonical, une image OG. À l’intérieur de la page, utilisez un chemin.
