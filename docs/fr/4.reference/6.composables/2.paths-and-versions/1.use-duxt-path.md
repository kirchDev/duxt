## Signature

```ts
const path = useDuxtPath();
```

## Retour

Le chemin de la route courante, segment de locale retiré — le chemin tel que la
documentation le connaît.

## Remarques

Tout ce qui raisonne sur les pages raisonne là-dessus, pas sur `route.path` :
`/de/duxt/getting-started` et `/duxt/getting-started` sont la même page.
