---
title: Le client de requêtes
description: Désactivé par défaut et dirigé uniquement vers une cible déclarée publique.
icon: lucide:send-horizontal
---

```ts
options: { tryIt: { baseUrl: 'https://api.example.com', variables: { tenant: 'demo' } } }
```

Sans `baseUrl`, la page reste statique. `/` utilise la même origine que la
documentation. `variables` est une liste d’autorisation ; si une variable
inconnue reste dans l’URL, aucun client n’apparaît. Les paramètres de chemin
restent modifiables. Les valeurs vivent uniquement dans l’état du composant et
la requête part directement du navigateur vers l’API.
