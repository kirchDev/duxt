Des règles que ce projet s'impose, écrites parce que le code ne peut pas les
énoncer. Elles engagent le travail dans ce dépôt ; rien ici ne contraint un site
qui étend la couche.

Une règle dit ce qui se fait ; une [décision d'architecture](/adr) dit pourquoi
elle l'a emporté sur les autres options, et reste lisible une fois le
raisonnement sorti de toutes les têtes. Le journal des décisions ne fait que
s'ajouter — d'où sa place à côté de ces pages et non parmi elles : celles-ci se
modifient quand elles changent.
