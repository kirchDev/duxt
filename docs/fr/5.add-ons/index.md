title: Extensions

---

Une extension est un layer Nuxt publié à côté de duxt plutôt qu'à l'intérieur.
Un site qui en veut une l'ajoute à `extends` à côté de `@kirchdev/duxt` ; un
site qui n'en veut pas n'embarque rien de son code. Chaque page en installe une.
Ce sur quoi elles reposent se trouve dans [Hooks](/reference/hooks).
