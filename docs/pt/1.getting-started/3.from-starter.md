title: Começar com o starter
description: Cria com o Nuxi um site de documentação duxt pronto a executar.

---

O [starter do duxt](https://github.com/kirchDev/duxt-starter) é um pequeno site
de documentação com uma página inicial e uma secção de primeiros passos. O
Nuxi copia-o, instala as dependências e cria o repositório Git:

```bash
npx nuxi@latest init -t github:kirchDev/duxt-starter
cd <diretório-do-projeto>
pnpm dev
```

Abre o endereço que o Nuxt mostra e depois edita os ficheiros em `docs/`. A
navegação e a pré-visualização da página inicial atualizam-se com as tuas
páginas. Para um projeto que já existe, usa antes a
[Instalação](/getting-started/installation).
