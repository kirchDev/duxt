Uma entrada em `navigation` ou `sections` torna-se um menu quando tem
`children`. Tudo o resto é configuração nos mesmos objetos de ligação: a
profundidade do menu, se é uma lista ou um painel e como cada entrada é
desenhada. A [demonstração](/demo) tem um exemplo de cada na sua fila de secções.

## Passos

::steps

1. **Aninhe as ligações.** Uma entrada com `children` abre um menu pendente, e
   um filho com `children` abre outro menu ao lado, com a profundidade que os dados
   tiverem:

   ```ts [app/app.config.ts]
   export default defineAppConfig({
     duxt: {
       navigation: [
         {
           label: 'Platform',
           icon: 'lucide:layers',
           children: [
             { label: 'Overview', to: '/platform' },
             {
               label: 'API',
               children: [
                 { label: 'REST', to: '/api/rest' },
                 { label: 'Webhooks', to: '/api/webhooks' }
               ]
             }
           ]
         }
       ]
     }
   });
   ```

2. **Transforme-o num painel.** `menu: 'mega'` dispõe os filhos numa grelha de
   `columns`. Um filho com filhos próprios é uma coluna sob o seu nome; um filho
   sem eles é uma célula própria:

   ```ts
   {
     label: 'Platform',
     menu: 'mega',
     columns: 3,
     divided: true,
     children: [
       {
         label: 'Highlights',
         hideLabel: true,
         children: [
           {
             label: 'Editor',
             to: '/editor',
             image: '/editor.svg',
             display: 'feature',
             description: 'Write and preview'
           }
         ]
       },
       {
         label: 'API',
         children: [
           { label: 'REST', to: '/api/rest' },
           { label: 'Webhooks', to: '/api/webhooks', badge: 'New' },
           { label: 'All of the API', to: '/api', display: 'more' }
         ]
       },
       { label: 'New here?', to: '/start', display: 'callout' }
     ]
   }
   ```

3. **Escolha a disposição.** As mesmas opções produzem painéis bem diferentes:

   | Quer | Defina |
   | :-- | :-- |
   | Colunas de ligações ao lado de uma lista em destaque | Uma primeira coluna com `hideLabel` e entradas `display: 'feature'`, e `divided` na segunda |
   | Uma grelha de produtos | `columns: 3`, entradas com `icon`, `description` e `display: 'feature'`, e um `display: 'callout'` final |
   | Um painel largo com introdução | `width: 'full'`, `columns: 6`, `divided` e uma primeira coluna com `span: 2`, `image` e `description` |
   | Uma imagem sobre cada coluna | `width: 'full'` e `image` em cada coluna |

4. **Acrescente uma célula sua, se as formas não chegarem.** `component` nomeia
   um componente registado globalmente, que substitui o conteúdo da entrada,
   preenche a sua célula e recebe a entrada como `link`. Dê ao ficheiro o nome
   `.global.vue`, porque `app.config` só o pode referir pelo nome. Um componente
   opaco esconde o realce que o menu pinta atrás de uma entrada, por isso desenhe o
   seu:

   ```vue [app/components/MenuPromo.global.vue]
   <script setup lang="ts">
   defineProps<{ link: DuxtLink }>();
   </script>

   <template>
     <span
       class="flex h-full p-3 in-data-highlighted:ring-2"
     >
       {{ link.label }}
     </span>
   </template>
   ```

5. **Use a segunda fila da mesma forma.** `sections` tem a mesma forma. Uma
   secção com menu pertence à área da sua primeira ligação e, quando duas entradas
   reclamam uma página, a primeira fica ativa, por isso as entradas simples vêm
   antes dos menus que repetem as suas ligações.

6. **Confirme num telemóvel.** Abaixo do ponto de quebra `lg`, o painel lateral
   mostra o primeiro nível e cada menu desliza como um nível próprio sob um botão
   de voltar. As colunas de um megamenu ficam num só nível, sob os seus nomes.

::

## Porque funciona assim

Um megamenu é centrado na página e não na sua entrada. Um painel tão largo não
tem uma posição sensata em relação a uma entrada da fila: preso a ela, o mesmo
menu ficava noutro sítio para cada entrada e cada largura de janela.

O painel lateral muda de nível em vez de indentar, porque cada nível aninhado
tira largura ao anterior e um telemóvel não a tem de sobra. Um nível de cada vez
também mantém cada ligação em toda a largura, seja qual for a profundidade.

Todas as opções estão na [referência de configuração](/reference/configuration),
e os componentes são
[DuxtNavigationMenu](/reference/components/navigation/duxt-navigation-menu) e
[DuxtSheetDrill](/reference/components/navigation/duxt-sheet-drill).

## Lista de verificação

- [ ] Cada entrada que abre um menu tem `children`, e um `to` apenas se a sua própria página deve encabeçar esse menu
- [ ] As `columns` de um megamenu condizem com os valores `span` das células
- [ ] As entradas simples de `sections` vêm antes dos menus que repetem as suas ligações
- [ ] O menu foi aberto com largura de telemóvel até ao nível mais profundo
