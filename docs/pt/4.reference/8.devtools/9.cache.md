title: Cache
description: A cache de descargas do Content, e uma forma de deitar fora uma entrada.

---

Todas as fontes remotas são clonadas para `.data/content` e ficam lá. Nada numa
compilação menciona esse directório, por isso nada o sugere quando corre mal.

::devtools-panel{tab="cache"}
::

## Porque interessa

Um directório desactualizado custou aqui tempo a sério uma vez: uma etiqueta foi
pedida como se fosse um ramo, a operação falhou, e a pasta escrita a meio continuou
a responder para a configuração já corrigida até alguém a apagar à mão. A
compilação não disse nada, porque para ela a fonte já estava descarregada.

**Drop** remove uma entrada; a compilação seguinte volta a descarregá-la.

## Notas

O Content indexa um directório por repositório **e** ref, por isso uma entrada de
uma ref que mudaste de nome nunca é reutilizada — nem nunca limpa. É neste painel
que se encontram.

::callout{type="warning"}
Deitar fora uma entrada apaga um directório no teu disco. É sempre só a cache —
nunca uma fonte de verdade —, mas é uma eliminação a sério, e é a razão pela qual
este separador não é registado numa compilação.
::
