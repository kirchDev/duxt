Sete idiomas e um ficheiro JSON por espaço de nomes fazem do desvio uma questão de
tempo — e o vue-i18n responde a uma chave em falta imprimindo a chave, por isso uma
falha aparece como um botão com o rótulo `duxt.nav.open` numa página que ninguém
abriu nesse idioma.

::devtools-panel{tab="i18n"}
::

## Colunas

| Coluna            | O que diz                                                        |
| :---------------- | :------------------------------------------------------------------ |
| `Directory`       | Uma pasta em `i18n/locales`; `base` marca aquela de comparação      |
| `Keys`            | Quantas chaves define ao todo                                        |
| `Missing vs base` | Chaves que a base tem e esta não                                     |
| `Not in base`     | Chaves que esta tem e a base não — normalmente uma mudança de nome   |

## Notas

**Faltar é um facto, não um veredicto.** Um ficheiro de idioma pode conter de
propósito apenas os seus desvios: `pt-BR` substitui um punhado de cadeias e lê o
resto de `pt` pelo recuo para o idioma base, por isso uma lista longa em «missing»
aí é o desenho a funcionar.

**«Not in base» lê-se duas vezes.** Uma chave que mais ninguém tem costuma ser uma
gralha ou uma mudança de nome que ficou a meio — e imprime-se a si própria na
página.

A linha acima da tabela lista os idiomas que o site serve de facto, que é uma lista
diferente das pastas em disco: vários idiomas podem partilhar uma.
