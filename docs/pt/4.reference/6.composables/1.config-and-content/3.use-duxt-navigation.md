## Assinatura

```ts
const { data: navigation } = await useDuxtNavigation();
```

## Devolve

Um handle de `useAsyncData` sobre a árvore de navegação da coleção que serve a
rota atual.

## Notas

Perguntar por rota em vez de uma vez para o site é o que torna correta uma
árvore versionada: ler `v0.7.0` dá as páginas dessa versão, não as da versão por
omissão.
