## Assinatura

```ts
const { section, items } = useDuxtSection(navigation);
```

## Devolve

| Valor     | Tipo     | O que é                                        |
| :-------- | :------- | :--------------------------------------------- |
| `section` | `object` | A secção configurada em que a página se encontra |
| `items`   | `array`  | O ramo da árvore dessa secção                   |

## Notas

Sem `sections` configuradas volta a árvore inteira, que é a forma certa para
documentação que não está dividida em partes.
