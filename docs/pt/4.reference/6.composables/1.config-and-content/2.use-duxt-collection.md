## Assinatura

```ts
const { collection, source, sources } = useDuxtCollection();
```

## Devolve

| Valor        | Tipo     | O que é                                         |
| :----------- | :------- | :---------------------------------------------- |
| `collection` | `string` | O nome da coleção que serve a rota atual         |
| `source`     | `object` | A fonte resolvida por trás dela                  |
| `sources`    | `array`  | Todas as fontes resolvidas                       |

## Notas

`collection` é uma **string**, não um tipo literal — os nomes de coleção de um
site são gerados a partir das suas próprias fontes, por isso nada na camada os
pode nomear. Passa-o a `queryCollection` em vez de escreveres `'docs'`.
