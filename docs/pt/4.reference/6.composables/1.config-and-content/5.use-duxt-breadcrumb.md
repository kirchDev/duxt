## Assinatura

```ts
const trail = useDuxtBreadcrumb(path);
```

## Devolve

As entradas entre a secção e a página, cada uma com o seu título e caminho.

## Notas

Um grupo que não transporta página própria aparece no trilho sem ligação — a
pasta é real, a página por trás dela não.
