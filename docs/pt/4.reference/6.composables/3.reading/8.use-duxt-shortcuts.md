## Assinatura

```ts
const shortcuts = useDuxtShortcuts();

onDuxtShortcut('k', () => open());
```

## Notas

O único sítio que sabe que teclas estão associadas, para que a sobreposição em
`?` e os handlers não possam discordar. `onDuxtShortcut()`, ao seu lado, associa
uma tecla com as salvaguardas de que qualquer associação precisa — incluindo
nunca disparar enquanto o leitor está a escrever.
