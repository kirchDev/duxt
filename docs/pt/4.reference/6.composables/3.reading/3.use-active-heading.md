## Assinatura

```ts
const active = useActiveHeading(ids);
```

## Devolve

O id do cabeçalho onde o leitor está neste momento.

## Notas

Observa os cabeçalhos em vez do deslocamento, por isso uma última secção curta
continua a ser dada como alcançada — a falha habitual de um índice guiado pela
posição de deslocamento.
