## Assinatura

```ts
const manager = usePackageManager();
```

## Notas

Um cookie em vez de armazenamento do navegador, e deliberadamente: o
armazenamento é lido depois da hidratação, por isso um bloco de comandos
desenharia um gestor e depois trocaria para outro à frente do leitor. É próprio
do site, não identifica ninguém e transporta um valor que o leitor escolheu.
