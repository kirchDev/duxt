title: useDuxtToast()
description: Notificações, embrulhadas para que nenhum componente importe a biblioteca.
icon: lucide:bell
---

## Assinatura

```ts
const notify = useDuxtToast();

notify.success(t('duxt.code.copiedToast'));
```

## Devolve

`{ success, info, warning, error, loading, dismiss }`.

## Notas

O embrulho é a junção: quem a consome e queira outro sistema de notificações
substitui este único composable em vez de todos os sítios que o chamam, e os
componentes da própria camada continuam a funcionar.
