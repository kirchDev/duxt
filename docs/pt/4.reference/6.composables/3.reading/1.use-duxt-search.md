## Assinatura

```ts
const { search, init, labelled } = useDuxtSearch();
```

## Devolve

| Valor      | O que é                                                                      |
| :--------- | :--------------------------------------------------------------------------- |
| `search`   | Correr uma consulta, em todas as fontes                                      |
| `init`     | Construir o índice, chamado quando a caixa de diálogo abre pela primeira vez |
| `labelled` | Resultados que transportam a fonte de onde vieram                            |

## Notas

O índice é construído na primeira utilização, não no carregamento da página: um
leitor que nunca pesquisa nunca paga por ele.

O Content ordena cada coleção separadamente. Como as pontuações não são
comparáveis entre coleções, o composable intercala as listas por posição e põe
primeiro em cada ronda a fonte que está a ser lida. `labelled` preserva a
proveniência com que a interface explica essa combinação.
