## Assinatura

```ts
const { search } = useFuzzySearch(collection, {
  ignoredTags: ['table'], threshold: 0.35, minMatchCharLength: 3, limit: 20
});
```

## Devolve

Uma função de pesquisa que pontua as aproximações.

## Notas

Só corre quando a pesquisa exata não devolve nada, e a interface di-lo — um
leitor que escreveu mal deve receber a página, mas também deve ser informado de
que foi isso que aconteceu.

`collection` usa `docs` por omissão. `ignoredTags` segue para as secções de
pesquisa Content; limiar e comprimento mínimo ajustam o Fuse e `limit` limita os
resultados. Os valores do site ficam em `duxt.search.fuzzy`.
