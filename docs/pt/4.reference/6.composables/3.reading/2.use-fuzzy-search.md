## Assinatura

```ts
const { search } = useFuzzySearch(items);
```

## Devolve

Uma função de pesquisa que pontua as aproximações.

## Notas

Só corre quando a pesquisa exata não devolve nada, e a interface di-lo — um
leitor que escreveu mal deve receber a página, mas também deve ser informado de
que foi isso que aconteceu.
