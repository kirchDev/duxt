---
title: useRecentPages()
description: As páginas abertas mais recentemente, até ao limite configurado.
icon: lucide:history
---

## Assinatura

```ts
const { recent, remember, load } = useRecentPages(limit);
```

## Notas

Guardado no navegador, não num cookie: nunca é preciso durante a renderização no
servidor, por isso não viaja com pedido nenhum.

O limite é cinco por omissão. A pesquisa usa `duxt.search.recentPages`; `0`
oculta a lista e não guarda páginas novas.
