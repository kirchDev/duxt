O inverso de [`useDuxtPath()`](/reference/composables/paths-and-versions/use-duxt-path).

## Assinatura

```ts
const localeLink = useDuxtLink();

localeLink('/getting-started');
```

## Devolve

Uma função que volta a pôr o prefixo de locale num caminho de documentação e
deixa em paz um URL absoluto.

## Notas

Usa-a em todos os `to` que um componente substituído desenhe. Um caminho escrito
à mão num componente está certo num idioma e errado nos outros seis.
