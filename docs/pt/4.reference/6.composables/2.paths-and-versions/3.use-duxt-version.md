## Assinatura

```ts
const version = useDuxtVersion();
```

## Devolve

| Valor           | O que responde                                     |
| :-------------- | :------------------------------------------------- |
| `sources`       | Todas as versões do repositório que está a ser lido |
| `current`       | A versão a que esta página pertence                 |
| `preferred`     | A versão em que o leitor devia estar                |
| `isPreferred`   | Se as duas são a mesma                              |
| `status`        | O seu ciclo de vida — upcoming, current, eol …      |
| `kind`          | Ramo ou tag                                         |
| `shouldIndex`   | Se a página pede para ser indexada                  |
| `shouldWarn`    | Se o aviso é mostrado                               |
| `preferredPath` | Esta mesma página, na versão preferida              |

## Notas

Três perguntas num só sítio — o que o seletor mostra, o que o aviso diz, e se a
página pede para ser indexada — porque são a mesma pergunta sobre a mesma
versão.
