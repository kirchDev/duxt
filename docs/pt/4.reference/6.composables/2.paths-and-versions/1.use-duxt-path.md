## Assinatura

```ts
const path = useDuxtPath();
```

## Devolve

O caminho da rota atual sem o segmento de locale — o caminho tal como a
documentação o conhece.

## Notas

Tudo o que raciocina sobre páginas raciocina sobre isto, e não sobre
`route.path`: `/de/duxt/getting-started` e `/duxt/getting-started` são a mesma
página.
