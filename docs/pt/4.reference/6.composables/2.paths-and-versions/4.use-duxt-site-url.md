## Assinatura

```ts
const { origin, absolute } = useDuxtSiteUrl();
```

## Devolve

| Valor      | Tipo       | O que é                                       |
| :--------- | :--------- | :-------------------------------------------- |
| `origin`   | `string`   | A origem configurada do site                  |
| `absolute` | `function` | Um caminho, tornado absoluto em relação a ela |

## Notas

Necessário sempre que um URL sai da página — um item de feed, uma etiqueta
canónica, uma imagem OG. Dentro da página, usa um caminho.
