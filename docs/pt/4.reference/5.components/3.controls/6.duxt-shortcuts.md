A sobreposição que lista todas as teclas que o tema associa, aberta com
<kbd>?</kbd>.

## Utilização

```vue
<DuxtShortcuts />
```

## API

Sem props.

## Notas

A sua lista é `duxtShortcuts` — o mesmo array com que os handlers fazem a
correspondência — por isso a folha não pode acabar a anunciar uma tecla que nada
associa. Ver
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).
