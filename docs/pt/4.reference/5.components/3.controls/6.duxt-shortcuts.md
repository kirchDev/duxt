A sobreposição que lista todas as teclas que o tema associa, aberta com
<kbd>?</kbd> ou com
[`DuxtShortcutsTrigger`](/reference/components/controls/duxt-shortcuts-trigger),
o botão de teclado do cabeçalho.

## Utilização

```vue
<DuxtShortcuts />
```

## API

Sem props.

## Notas

A sua lista é `duxtShortcuts` — o mesmo array com que os handlers fazem a
correspondência — por isso a folha não pode acabar a anunciar uma tecla que nada
associa. Ver
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).

O seu estado de abertura é `useDuxtShortcutSheet()` e não um `ref` próprio,
porque o gatilho tem de alcançar o mesmo booleano — e num sítio com
`shortcuts.singleCharacter: false` o gatilho é a única coisa que a consegue
abrir, já que não resta associação de `?`. Monta-a uma vez por layout; uma
segunda instância seria um segundo diálogo a responder à mesma tecla. Ver
[Atalhos de teclado](/concepts/keyboard-shortcuts).
