«Saltar para o conteúdo», invisível até receber foco.

## Utilização

```vue
<DuxtSkipLink />
```

## API

Sem props.

## Notas

Sem ela, cada mudança de página significa passar com o tabulador pelo cabeçalho,
pela linha de secções e por toda a barra lateral antes da primeira palavra do
texto. O `sr-only` reduz a ligação a um único píxel, e o estado de foco
devolve-a ao ecrã por cima de tudo o resto.

O clique é tratado em vez de ficar entregue ao hash, porque o foco só é movido
por uma ligação com hash em alguns navegadores — o handler move-o em todos.
