O campo de pesquisa e a sua caixa de diálogo, aberta pelo botão ou por
<kbd>⌘K</kbd>.

## Utilização

```vue
<DuxtSearch />
```

## API

Sem props. Assenta em
[`useDuxtSearch()`](/reference/composables/reading/use-duxt-search).

## Notas

Os resultados abrangem todas as fontes e são ordenados em conjunto, por isso um
termo que apareça em dois repositórios é respondido a partir de ambos. Quando
nada corresponde exatamente, a lista recai nas aproximações de
[`useFuzzySearch()`](/reference/composables/reading/use-fuzzy-search) e di-lo —
uma gralha deve devolver a página, não uma caixa vazia.
