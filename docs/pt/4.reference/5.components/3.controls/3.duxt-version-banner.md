Mostrada por cima da página quando a versão que está a ser lida não é a
predefinida.

## Utilização

```vue
<DuxtVersionBanner />
```

## API

Sem props. Lê
[`useDuxtVersion()`](/reference/composables/paths-and-versions/use-duxt-version).

## Notas

A metade visível do problema das versões. `canonical` e `noindex` dizem a um
rastreador que versão servir; ao leitor não dizem nada. Quem chegou à v0.7.0 a
partir de um resultado de pesquisa, ou de uma ligação num issue antigo, vê
documentação com exatamente o mesmo aspeto da atual. Qualquer uma das metades
sozinha deixa um público enganado, por isso as etiquetas do `head` e este aviso
são entregues juntos.

A uma versão `upcoming` diz-se que a sua documentação ainda pode mudar, e
**não** se lhe diz para atualizar — esse é o único estado que nunca pode ser
alcançado por adivinhação.
