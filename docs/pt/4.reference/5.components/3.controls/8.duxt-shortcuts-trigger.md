O ícone de teclado ao lado da pesquisa. Abre
[`DuxtShortcuts`](/reference/components/controls/duxt-shortcuts), a mesma folha
que <kbd>?</kbd> abre.

## Utilização

```vue
<DuxtShortcutsTrigger />
```

## API

Sem props.

## Notas

`?` abre a lista de teclas, e só a consegue premir quem já sabe que a lista
existe. É esse círculo que este botão quebra, pelo que é desenhado no cabeçalho
em qualquer largura em vez de receber uma classe responsiva própria.

É também a única entrada para a folha num sítio com
`shortcuts.singleCharacter: false`, onde não resta associação nenhuma de `?` —
retira-o de um cabeçalho substituído e a folha fica inalcançável. Desenha a tecla
que duplica através de `hint('help')`, pelo que nada diz sobre `?` num sítio que
a desvinculou. Ver [Atalhos de teclado](/concepts/keyboard-shortcuts).
