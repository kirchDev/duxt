title: DuxtLocale
description: O seletor de idioma.
icon: lucide:languages
---

Absolutamente nada quando o site serve um idioma, um menu pendente quando serve
vários.

## Utilização

```vue
<DuxtLocale />
```

## API

Sem props. Lê `locales`.

## Notas

Construído como o [`DuxtVersion`](/reference/components/controls/duxt-version)
ao seu lado, para que quem a consome com um só locale nunca veja que o duxt fala
sete idiomas.

Usa `switchLocalePath` em vez de uma ligação para a raiz do locale: mudar de
idioma numa página sobre implementação deve chegar a essa mesma página no novo
idioma, e não atirar o leitor de volta para a porta de entrada.
