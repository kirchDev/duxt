A barra no topo de todas as páginas — o título do site, as entradas de
navegação, a pesquisa, os seletores de versão e de locale, e o alternador de
tema.

## Utilização

```vue
<DuxtHeader />
```

## API

Sem props. Tudo vem da configuração: `title`, `navigation`, `links`, `version` e
`locales`.

## Notas

Uma entrada sem `to` nem `children` significa «a documentação». A entrada «Docs»
da própria camada vem sem `to` de propósito: onde vive a documentação depende
dos prefixos de quem a consome, e isso a camada não pode saber. Resolve para a
primeira secção, e é isso que faz a barra de navegação por omissão funcionar
tanto num site com versões como num site plano.
