As duas ligações no fim de uma página.

## Utilização

```vue
<DuxtPageNav :path="path" />
```

## API

### Props

| Prop   | Tipo     | Notas                                                |
| :----- | :------- | :--------------------------------------------------- |
| `path` | `string` | Obrigatório — o caminho da documentação, sem prefixo |

## Notas

Para na fronteira da secção de propósito: passar para outra parte da
documentação é trabalho da linha das secções, não de uma ligação que diz
«seguinte».

Os grupos são achatados nos seus filhos, por isso «seguinte» é a página que um
leitor leria a seguir, e não a pasta seguinte.
