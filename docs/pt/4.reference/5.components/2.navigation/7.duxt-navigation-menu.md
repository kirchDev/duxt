title: DuxtNavigationMenu

O que abre a partir de uma entrada com `children`: um menu pendente tão aninhado
quanto os dados ou um painel de megamenu. A fila desenha o seu próprio acionador
no slot, porque as duas filas não são iguais.

## Utilização

```vue
<DuxtNavigationMenu :link="entry" align="start">
  <button type="button">{{ entry.label }}</button>
</DuxtNavigationMenu>
```

## API

### Props

| Nome | Tipo | Predefinição | Descrição |
| :-- | :-- | :-- | :-- |
| `link` | `DuxtLink` | | A entrada a que este menu pertence |
| `align` | `start` \| `center` \| `end` | `center` | Como um menu pendente se alinha com o acionador. Um megamenu é sempre centrado na página |

### Slot

`default`: O acionador, como um único elemento.

## Notas

Como configurar um menu está em [Criar menus da
barra](/guides/build-navbar-menus). Para mudar o estilo de todas as entradas de
uma vez, substitua `DuxtNavigationMenuEntry`, que desenha o conteúdo de uma
entrada; `component` na ligação faz o mesmo para uma só.
