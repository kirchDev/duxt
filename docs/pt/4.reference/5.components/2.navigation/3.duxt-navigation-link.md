Uma única entrada, com o seu ícone, o seu estado ativo e — se for um ramo — os
seus filhos.

## Utilização

```vue
<DuxtNavigationLink :item="item" />
```

## API

### Props

| Prop   | Tipo                    | Notas                         |
| :----- | :---------------------- | :---------------------------- |
| `item` | `ContentNavigationItem` | Obrigatório — um nó da árvore |

## Notas

Vale a pena substituir por si só quando só o aspeto de uma entrada está errado:
sombreá-lo deixa a árvore, o estado ativo e o recolher a cargo de
[`DuxtNavigation`](/reference/components/navigation/duxt-navigation).
