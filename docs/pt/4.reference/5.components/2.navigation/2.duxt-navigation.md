A lista aninhada de páginas da secção atual.

## Utilização

```vue
<script setup lang="ts">
const { data: navigation } = await useDuxtNavigation();
const { items } = useDuxtSection(navigation);
</script>

<template>
  <DuxtNavigation :items="items" />
</template>
```

## API

### Props

| Prop    | Tipo                       | Notas                                       |
| :------ | :------------------------- | :------------------------------------------ |
| `items` | `ContentNavigationItem[]`  | Obrigatório — um ramo da árvore do Content   |

## Notas

A árvore vem de [`useDuxtNavigation()`](/reference/composables/config-and-content/use-duxt-navigation),
que pergunta à coleção que serve a rota atual — por isso um site versionado
obtém a árvore dessa versão, e não a da versão por omissão.
