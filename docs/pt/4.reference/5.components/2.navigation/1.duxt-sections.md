A linha de secções por baixo do cabeçalho, apenas nas páginas de documentação.

## Utilização

```vue
<DuxtSections />
```

## API

Sem props. Lê `sections`; não apresenta nada quando essa lista está vazia.

## Notas

Fica com a documentação em vez de ficar no cabeçalho global, porque a página de
entrada não tem secções para mostrar.

Uma secção raramente é a própria página — é o ramo em que a página está. Por
isso a correspondência exata anuncia `aria-current="page"` e um ascendente
anuncia `true`, que é a distinção para a qual `aria-current` existe.
