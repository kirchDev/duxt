Os cabeçalhos da página atual, acompanhando o leitor à medida que este desloca
a página, mais as ligações de `aside` configuradas por baixo.

## Utilização

```vue
<DuxtToc :links="page?.body?.toc?.links ?? []" />
```

## API

### Props

| Prop    | Tipo        | Notas                                             |
| :------ | :---------- | :------------------------------------------------ |
| `links` | `TocLink[]` | Obrigatório — as ligações de toc do próprio Content |

## Notas

Qual é o cabeçalho atual vem de
[`useActiveHeading()`](/reference/composables/reading/use-active-heading), que
observa os cabeçalhos em vez do deslocamento — uma última secção curta continua
a ser dada como alcançada.

O bloco `aside.links` por baixo dele é entregue **vazio**: uma ligação para um
repositório, um gestor de issues ou uma comunidade pertencem a quem gere o site.
