A secção, e depois quaisquer grupos entre ela e a página.

## Utilização

```vue
<DuxtBreadcrumb :path="path" />
```

## API

### Props

| Prop   | Tipo     | Notas                                                |
| :----- | :------- | :--------------------------------------------------- |
| `path` | `string` | Obrigatório — o caminho da documentação, sem prefixo |

## Notas

`breadcrumb: false` na configuração retira-o em todo o site: uma árvore de
documentação plana ganha um trilho que só repete o nome da sua própria secção.
