Guarda o primeiro nível do painel no seu slot e desenha cada menu aberto a
partir dele como um nível por cima, para que um menu de qualquer profundidade
mantenha toda a largura do painel.

## Utilização

```vue
<DuxtSheetDrill ref="levels">
  <!-- O primeiro nível -->
</DuxtSheetDrill>
```

## API

### Slot

`default`: O primeiro nível.

### Exposto

| Nome | Tipo | Descrição |
| :-- | :-- | :-- |
| `drill` | `(link: DuxtLink, event: Event) => void` | Abre o menu de `link` como um novo nível. Ao voltar, o foco regressa ao elemento de onde veio `event` |

## Notas

`DuxtHeader` desenha-o dentro do painel e `DuxtSheetLinks` desenha as ligações
de um nível. No nível de um megamenu, uma coluna não é mais um nível: fica sob o
seu nome, como no painel. Os níveis desaparecem quando o painel fecha, por isso
volta sempre a abrir no primeiro.
