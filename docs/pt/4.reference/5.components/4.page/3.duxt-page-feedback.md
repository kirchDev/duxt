O bloco no fim de todas as páginas.

## Utilização

```vue
<DuxtPageFeedback @feedback="(helpful) => track(helpful)" />
```

## API

### Emits

| Evento     | Carga útil          | Quando             |
| :--------- | :------------------ | :----------------- |
| `feedback` | `helpful: boolean`  | O leitor responde  |

### Slots

| Slot      | Props                  | O que substitui         |
| :-------- | :--------------------- | :---------------------- |
| `default` | `{ answered, answer }` | A pergunta e os botões  |

## Notas

Um slot com um evento e sem backend, e é esse o desenho todo. A camada não
guarda nada e não envia nada: não lhe compete saber onde vive a analítica de
quem a consome, e um tema de documentação que telefona para casa por omissão não
é um tema para publicar. A resposta vive no estado do próprio componente durante
a visita e em mais lado nenhum — uma mudança de rota repõe-na, porque uma página
nova é uma pergunta nova.

Fazer a ligação é um guia por si só:
[Recolher opiniões da página](/guides/collect-page-feedback).
