A moldura em que cada bloco é desenhado: nome do ficheiro, ícone da linguagem,
botão de copiar.

## Utilização

Chamado pelo [`ProsePre`](/reference/mdc-components/prose/prose-pre) e não à mão,
mas utilizável diretamente:

```vue
<DuxtCodeBlock code="pnpm add -D @kirchdev/duxt" language="bash" />
```

## API

### Props

| Prop       | Tipo     | Notas                                                     |
| :--------- | :------- | :-------------------------------------------------------- |
| `code`     | `string` | Código-fonte em bruto, para o botão de copiar e como corpo |
| `language` | `string` | Escolhe o ícone                                            |
| `filename` | `string` | O rótulo no cabeçalho                                      |

### Slots

| Slot      | O que leva dentro                |
| :-------- | :------------------------------- |
| `default` | Marcação realçada, quando existe |

## Notas

Sem nome de ficheiro, o botão de copiar flutua no canto e aparece ao passar o
rato; com um, fica no cabeçalho, onde está sempre visível. Um bloco que mostra
sempre um botão no canto da página é mais ruidoso do que um que o mostra quando
um leitor o vai procurar.
