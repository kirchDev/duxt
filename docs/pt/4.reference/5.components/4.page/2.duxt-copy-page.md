Um controlo dividido ao lado do título da página: copiar o Markdown, vê-lo, ou
abri-lo num modelo de chat.

## Utilização

```vue
<DuxtCopyPage :path="path" :title="page?.title" :rawbody="page?.rawbody" />
```

## API

### Props

| Prop      | Tipo     | Notas                                           |
| :-------- | :------- | :---------------------------------------------- |
| `path`    | `string` | Obrigatório — o caminho da documentação          |
| `title`   | `string` | Usado no prompt entregue a um modelo             |
| `rawbody` | `string` | O código-fonte Markdown, para o botão de copiar  |

## Notas

Um controlo dividido em vez de quatro botões — o caso comum é «copiar», e os
outros três são a mesma intenção por outra porta.

O que todos entregam é o **Markdown**, não a página apresentada: um modelo a
quem se dá HTML tem de desfazer um layout para encontrar um cabeçalho, e um a
quem se dá a fonte lê o que o autor escreveu. O frontmatter é removido, por isso
o que se copia lê-se como a página e não como o ficheiro.

As ligações externas precisam de um URL absoluto, e a origem é lida do browser
no momento do clique em vez de vir da configuração — o único valor que é
seguramente correto, incluindo num deployment de pré-visualização cujo domínio
ninguém anotou.
