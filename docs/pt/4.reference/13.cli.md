Cada comando responde a `--help` com as suas opções, mesmo num site que nunca foi
compilado. Essa saída é a lista de referência, por isso esta página apenas diz para
que serve cada comando.

| Comando             | Para que serve                                                            | Explicado em                                                 |
| :------------------ | :------------------------------------------------------------------------ | :----------------------------------------------------------- |
| `duxt report`       | Imprime fontes, verificações e redirecionamentos em Markdown, ou como dados com `--json` | [O que a compilação verifica](/concepts/build-checks) |
| `duxt content pack` | Constrói um bundle de conteúdo imutável sem compilar a aplicação          | [Empacotar bundles de conteúdo](/guides/pack-content-bundles) |
| `duxt-cache-key`    | Imprime a chave de cache e os caminhos das fontes remotas do Content      | [Guardar fontes remotas e imagens OG em cache](/guides/cache-build-work) |
| `duxt-og-cache`     | Imprime a chave de cache das imagens renderizadas, ou indica o que uma compilação reutilizou | [Guardar fontes remotas e imagens OG em cache](/guides/cache-build-work) |

Executa-os através do teu gestor de pacotes, por exemplo `pnpm exec duxt report`.
`duxt report` precisa de um site preparado ou compilado, porque lê os metadados das
camadas que esse passo regista.
