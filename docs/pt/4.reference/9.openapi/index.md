Aponta uma fonte para um documento OpenAPI e o duxt constrói uma referência a
partir dele — uma visão geral, uma página por etiqueta, uma página por operação —
com um cliente em cada página de operação que envia o pedido do próprio navegador
do leitor.

As páginas são uma coleção comum, e é esse o ponto: a pesquisa encontra-as, o
`llms.txt` lista-as, o sitemap leva-as, o selector de versões move-se entre elas.
Nada aqui é um segundo caminho de renderização.
