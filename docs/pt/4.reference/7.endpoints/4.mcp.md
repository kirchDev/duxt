Um endpoint Model Context Protocol, para que um agente possa consultar a
documentação em vez de lhe fazer scraping.

## Ferramentas

| Ferramenta    | O que faz                             |
| :------------ | :------------------------------------ |
| `list_pages`  | O índice de conteúdos                 |
| `search_docs` | Encontra uma página por termo         |
| `read_page`   | O texto completo de uma página        |

## Notas

As mesmas coleções das páginas, por isso as respostas não podem divergir do que
está publicado. O nome, a descrição e as instruções do servidor vêm das opções do
módulo.
