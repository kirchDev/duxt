Acrescenta `.md` a qualquer URL da documentação e a resposta é o Markdown a
partir do qual essa página foi apresentada.

```
/duxt/getting-started      → a página
/duxt/getting-started.md   → o seu código-fonte
```

## Notas

É um **middleware, não uma rota**, porque `.md` é um sufixo do último segmento e
não um segmento próprio — nenhum ficheiro de rota o consegue corresponder.

É isto que o [`DuxtCopyPage`](/reference/components/page/duxt-copy-page) entrega
a um modelo: o código-fonte, não a página apresentada.
