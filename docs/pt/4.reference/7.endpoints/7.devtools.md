::callout{type="danger" title="Nunca registado numa compilação"}
O painel expõe a configuração resolvida, os caminhos de ficheiros por trás dela e
um botão que apaga um directório de cache. Nada disso é da conta de ninguém em
produção, e é por isso que o módulo retorna antes de registar seja o que for fora
de um servidor de desenvolvimento.
::

## Resposta

`text/html`, um documento por painel: `/_duxt/devtools` é o painel Sources e cada
um dos outros pende dele — `/_duxt/devtools/paths`, `/_duxt/devtools/pages` e assim
por diante, pela ordem da linha de separadores.

São os mesmos documentos que as Nuxt Devtools enquadram no separador **duxt**, por
isso a rota existe para ser aberta numa janela própria — uma tabela larga lê-se
melhor fora de uma gaveta.

## Notas

Aquilo a que cada painel responde, com cada painel mostrado tal como se vê, é uma
secção própria: [Devtools](/reference/devtools).
