Vários blocos de código apresentados como um só bloco, com um separador cada. O
rótulo de cada separador é o nome de ficheiro do próprio bloco, porque é entre
isso que o leitor está a escolher e já está escrito.

## API

Sem props. Um bloco sem nome de ficheiro fica com a sua linguagem como rótulo.

### Slots

| Slot      | O que leva dentro                 |
| :-------- | :-------------------------------- |
| `default` | Uma sequência de blocos de código |

## Notas

Os filhos são lidos a partir dos VNodes do slot `default` em vez de serem
registados por um componente filho: um bloco de código é um `ProsePre`, não algo
a quem este bloco possa pedir que se anuncie, e o seu nome de ficheiro é uma
prop nesse nó.

Para tudo o que não seja código, usa
[Grupo de separadores](/reference/mdc-components/tab-group).
