`::tab-group` à volta de blocos [`::tab`](/reference/mdc-components/tab) — um
painel por separador, navegável pelo teclado.

## Utilização

::preview
::::tab-group
:::tab{label="macOS"}
Tudo o que a camada precisa vem com o Node.
:::

:::tab{label="Windows"}
O mesmo, e nada na compilação é específico da plataforma.
:::
::::

#code
```mdc
:::tab-group
  ::tab{label="macOS"}
  Tudo o que a camada precisa vem com o Node.
  ::

  ::tab{label="Windows"}
  O mesmo, e nada na compilação é específico da plataforma.
  ::
:::
```
::

## API

Sem props. Os rótulos vêm dos filhos.

### Slots

| Slot      | O que leva dentro |
| :-------- | :---------------- |
| `default` | Blocos `::tab`    |

## Notas

**Não `::tabs`.** O kit de UI do tema já regista um `Tabs` — o do shadcn — e dois
componentes com o mesmo nome não são uma substituição que a compilação resolva a
teu favor: o Nuxt fica com um deles, e ficou com o do shadcn, por isso `::tabs`
renderizava uma primitiva sem gatilhos e sem estado. Um componente de conteúdo
não pode tomar um nome que o kit de UI possui.

Assente nas primitivas do reka-ui e não no invólucro do shadcn, porque os rótulos
só são conhecidos depois de os filhos se registarem: o MDC entrega-os como
conteúdo de slot, não como prop. A navegação por teclado, o foco itinerante e os
papéis ARIA vêm com elas.
