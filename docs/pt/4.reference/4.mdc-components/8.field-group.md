---
title: Grupo de campos
description: Uma lista de campos como um só bloco.
icon: lucide:list-tree
---

Agrupa blocos [`::field`](/reference/mdc-components/field) para que se leiam como
uma só lista com separadores em vez de cartões soltos.

## Utilização

::preview
::::field-group
:::field{name="path" type="string" required}
Pasta com o Markdown, relativa à raiz do repositório.
:::

:::field{name="history" type="boolean" default="false"}
Lê o histórico git desta fonte para a «Última atualização» e os contribuidores.
:::
::::

#code
```mdc
:::field-group
  ::field{name="path" type="string" required}
  Pasta com o Markdown, relativa à raiz do repositório.
  ::
:::
```
::

## API

Sem props.

### Slots

| Slot      | O que leva dentro |
| :-------- | :---------------- |
| `default` | Blocos `::field`  |
