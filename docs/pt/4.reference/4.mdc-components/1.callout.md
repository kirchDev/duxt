Um aparte numa de quatro variantes. O corpo é Markdown, por isso ligações,
`code` e listas funcionam todos lá dentro.

## Tipos

::preview
:::callout{type="info"}
`info` — o predefinido, para contexto que a página pressupõe.
:::

:::callout{type="tip"}
`tip` — algo que torna a tarefa mais fácil.
:::

:::callout{type="warning"}
`warning` — uma forma de fazer isto mal.
:::

:::callout{type="danger"}
`danger` — perda de dados, ou uma alteração que não pode ser desfeita.
:::

#code
```mdc
::callout{type="info"}
`info` — o predefinido, para contexto que a página pressupõe.
```

## API

### Props

| Prop    | Tipo                                  | Por omissão | Notas                                        |
| :------ | :------------------------------------ | :---------- | :------------------------------------------- |
| `type`  | `info` · `tip` · `warning` · `danger` | `info`      | Escolhe a cor, o ícone e o papel             |
| `title` | `string`                              | —           | Primeira linha a negrito; o corpo segue-se   |
| `icon`  | `string`                              | por tipo    | Qualquer nome Iconify, substituindo o predefinido |

### Slots

| Slot      | O que leva dentro    |
| :-------- | :------------------- |
| `default` | O corpo, em Markdown |

## Notas

Um callout `danger` transporta `role="alert"`; os outros não. Um alerta
interrompe um leitor de ecrã a meio de uma frase, o que é certo para «isto apaga
os teus dados» e errado para uma dica.
