## Notas

Assenta no modelo de versões em vez de o repetir: o que o distintivo diz é a
versão em que algo APARECEU, o que é um facto sobre a API e não sobre a página
onde está documentado — por isso mantém-se correto em todas as versões da
documentação que transportem a frase.

Para tudo o resto, `:badge[…]` chama diretamente o Badge do próprio tema; o MDC
resolve pelo nome qualquer componente registado globalmente.
