Os filhos de uma secção, desenhados como cartões com o seu ícone, título e
descrição — aquilo com que termina cada `index.md` desta documentação.

## Utilização

```mdc
::page-cards
::
```

Sem prop, lista os filhos da página atual, e é por isso que aqui aparece pelo
nome em vez de apresentado: esta página não tem nenhum.

## API

### Props

| Prop   | Tipo     | Por omissão    | Notas                            |
| :----- | :------- | :------------- | :------------------------------- |
| `path` | `string` | a página atual | Listar os filhos de outra secção |

## Notas

O título, a descrição e o ícone vêm do frontmatter de cada filho, por isso um
cartão não pode divergir da página para que aponta.
