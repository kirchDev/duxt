Uma secção dentro de [`::accordion`](/reference/mdc-components/accordion).

## Utilização

```mdc
:::accordion
  ::accordion-item{label="Porquê uma camada e não um módulo?" icon="lucide:layers"}
  Um módulo não pode trazer páginas, um tema ou um valor por omissão em app.config.
  ::
:::
```

## API

### Props

| Prop    | Tipo     | Por omissão | Notas                                  |
| :------ | :------- | :---------- | :------------------------------------- |
| `label` | `string` | —           | O texto do gatilho                     |
| `icon`  | `string` | —           | Qualquer nome Iconify, antes do rótulo |

### Slots

| Slot      | O que leva dentro       |
| :-------- | :---------------------- |
| `default` | A resposta, em Markdown |
