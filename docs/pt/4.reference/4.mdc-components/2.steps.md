Envolve uma **lista ordenada** num layout de passos. Numera a lista que
envolver, seja ela qual for, por isso o Markdown continua a ser uma lista
vulgar.

## API

Sem props. O bloco estiliza o seu `<ol>` filho.

### Slots

| Slot      | O que leva dentro                     |
| :-------- | :------------------------------------ |
| `default` | Uma lista ordenada, itens em Markdown |

## Notas

Vale a pena recorrer a ele assim que um passo transporta um bloco de código:
numa lista ordenada simples o bloco afasta o texto do seu próprio número, e este
layout mantém o número preso ao lado dele.

Os marcadores são um contador CSS nos itens da lista, não conteúdo — um leitor
que copie os passos fica com o texto sem a numeração desenhada duas vezes.
