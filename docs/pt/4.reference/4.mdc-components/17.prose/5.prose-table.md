Todas as tabelas de Markdown.

## O que acrescenta

Um contentor com deslocamento à volta da tabela, para que uma tabela larga se
desloque dentro da sua própria caixa em vez de fazer a página inteira
deslocar-se para o lado.

## API

### Slots

| Slot      | O que leva dentro |
| :-------- | :---------------- |
| `default` | A tabela          |
