Todas as ligações de uma página Markdown passam por este componente.

## O que acrescenta

Um caminho da documentação é reescrito para levar o prefixo da fonte de onde a
página veio, mais o locale do leitor. Um URL externo fica intocado e recebe o
separador novo e a seta.

## Porquê

O Markdown não faz ideia de que está a ser servido sob um prefixo.
`/getting-started` escrito no `docs/` deste repositório está correto num site com
uma fonte e é um 404 num site com duas, onde a mesma página vive em
`/duxt/getting-started` — e quem escreveu o Markdown, que pode estar num
repositório completamente diferente, não tem como saber qual.

Pior, o mesmo ficheiro é servido em vários prefixos ao mesmo tempo quando é
publicado em mais do que uma versão: uma ligação não pode ser reescrita em tempo
de compilação, porque não há uma única resposta certa. É antes resolvida a cada
apresentação, em função da fonte a partir da qual a página está a ser lida — para
que uma ligação dentro de `v0.7.0` mantenha o leitor em `v0.7.0`.

## API

### Props

| Prop     | Tipo      | Notas                                    |
| :------- | :-------- | :--------------------------------------- |
| `href`   | `string`  | Tal como escrito no Markdown             |
| `target` | `string`  | Definido para uma ligação externa        |
