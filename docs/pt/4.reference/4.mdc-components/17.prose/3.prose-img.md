Todas as imagens de uma página Markdown.

## O que acrescenta

**Duas variantes.** A captura de um editor escuro numa página branca — ou o
contrário — é a coisa feia mais comum na documentação, e o CSS não a resolve
porque o que está errado são os píxeis, não a moldura. Uma página pode nomear um
segundo ficheiro:

```md
![A barra lateral](/shots/sidebar.png){dark="/shots/sidebar-dark.png"}
```

**Clicar para ampliar**, a não ser que a imagem peça o contrário:

```md
![Um diagrama](/diagram.svg){zoom="false"}
```

## API

### Props

| Prop   | Tipo      | Por omissão | Notas                                          |
| :----- | :-------- | :---------- | :--------------------------------------------- |
| `src`  | `string`  | —           | Tal como escrito                               |
| `alt`  | `string`  | —           | Tal como escrito                               |
| `dark` | `string`  | —           | Um segundo ficheiro, servido sob o tema escuro |
| `zoom` | `boolean` | `true`      | `false` deixa a imagem inerte                  |

## Notas

A variante escura é nomeada explicitamente em vez de adivinhada por convenção.
Derivar `-dark` de um nome de ficheiro faz com que um ficheiro em falta se torne
uma imagem partida, e quem a escreveu nunca chega a saber.
