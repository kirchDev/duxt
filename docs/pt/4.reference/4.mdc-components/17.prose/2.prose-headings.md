Três componentes, um comportamento: `ProseH2`, `ProseH3` e `ProseH4` apresentam
os cabeçalhos a partir dos quais se constrói o índice de uma página.

## O que acrescentam

Uma âncora permanente ao lado do cabeçalho, visível ao passar o rato e alcançável
pelo teclado. O `id` é o próprio slug do Content, por isso a âncora, o índice e a
navegação dentro da página concordam todos.

## API

### Props

| Prop | Tipo     | Notas                                   |
| :--- | :------- | :-------------------------------------- |
| `id` | `string` | O slug que o Content gerou para o texto |

### Slots

| Slot      | O que leva dentro    |
| :-------- | :------------------- |
| `default` | O texto do cabeçalho |

## Notas

`ProseH1` não é substituído de propósito: o título da página é apresentado pela
página, não pelo Markdown, por isso um cabeçalho `#` de Markdown dentro do corpo
seria um segundo `h1` na página.
