Um comando apresentado para cada gestor de pacotes que o site oferece, com a
escolha do leitor memorizada para todo o site.

## Utilização

Escreve o comando **sem** o gestor: o `install` do npm e a grafia de `dlx` de
cada gestor são substituídos.

::preview
:::package-managers{command="add -D @kirchdev/duxt"}
:::

## API

### Props

| Prop       | Tipo       | Por omissão            | Notas                                    |
| :--------- | :--------- | :--------------------- | :--------------------------------------- |
| `command`  | `string`   | obrigatório            | Sem o gestor — `add -D pkg`              |
| `managers` | `string[]` | `duxt.packageManagers` | Substitui a lista do site para um bloco  |

## Notas

A escolha é um cookie, não armazenamento do navegador, e deliberadamente: o
armazenamento é lido depois da hidratação, por isso o bloco desenharia um gestor
e depois trocaria para outro à frente do leitor. É próprio do site, não
identifica ninguém e transporta um valor que o leitor escolheu — ver
[`usePackageManager()`](/reference/composables/reading/use-package-manager).

Um bloco pode listar menos gestores do que a escolha do leitor abrange; recai no
seu próprio primeiro separador em vez de não mostrar nada.
