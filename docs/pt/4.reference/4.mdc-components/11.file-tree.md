Uma listagem de diretórios em árvore, com o ícone de cada tipo de ficheiro lido
a partir da sua extensão.

## Utilização

::preview
:::file-tree{title="o-teu-projeto/"}
---
tree:
  - name: docs/
    children:
      - name: index.md
      - name: 1.getting-started/
        children:
          - name: index.md
          - name: 1.installation.md
  - name: app/
    children:
      - name: app.config.ts
  - name: nuxt.config.ts
---
:::

## API

### Props

| Prop    | Tipo      | Por omissão | Notas                              |
| :------ | :-------- | :---------- | :--------------------------------- |
| `tree`  | `Entry[]` | —           | Dado como YAML no corpo do bloco   |
| `title` | `string`  | —           | O rótulo de raiz por cima da árvore |

Uma entrada é `{ name, children? }`. Um nome terminado em `/`, ou que transporte
filhos, é um diretório.

## Notas

Assenta na árvore da reka-ui, por isso tem foco itinerante, navegação com as
teclas de seta e os papéis ARIA. Os nós são indexados por caminho e não por
nome: os nomes repetem-se entre ramos, os caminhos não.
