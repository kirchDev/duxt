Um painel dentro de [`::tab-group`](/reference/mdc-components/tab-group). Não tem
significado sozinho.

## Utilização

```mdc
:::tab-group
  ::tab{label="pnpm"}
  A camada é uma dependência de desenvolvimento.
  ::
:::
```

## API

### Props

| Prop    | Tipo     | Por omissão | Notas                           |
| :------ | :------- | :---------- | :------------------------------ |
| `label` | `string` | —           | O texto no gatilho do separador |

### Slots

| Slot      | O que leva dentro     |
| :-------- | :-------------------- |
| `default` | O painel, em Markdown |

## Notas

O componente regista o seu próprio rótulo no pai durante o setup, e é isso que
permite construir a lista de gatilhos a partir de filhos que o MDC ainda não
renderizou.
