---
title: O cliente de pedidos
description: Desligado por omissão e dirigido apenas a destinos declarados públicos.
icon: lucide:send-horizontal
---

```ts
options: { tryIt: { baseUrl: 'https://api.example.com', variables: { tenant: 'demo' } } }
```

Sem `baseUrl`, a página fica estática. `/` usa a mesma origem da documentação.
`variables` é uma allowlist; se ficar uma variável desconhecida no URL, nenhum
cliente aparece. Os parâmetros de caminho continuam editáveis. Os valores vivem
apenas no estado do componente e o pedido segue diretamente do browser para a
API.
