---
title: Obter a coleção
description: O arquivo está ligado à versão e idioma visíveis; a ligação Bruno não.
icon: lucide:download
---

O resumo liga um ZIP criado na build para a versão e idioma visíveis, sem
`environments/`. Uma fonte remota descarregada pelo Content não recebe arquivo,
porque a sua localização de cache não é relida fora da coleção.

`options.fetch` acrescenta **Fetch in Bruno** para um URL git público. Não
carrega scripts de terceiros, mas clona o branch predefinido e não substitui o
arquivo versionado.
