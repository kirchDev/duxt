Uma fonte aponta para uma pasta de ficheiros `.bru` e o duxt cria um resumo,
uma página por pasta, uma por pedido e um arquivo da versão e idioma visíveis.

A referência é deliberadamente mais estreita do que
[OpenAPI](/reference/openapi): Bruno é um artefacto de cliente com pedidos,
pastas, headers, bodies, scripts e environments, sem schemas de resposta nem
componentes reutilizáveis. O duxt publica o que a coleção diz sem inventar uma
conversão para OpenAPI.
