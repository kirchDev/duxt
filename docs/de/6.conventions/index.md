Regeln, an die sich dieses Projekt hält, aufgeschrieben, weil der Code sie nicht
aussprechen kann. Sie binden die Arbeit in diesem Repository; nichts hier ist eine
Einschränkung für eine Website, die die Ebene erweitert.

Eine Regel sagt, was getan wird; eine [Architekturentscheidung](/adr) sagt, warum
sie gegenüber den Alternativen gewählt wurde, und bleibt lesbar, wenn die
Begründung längst aus allen Köpfen verschwunden ist. Das Entscheidungsprotokoll
ist append-only — deshalb steht es neben den Seiten hier und nicht zwischen
ihnen: die werden bearbeitet, wenn sie sich ändern.
