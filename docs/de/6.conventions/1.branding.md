::callout{type="warning" title="Platzhalter-Artwork"}
Die Wortmarke ist KI-gestützte Platzhalterarbeit — in einer Sitzung mit einem
KI-Coding-Agenten entworfen, nicht von einer gestaltenden Person, und ein
Provisorium, das irgendwann ersetzt wird, ohne festen Zeitplan. Kein
Bildgenerator war beteiligt: sie ist gesetzt, nicht gezeichnet.
::

Die Marke ist der Paketname mit seinem ersten Buchstaben in Klammern — `[d]uxt` —
weil das Paket dort, wo es benutzt wird, genau so geschrieben steht:

```ts
extends: ['@kirchdev/duxt'];
```

Ein Array mit einem Eintrag. Gesetzt in [IBM Plex Mono](https://github.com/IBM/plex)
SemiBold und in Konturen umgewandelt, damit kein Asset davon abhängt, dass die
Schrift irgendwo installiert ist.

## Die Assets

| Asset                    | Pfad                                                        | Genutzt von                          |
| :----------------------- | :----------------------------------------------------------- | :----------------------------------- |
| Wortmarke                | `.github/assets/wordmark-light.svg`, `wordmark-dark.svg`    | Der README-Hero, über `<picture>`    |
| Website-Icons            | `www/public/favicon.svg`, `apple-touch-icon.png` (180×180)  | Der Browser-Tab                      |
| Wortmarke auf der Seite  | `www/public/wordmark.svg`, `wordmark-dark.svg`              | `duxt.logo` in `www/`                |

Die README-Wortmarke verschmälert die Klammerzellen um 120 Font-Einheiten: Plex
Mono gibt `[` eine 600 Einheiten breite Zelle für 311 Einheiten Farbe, und bei
voller Monospace-Breite sitzen die Klammern in einem Wortzwischenraum für sich.

Das Favicon trägt seine eigene `prefers-color-scheme`-Regel, damit beide Farben
gegen einen dunklen Tab-Streifen aufhellen. Das PNG existiert nur, weil iOS
SVG-Icons ignoriert.

## Die Klammern des Icons sind neu gezeichnet, das `d` nicht

Plex' Klammer ist 311 Einheiten breit gegen ein 486 Einheiten breites `d`, und bei
16 px schließt diese Aufteilung die Punze zu einem Fleck. Das Icon behält Stamm
(104) und Arm (88) der Schrift, kürzt den Arm aber auf 185 — das bringt die Marke
von 1,45∶1 auf 1,13∶1 ins Quadrat und verschafft der Punze die Pixel, die sie
braucht.

Die Wortmarke hat diese Einschränkung nicht und bleibt reines Plex. Das ist der
ganze Unterschied zwischen den beiden Dateien und der Grund, warum sie sich nicht
aus einer Quelle erzeugen lassen.

## Farben

Die Klammern tragen die Farbe; die Buchstaben nehmen die umgebende Textfarbe. Nur
das Klammerpaar steht fest.

| Rolle              | Hex       | OKLCH                    |
| :----------------- | :-------- | :----------------------- |
| Klammern (hell)    | `#4F46E5` | `oklch(0.511 0.230 277)` |
| Klammern (dunkel)  | `#7D7BF5` | `oklch(0.644 0.178 281)` |
| Buchstaben (hell)  | `#15171E` | `oklch(0.206 0.014 273)` |
| Buchstaben (dunkel)| `#E8EBF2` | `oklch(0.940 0.010 267)` |

## Lizenzierung

IBM Plex steht unter [SIL OFL 1.1](https://github.com/IBM/plex/blob/master/LICENSE.txt),
und Klausel 5 klärt diesen Fall ausdrücklich: _„The requirement for fonts to
remain under this license does not apply to any document created using the Font
Software."_ Ein SVG mit Konturen ist ein solches Dokument, es wird keine
Schriftdatei weitergegeben, und der reservierte Name „Plex" taucht in den Assets
nirgends auf. Nichts muss bezahlt, genannt oder neu lizenziert werden — die
Nennung oben ist Höflichkeit.

## Nichts davon wird ausgeliefert

::callout{type="warning" title="Die Ebene trägt keine Marke"}
`duxt.logo` ist standardmäßig nicht gesetzt, und `DuxtBrand` fällt auf den eigenen
`duxt.title` des Konsumenten neben einem generischen Icon zurück. Eine Website,
die duxt erweitert, zeigt ihren eigenen Namen in Kopf- und Fußbereich und ihr
eigenes Icon im Tab, niemals dieses. Jedes Asset oben gehört diesem Repository und
`www/` — keines liegt im veröffentlichten Paket.
::

Wie du deine eigene setzt, steht in
[Deiner Website eine Marke geben](/guides/brand-your-site).
