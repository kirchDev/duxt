---
title: Der Request-Client
description: Standardmäßig aus und nur auf ausdrücklich öffentliche Ziele gerichtet.
icon: lucide:send-horizontal
---

```ts
options: {
  tryIt: {
    baseUrl: 'https://api.example.com',
    variables: { tenant: 'demo' }
  }
}
```

Ohne `baseUrl` bleibt eine Request-Seite statisch. `/` verwendet denselben
Origin wie die Dokumentationsseite. `variables` ist eine Allowlist; bleibt eine
unbekannte Variable in der URL, erscheint kein Client. Pfadparameter bleiben
editierbar. Eingaben leben nur im Komponentenzustand und gehen vom Browser
direkt an die API — nie über den Dokumentationsserver und nie in Storage.
