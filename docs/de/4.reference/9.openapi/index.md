Richte eine Quelle auf ein OpenAPI-Dokument, und duxt baut daraus eine Referenz —
eine Übersicht, eine Seite pro Tag, eine Seite pro Operation — mit einem Client
auf jeder Operationsseite, der die Anfrage aus dem Browser des Lesers sendet.

Die Seiten sind eine gewöhnliche Collection, und genau das ist der Punkt: Die
Suche findet sie, `llms.txt` listet sie, die Sitemap trägt sie, der
Versionsumschalter bewegt sich zwischen ihnen. Nichts hier ist ein zweiter
Renderpfad.
