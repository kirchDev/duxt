---
title: useDuxtToast()
description: Benachrichtigungen, gekapselt, damit keine Komponente die Bibliothek importiert.
icon: lucide:bell
---

## Signatur

```ts
const notify = useDuxtToast();

notify.success(t('duxt.code.copiedToast'));
```

## Rückgabe

`{ success, info, warning, error, loading, dismiss }`.

## Anmerkungen

Der Wrapper ist die Nahtstelle: Ein Konsument, der ein anderes
Benachrichtigungssystem will, ersetzt dieses eine Composable statt jeder
Aufrufstelle, und die eigenen Komponenten der Ebene laufen weiter.
