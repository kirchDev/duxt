icon: lucide:heading

## Signatur

```ts
const active = useActiveHeading(ids);
```

## Rückgabe

Die id der Überschrift, bei der der Leser gerade ist.

## Anmerkungen

Es beobachtet die Überschriften statt des Scroll-Offsets, ein kurzer letzter
Abschnitt wird also trotzdem als erreicht gemeldet — das übliche Versagen eines
Inhaltsverzeichnisses, das an der Scroll-Position hängt.
