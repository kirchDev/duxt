## Signatur

```ts
const { shortcuts, keys, on } = useDuxtShortcuts();

on('help', () => open());
```

## Anmerkungen

Die eine Stelle, die weiß, welche Tasten belegt sind, damit das Overlay auf `?`
und die Handler sich nicht widersprechen können. `shortcuts` ist die Liste, die
die Richtlinie `shortcuts.singleCharacter` der Seite übrig lässt, `keys()`
zeichnet eine Belegung für die Tastatur des Lesers (`⌘` oder `Ctrl`), und `on()`
belegt eine Aktion mit allen Absicherungen, die eine globale Belegung braucht —
nie während der Leser tippt, nie in einem Dialog oder Menü, nie wenn etwas
Näheres die Taste schon behandelt hat und, bei den unbelegten Tasten, nur
solange der Seiteninhalt selbst den Fokus hält.
