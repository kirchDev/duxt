## Signatur

```ts
const shortcuts = useDuxtShortcuts();

onDuxtShortcut('k', () => open());
```

## Anmerkungen

Die eine Stelle, die weiß, welche Tasten belegt sind, damit das Overlay auf `?`
und die Handler sich nicht widersprechen können. `onDuxtShortcut()` daneben
belegt eine Taste mit den Absicherungen, die jede Belegung braucht — dazu
gehört, nie auszulösen, während der Leser tippt.
