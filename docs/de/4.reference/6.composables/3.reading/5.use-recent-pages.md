---
title: useRecentPages()
description: Die zuletzt geöffneten Seiten bis zum konfigurierten Limit.
icon: lucide:history
---

## Signatur

```ts
const { recent, remember, load } = useRecentPages(limit);
```

## Anmerkungen

Im Browser gehalten, nicht in einem Cookie: Beim Server-Rendering wird das nie
gebraucht, es reist also mit keinem Request mit.

Das Limit ist standardmäßig fünf. Der Suchdialog nutzt
`duxt.search.recentPages`; `0` blendet die Liste aus und speichert keine neuen
Seiten.
