## Signatur

```ts
const { search, init, labelled } = useDuxtSearch();
```

## Rückgabe

| Wert       | Was es ist                                                            |
| :--------- | :-------------------------------------------------------------------- |
| `search`   | Eine Anfrage ausführen, über jede Quelle                               |
| `init`     | Den Index bauen; wird aufgerufen, wenn sich der Dialog zum ersten Mal öffnet |
| `labelled` | Treffer, die die Quelle tragen, aus der sie kamen                      |

## Anmerkungen

Der Index wird bei der ersten Nutzung gebaut, nicht beim Laden der Seite: Ein
Leser, der nie sucht, zahlt nie dafür.

Content bewertet jede Collection getrennt. Weil die resultierenden Werte nicht
zwischen Collections vergleichbar sind, verschränkt das Composable die Listen
nach Position und setzt die gerade gelesene Quelle in jeder Runde zuerst.
`labelled` bewahrt die Herkunft, mit der die Oberfläche diesen Merge erklärt.
