## Signatur

```ts
const { search } = useFuzzySearch(items);
```

## Rückgabe

Eine Suchfunktion, die Beinahetreffer bewertet.

## Anmerkungen

Sie läuft nur, wenn die exakte Suche nichts zurückgibt, und die Oberfläche sagt
das auch — ein Leser, der sich vertippt hat, soll die Seite bekommen, aber auch
erfahren, dass genau das passiert ist.
