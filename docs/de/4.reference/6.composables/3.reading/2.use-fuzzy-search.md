## Signatur

```ts
const { search } = useFuzzySearch(collection, {
  ignoredTags: ['table'], threshold: 0.35, minMatchCharLength: 3, limit: 20
});
```

## Rückgabe

Eine Suchfunktion, die Beinahetreffer bewertet.

## Anmerkungen

Sie läuft nur, wenn die exakte Suche nichts zurückgibt, und die Oberfläche sagt
das auch — ein Leser, der sich vertippt hat, soll die Seite bekommen, aber auch
erfahren, dass genau das passiert ist.

`collection` ist standardmäßig `docs`. `ignoredTags` geht an Contents
Suchabschnitte; Schwelle und Mindestlänge steuern Fuse, `limit` begrenzt die
Beinahetreffer. Die Site-Defaults stehen unter `duxt.search.fuzzy`.
