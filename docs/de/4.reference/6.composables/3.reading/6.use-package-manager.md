icon: lucide:package
---

## Signatur

```ts
const manager = usePackageManager();
```

## Anmerkungen

Ein Cookie statt Browser-Speicher, und das mit Absicht: Der Speicher wird erst
nach der Hydration gelesen, ein Befehlsblock würde also einen Paketmanager
rendern und dann vor den Augen des Lesers auf einen anderen umspringen. Es ist
First-Party, identifiziert niemanden und trägt einen Wert, den der Leser
gewählt hat.
