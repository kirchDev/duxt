## Signatur

```ts
const { section, items } = useDuxtSection(navigation);
```

## Rückgabe

| Wert      | Typ      | Was es ist                                           |
| :-------- | :------- | :--------------------------------------------------- |
| `section` | `object` | Die konfigurierte Sektion, unter der die Seite liegt  |
| `items`   | `array`  | Der Ast dieser Sektion im Baum                        |

## Anmerkungen

Ohne konfigurierte `sections` kommt der ganze Baum zurück, was die richtige Form
für eine Doku ist, die nicht in Teile geteilt ist.
