## Signatur

```ts
const { data: navigation } = await useDuxtNavigation();
```

## Rückgabe

Ein `useAsyncData`-Handle über den Navigationsbaum der Collection, die die
aktuelle Route bedient.

## Anmerkungen

Pro Route zu fragen statt einmal für die ganze Site ist das, was einen
versionierten Baum richtig macht: Wer `v0.7.0` liest, bekommt die Seiten dieser
Version, nicht die der Standardversion.
