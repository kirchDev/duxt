Das, wonach man in einer ersetzten Komponente greift.

## Signatur

```ts
const duxt = useDuxtConfig();
```

## Rückgabe

Die ganze Konfiguration, reaktiv: die Standardwerte der Ebene, mit deiner
`app.config.ts` darübergelegt, und jedes Textfeld bereits eine Zeichenkette.

## Anmerkungen

Zwei Dinge passieren hier, von denen eine Komponente nie etwas wissen muss.
Nuxts eigene `app.config`-Zusammenführung **hängt** Arrays **an**, statt sie zu
ersetzen, ein Konsument, der `navigation` überschreibt, bekäme die Einträge der
Ebene also hinter seinen eigenen; diese Zusammenführung ersetzt sie. Und eine
Beschriftung darf ein Literal, ein i18n-Schlüssel oder ein Datensatz je Locale
sein — alle drei fallen zu einer Zeichenkette zusammen, ein Template trifft also
nie einen Schlüssel.

Das Ergebnis bleibt reaktiv, das Umschalten der Sprache aktualisiert die
Navigationsleiste also ohne vollständiges Neuladen der Seite.
