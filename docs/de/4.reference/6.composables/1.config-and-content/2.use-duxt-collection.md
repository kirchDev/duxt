## Signatur

```ts
const { collection, source, sources } = useDuxtCollection();
```

## Rückgabe

| Wert         | Typ      | Was es ist                                              |
| :----------- | :------- | :------------------------------------------------------ |
| `collection` | `string` | Der Name der Collection, die die aktuelle Route bedient  |
| `source`     | `object` | Die aufgelöste Quelle dahinter                           |
| `sources`    | `array`  | Jede aufgelöste Quelle                                   |

## Anmerkungen

`collection` ist eine **Zeichenkette**, kein Literaltyp — die Collection-Namen
einer Site werden aus ihren eigenen Quellen erzeugt, nichts in der Ebene kann
sie also benennen. Gib sie an `queryCollection` weiter, statt `'docs'` zu
schreiben.
