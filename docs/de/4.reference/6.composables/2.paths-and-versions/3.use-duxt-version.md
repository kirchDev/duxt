## Signatur

```ts
const version = useDuxtVersion();
```

## Rückgabe

| Wert            | Was es beantwortet                                 |
| :-------------- | :------------------------------------------------- |
| `sources`       | Jede Version des gelesenen Repositories             |
| `current`       | Die Version, zu der diese Seite gehört              |
| `preferred`     | Die Version, auf der ein Leser sein sollte          |
| `isPreferred`   | Ob die beiden dieselbe Version sind                 |
| `status`        | Ihr Lebenszyklus — upcoming, current, eol …         |
| `kind`          | Branch oder Tag                                     |
| `shouldIndex`   | Ob die Seite darum bittet, indexiert zu werden      |
| `shouldWarn`    | Ob das Banner erscheint                             |
| `preferredPath` | Dieselbe Seite, in der bevorzugten Version          |

## Anmerkungen

Drei Fragen an einer Stelle — was der Umschalter zeigt, was das Banner sagt, und
ob die Seite darum bittet, indexiert zu werden — weil sie dieselbe Frage über
dieselbe Version sind.
