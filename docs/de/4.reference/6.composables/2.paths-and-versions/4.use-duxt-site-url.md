## Signatur

```ts
const { origin, absolute } = useDuxtSiteUrl();
```

## Rückgabe

| Wert       | Typ        | Was es ist                           |
| :--------- | :--------- | :----------------------------------- |
| `origin`   | `string`   | Der konfigurierte Ursprung der Seite |
| `absolute` | `function` | Ein Pfad, dagegen absolut gemacht    |

## Anmerkungen

Gebraucht überall dort, wo eine URL die Seite verlässt — ein Feed-Eintrag, ein
Canonical-Tag, ein OG-Bild. Innerhalb der Seite nimm einen Pfad.
