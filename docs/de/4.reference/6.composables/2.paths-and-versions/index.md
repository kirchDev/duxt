description: Eine URL lesen, eine zurückschreiben, und wissen, welche Version gerade gelesen wird.

Ein Dokumentationspfad und eine URL sind nicht dieselbe Zeichenkette: Die URL
trägt die Locale, das Repository und die Version. Diese vier sind die
Nahtstelle zwischen ihnen.
