Die Umkehrung von [`useDuxtPath()`](/reference/composables/paths-and-versions/use-duxt-path).

## Signatur

```ts
const localeLink = useDuxtLink();

localeLink('/getting-started');
```

## Rückgabe

Eine Funktion, die einem Dokumentationspfad das Locale-Präfix wieder voranstellt
und eine absolute URL unberührt lässt.

## Anmerkungen

Nimm sie für jedes `to`, das eine ersetzte Komponente rendert. Ein von Hand in
eine Komponente geschriebener Pfad ist in einer Sprache richtig und in den
anderen sechs falsch.
