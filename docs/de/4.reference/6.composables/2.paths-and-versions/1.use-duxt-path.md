## Signatur

```ts
const path = useDuxtPath();
```

## Rückgabe

Der aktuelle Routenpfad ohne das Locale-Segment — der Pfad, wie die
Dokumentation ihn kennt.

## Anmerkungen

Alles, was mit Seiten rechnet, rechnet mit diesem Pfad, nicht mit `route.path`:
`/de/duxt/getting-started` und `/duxt/getting-started` sind dieselbe Seite.
