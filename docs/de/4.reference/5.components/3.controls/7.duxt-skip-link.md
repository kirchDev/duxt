„Zum Inhalt springen“, unsichtbar bis fokussiert.

## Verwendung

```vue
<DuxtSkipLink />
```

## API

Keine Props.

## Anmerkungen

Ohne ihn bedeutet jeder Seitenwechsel, sich per Tab durch den Kopfbereich, die
Sektionszeile und die gesamte Seitenleiste zu bewegen, bevor das erste Wort des
Textes kommt. `sr-only` schrumpft ihn auf ein einziges Pixel, und der
Fokuszustand holt ihn über allem anderen zurück auf den Bildschirm.

Der Klick wird behandelt, statt ihn dem Hash zu überlassen, denn nur manche
Browser bewegen bei einem Hash-Link den Fokus — der Handler bewegt ihn in allen.
