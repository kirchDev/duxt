Wird über der Seite gezeigt, wenn die gelesene Version nicht die Standardversion
ist.

## Verwendung

```vue
<DuxtVersionBanner />
```

## API

Keine Props. Liest
[`useDuxtVersion()`](/reference/composables/paths-and-versions/use-duxt-version).

## Anmerkungen

Die sichtbare Hälfte des Versionsproblems. `canonical` und `noindex` sagen einem
Crawler, welche Version auszuliefern ist; dem Leser sagen sie nichts. Wer über
ein Suchergebnis oder über einen Link in einem alten Issue auf v0.7.0 gelandet
ist, sieht eine Dokumentation, die genau wie die aktuelle aussieht. Jede Hälfte
allein lässt eine Zielgruppe im Irrtum, deshalb werden die Head-Tags und dieses
Banner zusammen ausgeliefert.

Einer `upcoming`-Version wird gesagt, dass ihre Dokumentation sich noch ändern
kann, und **nicht**, zu aktualisieren — das ist der eine Zustand, der nie durch
Raten erreicht werden darf.
