Eine zwei Pixel hohe Linie unter dem Kopfbereich.

## Verwendung

```vue
<DuxtProgress />
```

## API

Keine Props.

## Anmerkungen

Eine Linie statt einer Zahl: Auf einer langen Referenzseite lautet die nützliche
Frage „bin ich nahe am Ende“, und ein Prozentwert beantwortet sie schlechter als
eine Linie es tut. Sie ist `aria-hidden`, denn sie sagt nichts, was ein
Screenreader das Dokument nicht ohnehin fragen kann.

Gemessen wird gegen das Dokument statt gegen einen Scroll-Container, sie bleibt
also im Dokumentations-Layout und auf der Landeseite gleichermaßen korrekt.
