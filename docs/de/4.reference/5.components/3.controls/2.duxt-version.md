Ein Element neben dem Titel: ein Abzeichen, wenn es nichts zu wählen gibt,
dasselbe Abzeichen als Dropdown-Auslöser, wenn doch.

## Verwendung

```vue
<DuxtVersion />
```

## API

Keine Props. Liest `versions`, oder das aufgelöste Quellen-Manifest, wenn das
nicht gesetzt ist.

## Anmerkungen

Vorher saß die Version des Projekts als Abzeichen neben dem Titel, während die
Versionen der Dokumentation in einem eigenen Dropdown ganz rechts lebten — zwei
Bedienelemente, die Verschiedenes sagten, und das rechte erschien nur bei
Quellen, die Versionen haben, sodass die Icons daneben sich verschoben, sobald
man zwischen Repositories wechselte.

Ein Versionswechsel behält die Seite: Das Präfix wird getauscht, statt den Leser
an die Wurzel der Version zu schicken. Jeder Eintrag trägt seinen Lebenszyklus,
denn eine Liste, in der drei Einträge gleich aussehen, sagt nichts darüber,
welcher davon noch gefahrlos zu lesen ist.
