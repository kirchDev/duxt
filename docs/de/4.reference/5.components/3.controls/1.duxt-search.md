Das Suchfeld und sein Dialog, geöffnet über die Schaltfläche oder mit
<kbd>⌘K</kbd>.

## Verwendung

```vue
<DuxtSearch />
```

## API

Keine Props. Gebaut auf
[`useDuxtSearch()`](/reference/composables/reading/use-duxt-search).

## Anmerkungen

Die Ergebnisse erstrecken sich über jede Quelle und werden gemeinsam bewertet,
ein Begriff, der in zwei Repositories vorkommt, wird also aus beiden beantwortet.
Passt nichts exakt, fällt die Liste auf Beinahetreffer aus
[`useFuzzySearch()`](/reference/composables/reading/use-fuzzy-search) zurück und
sagt das auch — ein Tippfehler soll die Seite zurückgeben, keinen leeren Kasten.

Jedes Ergebnis ist eine auswählbare Zeile aus drei Teilen — Titel, dieselbe
Kontextzeile, die auch der Verlauf darüber trägt, und ein kurzer Auszug aus dem
Text des Abschnitts, damit sich ein Treffer beurteilen lässt, ohne ihn zu öffnen.
Hat eine Seite mehrere Quellen, eröffnet eine zurückhaltende Beschriftung aus
Quelle, Artefakt und Version jeden Lauf von Ergebnissen, die sich eine teilen —
einmal pro Lauf statt an jeder Zeile wiederholt. Deshalb lassen diese Zeilen die
Quelle in ihrer eigenen Kontextzeile weg und behalten Sektion und Route, die sie
weiterhin unterscheiden. Die Beschriftung sortiert nichts um: das Ranking gehört
dem Merge. Mit [`sources[].name`](/reference/sources) legst du fest, was sie
sagt.
