Gar nichts, wenn die Seite eine Sprache ausliefert, ein Dropdown, wenn sie
mehrere ausliefert.

## Verwendung

```vue
<DuxtLocale />
```

## API

Keine Props. Liest `locales`.

## Anmerkungen

Gebaut wie [`DuxtVersion`](/reference/components/controls/duxt-version) daneben,
sodass ein einsprachiger Konsument nie sieht, dass duxt sieben Sprachen spricht.

Es nutzt `switchLocalePath` statt eines Links auf die Wurzel der Locale: Auf
einer Seite über das Deployen die Sprache zu wechseln sollte auf derselben Seite
in der neuen Sprache landen, nicht den Leser zurück an die Eingangstür werfen.
