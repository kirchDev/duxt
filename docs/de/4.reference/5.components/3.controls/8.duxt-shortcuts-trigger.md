Das Tastatur-Icon neben der Suche. Es öffnet
[`DuxtShortcuts`](/reference/components/controls/duxt-shortcuts), dieselbe
Übersicht, die <kbd>?</kbd> öffnet.

## Verwendung

```vue
<DuxtShortcutsTrigger />
```

## API

Keine Props.

## Anmerkungen

`?` öffnet die Liste der Tasten, und drücken kann sie nur, wer schon weiß, dass
es die Liste gibt. Genau diesen Kreis bricht dieser Button auf — deshalb wird er
im Kopfbereich in jeder Breite gezeichnet und bekommt keine eigene
Responsive-Klasse.

Auf einer Seite mit `shortcuts.singleCharacter: false` ist er zudem der einzige
Eingang zur Übersicht, denn dort gibt es gar keine `?`-Belegung mehr. Entfernst
du ihn aus einem überschriebenen Kopfbereich, ist die Übersicht nicht mehr
erreichbar. Die Taste, die er verdoppelt, zeichnet er über `hint('help')` — auf
einer Seite, die sie gelöst hat, sagt er also nichts über `?`. Siehe
[Tastenkürzel](/concepts/keyboard-shortcuts).
