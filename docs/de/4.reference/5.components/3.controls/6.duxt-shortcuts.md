Das Overlay, das jede Taste auflistet, die das Theme belegt, geöffnet mit
<kbd>?</kbd>.

## Verwendung

```vue
<DuxtShortcuts />
```

## API

Keine Props.

## Anmerkungen

Ihre Liste ist `duxtShortcuts` — dasselbe Array, gegen das die Handler
abgleichen — die Übersicht kann also nicht dazu kommen, eine Taste anzukündigen,
die nichts belegt. Siehe
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).
