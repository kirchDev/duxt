Das Overlay, das jede Taste auflistet, die das Theme belegt, geöffnet mit
<kbd>?</kbd> oder über
[`DuxtShortcutsTrigger`](/reference/components/controls/duxt-shortcuts-trigger),
den Tastatur-Button im Kopfbereich.

## Verwendung

```vue
<DuxtShortcuts />
```

## API

Keine Props.

## Anmerkungen

Ihre Liste ist `duxtShortcuts` — dasselbe Array, gegen das die Handler
abgleichen — die Übersicht kann also nicht dazu kommen, eine Taste anzukündigen,
die nichts belegt. Siehe
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).

Ihr Öffnungszustand ist `useDuxtShortcutSheet()` statt eines eigenen `ref`, denn
der Trigger muss denselben Boolean erreichen — und auf einer Seite mit
`shortcuts.singleCharacter: false` ist der Trigger überhaupt das Einzige, was sie
öffnen kann, weil keine `?`-Belegung mehr übrig ist. Binde sie einmal pro Layout
ein; eine zweite Instanz wäre ein zweiter Dialog auf dieselbe Taste. Siehe
[Tastenkürzel](/concepts/keyboard-shortcuts).
