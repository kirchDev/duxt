Die Zeile der Sektionen unter dem Kopfbereich, nur auf Dokumentationsseiten.

## Verwendung

```vue
<DuxtSections />
```

## API

Keine Props. Liest `sections`; rendert nichts, wenn diese Liste leer ist.

## Anmerkungen

Sie sitzt bei der Doku statt im globalen Kopfbereich, denn die Startseite hat
keine Sektionen zu zeigen.

Eine Sektion ist selten die Seite selbst — sie ist der Zweig, in dem die Seite
sitzt. Die exakte Übereinstimmung meldet daher `aria-current="page"` und ein
Vorfahre meldet `true`, und genau für diese Unterscheidung gibt es
`aria-current`.
