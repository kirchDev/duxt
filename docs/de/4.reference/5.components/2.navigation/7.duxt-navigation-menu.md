---
title: DuxtNavigationMenu
description: Das Menü, das ein Navbar-Eintrag öffnet, in beiden Zeilen.
icon: lucide:menu
---

Was sich an einem Eintrag mit `children` öffnet: ein Dropdown, so tief
verschachtelt wie die Daten, oder ein Mega-Menü-Panel. Die Zeile zeichnet ihren
Auslöser selbst im Slot, weil die beiden Zeilen nicht gleich aussehen.

## Verwendung

```vue
<DuxtNavigationMenu :link="entry" align="start">
  <button type="button">{{ entry.label }}</button>
</DuxtNavigationMenu>
```

## API

### Props

| Name | Typ | Standard | Beschreibung |
| :-- | :-- | :-- | :-- |
| `link` | `DuxtLink` | | Der Eintrag, dessen Menü das ist |
| `align` | `start` \| `center` \| `end` | `center` | Wie sich ein Dropdown an seinem Auslöser ausrichtet. Ein Mega-Menü ist immer auf der Seite zentriert |

### Slot

`default`: Der Auslöser, als einzelnes Element.

## Anmerkungen

Wie man ein Menü konfiguriert, steht in [Navbar-Menüs
bauen](/guides/build-navbar-menus). Um jeden Eintrag auf einmal neu zu
gestalten, ersetze `DuxtNavigationMenuEntry`, das den Inhalt eines Eintrags
zeichnet. `component` am Link macht dasselbe für einen einzelnen.
