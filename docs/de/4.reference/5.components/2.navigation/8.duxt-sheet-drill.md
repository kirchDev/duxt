Hält die erste Ebene des Sheets in seinem Slot und zeichnet jedes daraus
geöffnete Menü als Ebene darüber, sodass ein Menü jeder Tiefe die volle Breite
des Sheets behält.

## Verwendung

```vue
<DuxtSheetDrill ref="levels">
  <!-- Die erste Ebene -->
</DuxtSheetDrill>
```

## API

### Slot

`default`: Die erste Ebene.

### Bereitgestellt

| Name | Typ | Beschreibung |
| :-- | :-- | :-- |
| `drill` | `(link: DuxtLink, event: Event) => void` | Öffnet das Menü von `link` als neue Ebene. Beim Zurückgehen kehrt der Fokus zu dem Element zurück, von dem `event` kam |

## Anmerkungen

`DuxtHeader` zeichnet es im Sheet, und `DuxtSheetLinks` zeichnet die Links einer
Ebene. Auf der Ebene eines Mega-Menüs ist eine Spalte keine weitere Ebene: Sie
steht unter ihrem Namen, wie im Panel. Die Ebenen verschwinden, wenn sich das
Sheet schließt, es öffnet sich also immer wieder auf der ersten.
