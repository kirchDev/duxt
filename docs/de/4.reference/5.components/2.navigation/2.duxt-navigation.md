Die verschachtelte Liste der Seiten in der aktuellen Sektion.

## Verwendung

```vue
<script setup lang="ts">
const { data: navigation } = await useDuxtNavigation();
const { items } = useDuxtSection(navigation);
</script>

<template>
  <DuxtNavigation :items="items" />
</template>
```

## API

### Props

| Prop    | Typ                        | Anmerkungen                            |
| :------ | :------------------------- | :------------------------------------- |
| `items` | `ContentNavigationItem[]`  | Pflicht — ein Zweig aus Contents Baum   |

## Anmerkungen

Der Baum kommt aus [`useDuxtNavigation()`](/reference/composables/config-and-content/use-duxt-navigation),
das die Collection fragt, die die aktuelle Route bedient — eine versionierte
Seite bekommt also den Baum dieser Version, nicht den der Standardversion.
