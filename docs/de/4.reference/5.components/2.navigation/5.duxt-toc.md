Die Überschriften der aktuellen Seite, die mitlaufen, während der Leser scrollt,
plus die konfigurierten `aside`-Links darunter.

## Verwendung

```vue
<DuxtToc :links="page?.body?.toc?.links ?? []" />
```

## API

### Props

| Prop    | Typ         | Anmerkungen                         |
| :------ | :---------- | :---------------------------------- |
| `links` | `TocLink[]` | Pflicht — Contents eigene toc-Links |

## Anmerkungen

Welche Überschrift die aktuelle ist, kommt aus
[`useActiveHeading()`](/reference/composables/reading/use-active-heading), das
die Überschriften beobachtet, nicht den Scroll-Versatz — eine kurze letzte
Sektion wird trotzdem als erreicht gemeldet.

Der `aside.links`-Block darunter wird **leer** ausgeliefert: Ein
Repository-Link, ein Issue-Tracker oder eine Community gehört dem, der die Seite
betreibt.
