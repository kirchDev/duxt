Die Sektion, dann jede Gruppe zwischen ihr und der Seite.

## Verwendung

```vue
<DuxtBreadcrumb :path="path" />
```

## API

### Props

| Prop   | Typ      | Anmerkungen                                   |
| :----- | :------- | :-------------------------------------------- |
| `path` | `string` | Pflicht — der Dokumentationspfad, ohne Präfix |

## Anmerkungen

`breadcrumb: false` in der Konfiguration entfernt sie auf der ganzen Website:
Ein flacher Doku-Baum bekommt eine Spur, die nur seinen eigenen Sektionsnamen
wiederholt.
