Ein einzelner Eintrag, mit seinem Icon, seinem aktiven Zustand und — bei einem
Zweig — seinen Kindern.

## Verwendung

```vue
<DuxtNavigationLink :item="item" />
```

## API

### Props

| Prop   | Typ                     | Anmerkungen                    |
| :----- | :---------------------- | :----------------------------- |
| `item` | `ContentNavigationItem` | Pflicht — ein Knoten des Baums |

## Anmerkungen

Diese Komponente allein zu ersetzen lohnt sich, wenn nur das Aussehen eines
Eintrags falsch ist: Sie zu überschatten lässt den Baum, den aktiven Zustand
und das Einklappen bei
[`DuxtNavigation`](/reference/components/navigation/duxt-navigation).
