Der Rahmen, in dem jeder Fence gezeichnet wird: Dateiname, Sprach-Icon,
Kopier-Button.

## Verwendung

Eher von [`ProsePre`](/reference/mdc-components/prose/prose-pre) aufgerufen als
von Hand, aber direkt nutzbar:

```vue
<DuxtCodeBlock code="pnpm add -D @kirchdev/duxt" language="bash" />
```

## API

### Props

| Prop       | Typ      | Anmerkungen                                        |
| :--------- | :------- | :------------------------------------------------- |
| `code`     | `string` | Roher Quelltext, für den Kopier-Button und als Inhalt des Blocks |
| `language` | `string` | Wählt das Icon                                      |
| `filename` | `string` | Die Beschriftung in der Kopfzeile                   |

### Slots

| Slot      | Was hineingehört                             |
| :-------- | :------------------------------------------- |
| `default` | Hervorgehobenes Markup, sofern es welches gibt |

## Anmerkungen

Ohne Dateinamen schwebt der Kopier-Button in der Ecke und erscheint beim Hover;
mit einem sitzt er in der Kopfzeile, wo er immer sichtbar ist. Ein Block, der
dauerhaft eine Schaltfläche in der Ecke der Seite zeigt, ist lauter als einer,
der sie zeigt, wenn ein Leser danach sucht.
