Der Block am Fuß jeder Seite.

## Verwendung

```vue
<DuxtPageFeedback @feedback="(helpful) => track(helpful)" />
```

## API

### Emits

| Ereignis   | Nutzlast           | Wann                |
| :--------- | :----------------- | :------------------ |
| `feedback` | `helpful: boolean` | Der Leser antwortet |

### Slots

| Slot      | Props                  | Was er ersetzt                  |
| :-------- | :--------------------- | :------------------------------ |
| `default` | `{ answered, answer }` | Die Frage und die Schaltflächen |

## Anmerkungen

Ein Slot mit einem Ereignis und ohne Backend, und das ist das ganze Design. Die
Ebene speichert nichts und sendet nichts: Es geht sie nichts an, wo die Analytik
eines Konsumenten liegt, und ein Dokumentations-Theme, das standardmäßig nach
Hause telefoniert, ist keines, das man veröffentlicht. Die Antwort lebt für die
Dauer des Besuchs im eigenen Zustand der Komponente und sonst nirgends — ein
Routenwechsel setzt sie zurück, denn eine neue Seite ist eine neue Frage.

Sie anzuschließen ist eine eigene Anleitung:
[Seiten-Feedback sammeln](/guides/collect-page-feedback).
