Ein geteiltes Bedienelement neben dem Seitentitel: das Markdown kopieren, es
ansehen oder es in einem Chatmodell öffnen.

## Verwendung

```vue
<DuxtCopyPage :path="path" :title="page?.title" :rawbody="page?.rawbody" />
```

## API

### Props

| Prop      | Typ      | Anmerkungen                                             |
| :-------- | :------- | :------------------------------------------------------ |
| `path`    | `string` | Erforderlich — der Dokumentationspfad                    |
| `title`   | `string` | Wird im Prompt genutzt, der einem Modell übergeben wird  |
| `rawbody` | `string` | Der Markdown-Quelltext, für die Kopieren-Schaltfläche    |

## Anmerkungen

Ein geteiltes Bedienelement statt vier Schaltflächen — der übliche Fall ist
„kopieren“, und die anderen drei sind dieselbe Absicht durch eine andere Tür.

Was sie alle übergeben, ist das **Markdown**, nicht die gerenderte Seite: Ein
Modell, dem man HTML gibt, muss ein Layout rückgängig machen, um eine Überschrift
zu finden, und eines, dem man die Quelle gibt, liest, was der Autor geschrieben
hat. Das Frontmatter wird entfernt, sodass sich das Kopierte wie die Seite liest
und nicht wie die Datei.

Die externen Links brauchen eine absolute URL, und der Origin wird beim Klick aus
dem Browser gelesen statt aus der Konfiguration — der einzige Wert, der sicher
stimmt, auch auf einem Vorschau-Deployment, dessen Domain niemand aufgeschrieben
hat.
