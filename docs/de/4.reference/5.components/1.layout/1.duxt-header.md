Die Leiste am oberen Rand jeder Seite — der Seitentitel, die
Navigationseinträge, die Suche, die Umschalter für Version und Locale und der
Theme-Schalter.

## Verwendung

```vue
<DuxtHeader />
```

## API

Keine Props. Alles kommt aus der Konfiguration: `title`, `navigation`, `links`,
`version` und `locales`.

## Anmerkungen

Ein Eintrag, der weder `to` noch `children` hat, bedeutet „die Dokumentation“.
Der „Docs“-Eintrag der Ebene selbst kommt bewusst ohne `to`: Wo die
Dokumentation liegt, hängt von den Präfixen des Konsumenten ab, die die Ebene
nicht kennen kann. Er löst auf die erste Sektion auf, und genau das lässt die
Standard-Navbar auf einer versionierten Seite genauso funktionieren wie auf
einer flachen.
