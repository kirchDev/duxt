Eine Zeile, und nur das, was ein Fußbereich schuldet: wem diese Seite gehört,
und die Links, die das Gesetz verlangt. Navigation lebt im Kopfbereich und in
der Seitenleiste.

## Verwendung

```vue
<DuxtFooter />
```

## API

Keine Props. Liest `footer.copyright`, `footer.legal` und `poweredBy`.

## Anmerkungen

Die Zeile „Powered by duxt“ liest ihre Version und ihr Repository zur Build-Zeit
aus duxts eigener `package.json` — release-please hebt diese Datei an, und eine
zweite Kopie der Nummer ist eine Kopie, die ab dem ersten Release falsch ist.

Sie ist abschaltbar, denn eine Ebene, der man nicht sagen kann, dass sie
aufhören soll, sich selbst zu nennen, ist Adware: `poweredBy: false` entfernt
sie.

Die Rechtszeile wird **leer** ausgeliefert. Ein Impressum zu beanspruchen steht
der Vorlage nie zu.
