## Zwei Achsen, nicht eine

Eine Übersetzung ist keine Version, und die beiden zu vergleichen, als wären sie
dasselbe, zeichnet ein Raster aus identischen Spalten. Deshalb hält das Panel
immer eine Achse fest:

- **Versionen einer Sprache** — `v2` gegen `v1.9`, beide auf Englisch.
- **Sprachen einer Version** — `en` gegen `de`, beide bei `v2`.

Eine Seite mit zwei Versionen in zwei Sprachen bekommt also vier Raster, jedes
mit einer Frage. Ein Repository, das einmal und in einer Sprache veröffentlicht
ist, bekommt keines: eine einzelne Spalte vergleicht nichts.

Repositories werden nie vermischt. `/sdk/guides` und `/cli/guides` sind zwei
Projekte, die zufällig einen Ordnernamen teilen, und sie in ein Raster zu
stecken, würde eine Lücke erfinden, die keine ist.

## So liest du es

`✓` heißt, die Collection hält diese Seite; `·` heißt, sie tut es nicht. Das `*`
neben einer Überschrift markiert die eine, die ohne eigenes Segment ausgeliefert
wird — die Standardversion oder die Sprache, die im Quellordner selbst liegt.

Ein `·` in einer Sprachspalte ist eine Seite, die auf ihre Übersetzung wartet.
Ein `·` in der Spalte einer älteren Version ist meist richtig: den Guide gab es
damals noch nicht.
