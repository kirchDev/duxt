title: Changelog
description: Ein Release-Log, als Seiten veröffentlicht — eine Zeitleiste, eine Seite pro Release, und ein Feed.
icon: lucide:tag
---

Zeige eine Quelle auf die Datei, die dein Release-Werkzeug schreibt, und duxt
baut daraus eine Historie — eine Übersicht mit jedem Release auf einer Zeitleiste
und eine Seite pro Release mit einem eigenen Deep Link, einem eigenen Suchtreffer,
einem eigenen Feed-Eintrag und einem eigenen Eintrag in `llms.txt`.

Gelesen wird, was release-please schreibt, und absichtlich mehr als das: Eine
Überschrift ist ein Release, wenn sie mit etwas beginnt, das wie eine Version
aussieht — ein handgepflegtes `## 1.4.0` und eine Keep-a-Changelog-Datei werden
also ebenso gelesen.
