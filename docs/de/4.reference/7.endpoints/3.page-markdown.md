title: <seite>.md
description: Der Quelltext jeder Seite, unter ihrer eigenen URL plus .md.

---

Hänge `.md` an eine beliebige Dokumentations-URL, und die Antwort ist das
Markdown, aus dem diese Seite gerendert wurde.

```
/duxt/getting-started      → die Seite
/duxt/getting-started.md   → ihr Quelltext
```

## Anmerkungen

Es ist eine **Middleware, keine Route**, denn `.md` ist ein Suffix am letzten
Segment und kein eigenes Segment — eine Routendatei kann es nicht treffen.

Das ist es, was [`DuxtCopyPage`](/reference/components/page/duxt-copy-page)
einem Modell übergibt: den Quelltext, nicht die gerenderte Seite.
