Content speichert nur, was das Schema einer Collection deklariert — dies ist
also die vollständige Liste: Ein nicht deklariertes Feld wird stillschweigend
verworfen, bevor die Seitenleiste oder die Suche es je sieht.

## Was du schreibst

| Feld           | Typ        | Was es tut                                                        |
| :------------- | :--------- | :----------------------------------------------------------------- |
| `title`        | `string`   | Als `<h1>` der Seite gerendert, plus SEO- und Social-Titel          |
| `description`  | `string`   | Die Zusammenfassung — Seitenleiste, Karten, OG-Bild, `llms.txt`     |
| `icon`         | `string`   | Neben dem Eintrag in Seitenleiste, Sektionszeile und Karten gezeigt |
| `navigation`   | `boolean`  | `false` verbirgt die Seite in der Navigation                        |
| `layout`       | `string`   | `landing` rendert die Seite ohne das Doku-Layout                    |
| `redirectFrom` | `string[]` | Alte URLs dieser Seite — siehe [Eine Seite verschieben](/guides/move-a-page) |
| `date`         | `string`   | Wann diese Seite datiert ist, für den Feed                          |

`title` und `description` sind die beiden, vor deren Fehlen der Build warnt.
Keines bricht eine Seite, und beide verschlechtern still das
Inhaltsverzeichnis, die Social Card und `llms.txt`.

::callout{type="tip" title="Kein H1 im Text"}
`title` wird als Überschrift gerendert. Eine `#`-Überschrift am Anfang der Datei
ist das zweite `<h1>` auf der Seite.
::

## Was der Build füllt

| Feld           | Gefüllt von              | Enthält                                          |
| :------------- | :----------------------- | :----------------------------------------------- |
| `lastUpdated`  | dem git-meta-Modul       | Den letzten Commit, der die Datei berührt hat     |
| `contributors` | dem git-meta-Modul       | Name, Commit-Zahl und Benutzername, je Autor      |
| `rawbody`      | dem Collection-Schema    | Das Markdown, wie es geschrieben wurde            |
| `sitemap`      | der Sitemap-Integration  | Das, was die Seite überhaupt in `/sitemap.xml` bringt |

Eines davon von Hand zu schreiben ist zwecklos: Der Build überschreibt sie.
Beide git-Felder brauchen eine echte Historie, eine entfernte Quelle braucht
also `history: true` — siehe [Quellen-Referenz](/reference/sources).

## Der Dateiname trägt zwei weitere Dinge

- **Ein numerisches Präfix ordnet den Baum** und wird aus der URL entfernt:
  `3.guides/2.deploy.md` wird unter `/guides/deploy` ausgeliefert. Umsortieren
  verschiebt nie eine URL.
- **`.draft.md` ist ein Entwurf.** Er wird im Entwicklungsserver ausgeliefert
  und fehlt im Build. Es gibt kein `draft: true`, weil der Inhalt einer
  Collection deklariert wird, bevor irgendeine Datei gelesen wurde — siehe
  [Collections](/concepts/collections).
