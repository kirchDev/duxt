Inline, und die eine Komponente, die über die eigene Quelle der Seite
hinausgreift: `_partials/` in **jeder** Quelle speist eine gemeinsame Collection.

## Verwendung

```mdc
:partial{name="install"}
```

## API

### Props

| Prop   | Typ      | Standard | Anmerkungen                           |
| :----- | :------- | :------- | :------------------------------------ |
| `name` | `string` | —        | Die Datei in `_partials/`, ohne `.md` |

## Anmerkungen

Content liefert keine Include-Direktive, und über Repositories hinweg ist das
eine Lücke ohne Umweg: Ein Installationshinweis, der in drei Projekten gleich
lauten muss, wird in drei Projekte kopiert und driftet auseinander. Ein Block,
der in einem Repository definiert ist, ist aus den Seiten eines anderen
aufrufbar.
