Die Kinder einer Sektion, als Karten mit Icon, Titel und Beschreibung
gezeichnet — das, womit jede `index.md` in dieser Dokumentation endet.

## Verwendung

```mdc
::page-cards
::
```

Ohne Prop listet es die Kinder der aktuellen Seite auf, weshalb es hier beim
Namen genannt statt gerendert wird: Diese Seite hat keine.

## API

### Props

| Prop   | Typ      | Standard           | Anmerkungen                                |
| :----- | :------- | :----------------- | :----------------------------------------- |
| `path` | `string` | die aktuelle Seite | Die Kinder einer anderen Sektion auflisten |

## Anmerkungen

Titel, Beschreibung und Icon kommen aus dem Frontmatter des jeweiligen Kindes,
eine Karte kann also nicht von der Seite abdriften, auf die sie zeigt.
