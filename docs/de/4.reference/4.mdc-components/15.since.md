Inline. Markiert die Version, in der eine Sache kam — nutzbar innerhalb einer
Überschrift.

## Verwendung

### Retries :since{version="v2.0.0"}

```mdc
### Retries :since{version="v2.0.0"}
```

## API

### Props

| Prop      | Typ      | Standard | Anmerkungen                 |
| :-------- | :------- | :------- | :-------------------------- |
| `version` | `string` | —        | Ausgegeben, wie geschrieben |

## Anmerkungen

Es hängt am Versionsmodell, statt es zu wiederholen: Was das Badge sagt, ist die
Version, in der eine Sache KAM, und das ist eine Tatsache über die API, nicht
über die Seite, auf der sie dokumentiert ist — es bleibt also in jeder Version
der Dokumentation richtig, die den Satz trägt.

Für alles andere ruft `:badge[…]` das Badge des Themes direkt auf; MDC löst jede
global registrierte Komponente über ihren Namen auf.
