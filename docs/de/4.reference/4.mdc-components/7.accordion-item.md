Ein Abschnitt innerhalb von
[`::accordion`](/reference/mdc-components/accordion).

## Verwendung

```mdc
:::accordion
  ::accordion-item{label="Warum eine Ebene und kein Modul?" icon="lucide:layers"}
  Ein Modul kann keine Seiten, kein Theme und keinen app.config-Standard ausliefern.
  ::
:::
```

## API

### Props

| Prop    | Typ      | Standard | Anmerkungen                            |
| :------ | :------- | :------- | :------------------------------------- |
| `label` | `string` | —        | Der Text des Triggers                  |
| `icon`  | `string` | —        | Beliebiger Iconify-Name, vor dem Label |

### Slots

| Slot      | Was hineinkommt           |
| :-------- | :------------------------ |
| `default` | Die Antwort, als Markdown |
