Umschließt eine **geordnete Liste** mit einem Schritt-Layout. Der Block
nummeriert jede Liste, die er umschließt, das Markdown bleibt also eine
gewöhnliche Liste.

## API

Keine Props. Der Block gestaltet sein Kind-`<ol>`.

### Slots

| Slot      | Was hineingehört                        |
| :-------- | :-------------------------------------- |
| `default` | Eine geordnete Liste, Markdown-Einträge |

## Anmerkungen

Lohnt sich, sobald ein Schritt einen Codeblock trägt: In einer schlichten
geordneten Liste drückt der Fence den Text von seiner eigenen Nummer weg, und
dieses Layout hält die Nummer daneben fest.

Die Marker sind ein CSS-Zähler auf den Listeneinträgen, kein Inhalt — ein
Leser, der die Schritte kopiert, bekommt den Text ohne die doppelt gezeichnete
Nummerierung.
