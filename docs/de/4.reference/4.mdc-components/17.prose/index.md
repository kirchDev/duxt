title: Prose-Overrides
description: Was die Ebene an schlichtem Markdown ändert — Links, Überschriften, Bilder, Code und Tabellen.
icon: lucide:type
---

Diese Komponenten werden nie beim Namen aufgerufen. Content rendert schlichtes
Markdown durch sie hindurch, eine davon zu ersetzen ändert also, wie ein
gewöhnlicher Absatz, Link oder Fence auf jeder Seite aussieht.

Sie stehen hier aus demselben Grund wie die Blöcke daneben: Ein dokumentierter
Name ist Teil der öffentlichen Oberfläche der Ebene, und deine eigene Datei
gleichen Namens ersetzt unsere.
