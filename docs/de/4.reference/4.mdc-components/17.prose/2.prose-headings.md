Drei Komponenten, ein Verhalten: `ProseH2`, `ProseH3` und `ProseH4` rendern die
Überschriften, aus denen das Inhaltsverzeichnis einer Seite gebaut wird.

## Was sie hinzufügen

Einen Permalink-Anker neben der Überschrift, sichtbar beim Hover und per Tastatur
erreichbar. Die `id` ist Contents eigener Slug, damit der Anker, das
Inhaltsverzeichnis und die Navigation innerhalb der Seite übereinstimmen.

## API

### Props

| Prop | Typ      | Anmerkungen                             |
| :--- | :------- | :-------------------------------------- |
| `id` | `string` | Der Slug, den Content für den Text erzeugt hat |

### Slots

| Slot      | Was hineinkommt          |
| :-------- | :----------------------- |
| `default` | Der Text der Überschrift |

## Anmerkungen

`ProseH1` wird bewusst nicht überschrieben: Der Seitentitel wird von der Seite
gerendert, nicht vom Markdown — eine `#`-Überschrift im Text wäre also ein
zweites `h1` auf der Seite.
