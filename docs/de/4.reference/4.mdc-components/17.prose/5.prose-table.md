Jede Markdown-Tabelle.

## Was sie hinzufügt

Einen Scroll-Container um die Tabelle, damit eine breite Tabelle in ihrem
eigenen Kasten scrollt, statt die ganze Seite seitwärts scrollen zu lassen.

## API

### Slots

| Slot      | Was hineingehört |
| :-------- | :--------------- |
| `default` | Die Tabelle      |
