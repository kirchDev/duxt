`code` und Listen funktionieren also alle darin.

## Typen

::preview
:::callout{type="info"}
`info` — der Standard, für Kontext, den die Seite voraussetzt.
:::

:::callout{type="tip"}
`tip` — etwas, das die Aufgabe leichter macht.
:::

:::callout{type="warning"}
`warning` — eine Art, das falsch zu machen.
:::

:::callout{type="danger"}
`danger` — Datenverlust, oder eine Änderung, die sich nicht rückgängig machen lässt.
:::

#code
```mdc
::callout{type="info"}
`info` — der Standard, für Kontext, den die Seite voraussetzt.
::
```

## API

### Props

| Prop    | Typ                                   | Standard    | Anmerkungen                              |
| :------ | :------------------------------------ | :---------- | :--------------------------------------- |
| `type`  | `info` · `tip` · `warning` · `danger` | `info`      | Wählt die Farbe, das Icon und die Rolle  |
| `title` | `string`                              | —           | Fette erste Zeile; der Text folgt        |
| `icon`  | `string`                              | je nach Typ | Beliebiger Iconify-Name, der den Standard überschreibt |

### Slots

| Slot      | Was hineingehört       |
| :-------- | :--------------------- |
| `default` | Der Text, als Markdown |

## Anmerkungen

Ein `danger`-Callout trägt `role="alert"`; die anderen nicht. Ein Alert
unterbricht einen Screenreader mitten im Satz, was für „das löscht deine Daten“
richtig ist und für einen Tipp falsch.
