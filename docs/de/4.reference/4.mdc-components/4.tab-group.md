## API

Keine Props. Die Labels kommen von den Kindern.

### Slots

| Slot      | Was hineinkommt |
| :-------- | :-------------- |
| `default` | `::tab`-Blöcke  |

## Anmerkungen

**Nicht `::tabs`.** Das UI-Kit des Themes registriert bereits ein `Tabs` — das
von shadcn — und zwei Komponenten desselben Namens sind keine Überschreibung,
die ein Build zu deinen Gunsten auflöst: Nuxt behält eine von beiden, und es
behielt die von shadcn, sodass `::tabs` ein Primitive ohne Trigger und ohne
Zustand renderte. Eine Content-Komponente darf keinen Namen tragen, der dem
UI-Kit gehört.

Auf reka-uis Primitives gebaut statt auf dem shadcn-Wrapper, weil die Labels
erst feststehen, wenn die Kinder sich selbst registriert haben: MDC reicht sie
als Slot-Inhalt herein, nicht als Prop. Tastaturnavigation, wandernder Fokus
und die ARIA-Rollen kommen mit ihnen.
