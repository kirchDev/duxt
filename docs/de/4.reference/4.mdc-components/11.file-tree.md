## API

### Props

| Prop    | Typ       | Standard | Anmerkungen                               |
| :------ | :-------- | :------- | :---------------------------------------- |
| `tree`  | `Entry[]` | —        | Als YAML im Text des Blocks angegeben     |
| `title` | `string`  | —        | Die Beschriftung der Wurzel über dem Baum |

Ein Eintrag ist `{ name, children? }`. Ein Name, der auf `/` endet, oder einer,
der Kinder trägt, ist ein Verzeichnis.

## Anmerkungen

Auf reka-uis Baum gebaut, es gibt also wandernden Fokus, Navigation mit den
Pfeiltasten und die ARIA-Rollen. Knoten werden über ihren Pfad statt über ihren
Namen identifiziert: Namen wiederholen sich über Zweige hinweg, Pfade nicht.
