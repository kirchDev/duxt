Ein Panel innerhalb von [`::tab-group`](/reference/mdc-components/tab-group).
Für sich allein hat es keine Bedeutung.

## Verwendung

```mdc
:::tab-group
  ::tab{label="pnpm"}
  Die Ebene ist eine Dev-Abhängigkeit.
  ::
:::
```

## API

### Props

| Prop    | Typ      | Standard | Anmerkungen                       |
| :------ | :------- | :------- | :-------------------------------- |
| `label` | `string` | —        | Der Text auf dem Trigger des Tabs |

### Slots

| Slot      | Was hineinkommt         |
| :-------- | :---------------------- |
| `default` | Das Panel, als Markdown |

## Anmerkungen

Die Komponente registriert ihr eigenes Label im Setup beim Elternelement, und
genau das lässt die Liste der Trigger aus Kindern bauen, die MDC noch nicht
gerendert hat.
