title: Feldgruppe

---

Gruppiert [`::field`](/reference/mdc-components/field)-Blöcke, sodass sie sich
als eine Liste mit Trennlinien lesen und nicht als einzelne Karten.

## Verwendung

::preview
::::field-group
:::field{name="path" type="string" required}
Ordner mit dem Markdown, relativ zur Repository-Wurzel.
:::

:::field{name="history" type="boolean" default="false"}
Liest die git-Historie dieser Quelle für „Zuletzt aktualisiert“ und die
Mitwirkenden.
:::
::::

#code
```mdc
:::field-group
  ::field{name="path" type="string" required}
  Ordner mit dem Markdown, relativ zur Repository-Wurzel.
  ::
:::
```
::

## API

Keine Props.

| Slot      | Was hineingehört  |
