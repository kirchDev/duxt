Mehrere Fence-Blöcke, gezeigt als ein Block mit je einem Tab. Die Beschriftung
jedes Tabs ist der eigene Dateiname des Fences, denn genau zwischen dem wählt
der Leser, und geschrieben ist er ohnehin schon.

## API

Keine Props. Ein Fence ohne Dateinamen bekommt seine Sprache als Beschriftung.

### Slots

| Slot      | Was hineingehört             |
| :-------- | :--------------------------- |
| `default` | Eine Folge von Fence-Blöcken |

## Anmerkungen

Die Kinder werden aus den VNodes des Standard-Slots gelesen, statt sich über
eine Kindkomponente zu registrieren: Ein Fence ist ein `ProsePre`, nichts, was
dieser Block bitten könnte, sich selbst zu melden, und sein Dateiname ist ein
Prop auf diesem Knoten.

Für alles, was kein Code ist, nimm
[Tab-Gruppe](/reference/mdc-components/tab-group).
