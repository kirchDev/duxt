---
title: Mit dem Starter beginnen
description: Erstelle mit Nuxi eine sofort lauffähige duxt-Dokumentationsseite.
icon: lucide:rocket
---

Der [duxt-Starter](https://github.com/kirchDev/duxt-starter) ist eine kleine
Dokumentationsseite mit Landing-Page und einem Abschnitt für die ersten
Schritte. Nuxi kopiert ihn, installiert die Abhängigkeiten und legt sein
Git-Repository an:

```bash
npx nuxi@latest init -t github:kirchDev/duxt-starter
cd <projektverzeichnis>
pnpm dev
```

Öffne die Adresse, die Nuxt ausgibt, und bearbeite danach Dateien in `docs/`.
Die Navigation und die Vorschau auf der Landing-Page aktualisieren sich mit
deinen Seiten. Für ein bereits bestehendes Projekt nutze stattdessen die
[Installation](/getting-started/installation).
