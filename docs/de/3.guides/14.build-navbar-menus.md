Ein Eintrag in `navigation` oder `sections` wird zum Menü, sobald er `children`
hat. Alles Weitere ist Konfiguration an denselben Link-Objekten: wie tief das
Menü geht, ob es eine Liste oder ein Panel ist und wie jeder Eintrag darin
gezeichnet wird. Die [Demo](/demo) zeigt in ihrer Sektionszeile je ein Beispiel.

## Schritte

::steps

1. **Verschachtle die Links.** Ein Eintrag mit `children` öffnet ein Dropdown,
   und ein Kind mit `children` öffnet daneben ein weiteres Menü, so tief wie die
   Daten reichen:

   ```ts [app/app.config.ts]
   export default defineAppConfig({
     duxt: {
       navigation: [
         {
           label: 'Platform',
           icon: 'lucide:layers',
           children: [
             { label: 'Overview', to: '/platform' },
             {
               label: 'API',
               children: [
                 { label: 'REST', to: '/api/rest' },
                 { label: 'Webhooks', to: '/api/webhooks' }
               ]
             }
           ]
         }
       ]
     }
   });
   ```

2. **Mach daraus ein Panel.** `menu: 'mega'` legt die Kinder in einem Raster aus
   `columns` an. Ein Kind mit eigenen Kindern ist eine Spalte unter seinem Namen,
   ein Kind ohne ist eine eigene Zelle:

   ```ts
   {
     label: 'Platform',
     menu: 'mega',
     columns: 3,
     divided: true,
     children: [
       {
         label: 'Highlights',
         hideLabel: true,
         children: [
           {
             label: 'Editor',
             to: '/editor',
             image: '/editor.svg',
             display: 'feature',
             description: 'Write and preview'
           }
         ]
       },
       {
         label: 'API',
         children: [
           { label: 'REST', to: '/api/rest' },
           { label: 'Webhooks', to: '/api/webhooks', badge: 'New' },
           { label: 'All of the API', to: '/api', display: 'more' }
         ]
       },
       { label: 'New here?', to: '/start', display: 'callout' }
     ]
   }
   ```

3. **Wähle das Layout.** Dieselben Optionen ergeben recht unterschiedliche
   Panels:

   | Du willst | Setze |
   | :-- | :-- |
   | Linkspalten neben einer Feature-Liste | Eine erste Spalte mit `hideLabel` und `display: 'feature'`-Einträgen, dazu `divided` an der zweiten |
   | Ein Raster aus Produkten | `columns: 3`, Einträge mit `icon`, `description` und `display: 'feature'`, zum Abschluss `display: 'callout'` |
   | Ein breites Panel mit Einleitung | `width: 'full'`, `columns: 6`, `divided` und eine erste Spalte mit `span: 2`, `image` und `description` |
   | Ein Bild über jeder Spalte | `width: 'full'` und `image` an jeder Spalte |

4. **Ergänze eine eigene Zelle, wenn die Formen nicht reichen.** `component`
   nennt eine global registrierte Komponente. Sie ersetzt den Inhalt des Eintrags,
   füllt seine Zelle und bekommt den Eintrag als `link`. Benenne die Datei
   `.global.vue`, denn `app.config` kann sie nur beim Namen nennen. Eine deckende
   Komponente verdeckt die Hervorhebung, die das Menü hinter einen Eintrag malt,
   zeichne also deine eigene:

   ```vue [app/components/MenuPromo.global.vue]
   <script setup lang="ts">
   defineProps<{ link: DuxtLink }>();
   </script>

   <template>
     <span
       class="flex h-full p-3 in-data-highlighted:ring-2"
     >
       {{ link.label }}
     </span>
   </template>
   ```

5. **Nutze die zweite Zeile genauso.** `sections` hat dieselbe Form. Eine
   Sektion mit Menü gehört zum Bereich ihres ersten Links, und wenn zwei Einträge
   eine Seite beanspruchen, bleibt der erste aktiv. Einfache Einträge gehören also
   vor Menüs, die ihre Links wiederholen.

6. **Prüfe es auf dem Smartphone.** Unterhalb des Breakpoints `lg` zeigt das
   Sheet die erste Ebene, und jedes Menü fährt als eigene Ebene unter einem
   Zurück-Button herein. Spalten eines Mega-Menüs bleiben auf einer Ebene, unter
   ihren Namen.

::

## Warum das so funktioniert

Ein Mega-Menü ist auf der Seite zentriert, nicht auf seinem Eintrag. Ein so
breites Panel hat keine sinnvolle Position relativ zu einem einzelnen Eintrag
der Zeile: Am Eintrag aufgehängt saß dasselbe Menü bei jedem Eintrag und jeder
Fensterbreite woanders.

Das Sheet wechselt die Ebene, statt einzurücken, weil jede verschachtelte Ebene
der vorherigen Breite nimmt und ein Smartphone keine übrig hat. Eine Ebene auf
einmal hält außerdem jeden Link in voller Breite, egal wie tief er liegt.

Alle Optionen stehen in der [Konfigurationsreferenz](/reference/configuration),
die Komponenten sind
[DuxtNavigationMenu](/reference/components/navigation/duxt-navigation-menu) und
[DuxtSheetDrill](/reference/components/navigation/duxt-sheet-drill).

## Checkliste

- [ ] Jeder Eintrag, der ein Menü öffnet, hat `children`, und ein `to` nur, wenn seine eigene Seite das Menü anführen soll
- [ ] Die `columns` eines Mega-Menüs passen zu den `span`-Werten der Zellen
- [ ] Einfache Einträge in `sections` stehen vor Menüs, die ihre Links wiederholen
- [ ] Das Menü wurde in Smartphone-Breite bis zur tiefsten Ebene geöffnet
