The overlay listing every key the theme binds, opened with <kbd>?</kbd>.

## Usage

```vue
<DuxtShortcuts />
```

## API

No props.

## Notes

Its list is `duxtShortcuts` — the same array the handlers match against — so the
sheet cannot come to advertise a key that nothing binds. See
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).
