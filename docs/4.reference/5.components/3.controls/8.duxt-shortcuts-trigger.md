The keyboard icon beside the search. It opens
[`DuxtShortcuts`](/reference/components/controls/duxt-shortcuts), the same sheet
<kbd>?</kbd> opens.

## Usage

```vue
<DuxtShortcutsTrigger />
```

## API

No props.

## Notes

`?` opens the list of keys, and a reader can only press it if they already know
the list is there. That circle is what this button breaks, so it is drawn in the
header at every width rather than given a responsive class of its own.

It is also the sheet's only entry point on a site with
`shortcuts.singleCharacter: false`, where there is no `?` binding left at all —
drop it from an overridden header and the sheet becomes unreachable. It draws the
key it duplicates through `hint('help')`, so it says nothing about `?` on a site
that unbound it. See [Keyboard shortcuts](/concepts/keyboard-shortcuts).
