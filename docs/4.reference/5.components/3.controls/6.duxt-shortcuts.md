The overlay listing every key the theme binds, opened with <kbd>?</kbd> or with
[`DuxtShortcutsTrigger`](/reference/components/controls/duxt-shortcuts-trigger),
the keyboard button in the header.

## Usage

```vue
<DuxtShortcuts />
```

## API

No props.

## Notes

Its list is `duxtShortcuts` — the same array the handlers match against — so the
sheet cannot come to advertise a key that nothing binds. See
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).

Its open state is `useDuxtShortcutSheet()` rather than a `ref` of its own,
because the trigger has to reach the same boolean — and on a site with
`shortcuts.singleCharacter: false` the trigger is the only thing that can open it
at all, since there is no `?` binding left. Mount it once per layout; a second
instance would be a second dialog answering the same key. See
[Keyboard shortcuts](/concepts/keyboard-shortcuts).
