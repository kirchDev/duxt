Holds the sheet's first level in its slot and draws each menu opened from it as
a level on top, so a menu of any depth keeps the sheet's full width.

## Usage

```vue
<DuxtSheetDrill ref="levels">
  <!-- The first level -->
</DuxtSheetDrill>
```

## API

### Slot

`default`: The first level.

### Exposed

| Name | Type | Description |
| :-- | :-- | :-- |
| `drill` | `(link: DuxtLink, event: Event) => void` | Opens `link`'s menu as a new level. Going back returns focus to the element `event` came from |

## Notes

`DuxtHeader` draws it inside the sheet, and `DuxtSheetLinks` draws the links of
one level. In a mega menu's level a column is not a further level: it stands
under its name, as it does in the panel. The levels are gone when the sheet
closes, so it always reopens at the first.
