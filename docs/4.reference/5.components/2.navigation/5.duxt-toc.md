The headings of the current page, tracking as the reader scrolls, plus the
configured `aside` links beneath.

## Usage

```vue
<DuxtToc :links="page?.body?.toc?.links ?? []" />
```

## API

### Props

| Prop    | Type        | Notes                              |
| :------ | :---------- | :--------------------------------- |
| `links` | `TocLink[]` | Required — Content's own toc links |

## Notes

Which heading is current comes from
[`useActiveHeading()`](/reference/composables/reading/use-active-heading), which watches
the headings rather than the scroll offset — a short last section is still
reported as reached.

The `aside.links` block below it ships **empty**: a repository link, an issue
tracker or a community belongs to whoever runs the site.
