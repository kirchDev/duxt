Section, then any groups between it and the page.

## Usage

```vue
<DuxtBreadcrumb :path="path" />
```

## API

### Props

| Prop   | Type     | Notes                                      |
| :----- | :------- | :----------------------------------------- |
| `path` | `string` | Required — the documentation path, unprefixed |

## Notes

`breadcrumb: false` in the config drops it site-wide: a flat docs tree gets a
trail that only repeats its own section name.
