title: DuxtNavigationMenu

What opens from an entry with `children`: a dropdown nested as deep as the data
goes, or a mega menu panel. The row draws its own trigger in the slot, because
the two rows do not look alike.

## Usage

```vue
<DuxtNavigationMenu :link="entry" align="start">
  <button type="button">{{ entry.label }}</button>
</DuxtNavigationMenu>
```

## API

### Props

| Name | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `link` | `DuxtLink` | | The entry whose menu this is |
| `align` | `start` \| `center` \| `end` | `center` | Where a dropdown lines up with its trigger. A mega menu is always centred on the page |

### Slot

`default`: The trigger, as a single element.

## Notes

How to configure a menu is in [Build navbar menus](/guides/build-navbar-menus).
To restyle every entry at once, replace `DuxtNavigationMenuEntry`, which draws
one entry's content; `component` on the link does the same for a single one.
