Nothing else shows this. The fallback's whole job is the gap between two columns
of this grid, and without it the only way to find one is to open a URL and see a
404.

::devtools-panel{tab="versions"}
::

## Two axes, not one

A translation is not a version, and comparing the two as if they were draws a
grid of identical columns. So the panel holds one axis fixed at a time:

- **Versions of one language** — `v2` against `v1.9`, both in English.
- **Languages of one version** — `en` against `de`, both at `v2`.

A site with two versions in two languages therefore gets four grids, each
answering one question. A repository published once, in one language, gets none:
a single column compares nothing.

Repositories are never mixed. `/sdk/guides` and `/cli/guides` are two projects
that happen to share a folder name, and putting them in one grid would invent a
gap that is not one.

## Reading it

`✓` means the collection holds that page; `·` means it does not. The `*` beside a
heading marks the one served without a segment of its own — the default version,
or the language that lives in the source folder itself.

A `·` in a language column is a page waiting to be translated. A `·` in an older
version's column is usually correct: the guide did not exist yet.
