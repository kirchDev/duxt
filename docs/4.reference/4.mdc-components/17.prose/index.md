title: Prose overrides
description: What the layer changes about plain Markdown — links, headings, images, code and tables.

These components are never called by name. Content renders plain Markdown through
them, so replacing one changes what an ordinary paragraph, link or fence looks
like across every page.

They are listed here for the same reason as the blocks beside them: a documented
name is part of the layer's public surface, and your own file of the same name
replaces ours.
