The children of a section, drawn as cards with their icon, title and
description — what every `index.md` in this documentation ends with.

## Usage

```mdc
::page-cards
::
```

With no prop it lists the children of the current page, which is why it is shown
here by name rather than rendered: this page has none.

## API

### Props

| Prop   | Type     | Default          | Notes                              |
| :----- | :------- | :--------------- | :--------------------------------- |
| `path` | `string` | the current page | List another section's children    |

## Notes

Title, description and icon come from each child's own frontmatter, so a card
cannot drift from the page it points at.
