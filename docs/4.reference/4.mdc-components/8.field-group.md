---
title: Field group
description: A list of fields as one block.
icon: lucide:list-tree
---

Groups [`::field`](/reference/mdc-components/field) blocks so they read as one
list with dividers rather than as separate cards.

## Usage

::preview
::::field-group
:::field{name="path" type="string" required}
Folder holding the Markdown, relative to the repository root.
:::

:::field{name="history" type="boolean" default="false"}
Read this source's git history for "Last updated" and the contributors.
:::
::::

#code
```mdc
:::field-group
  ::field{name="path" type="string" required}
  Folder holding the Markdown, relative to the repository root.
  ::
:::
```
::

## API

No props.

### Slots

| Slot      | What goes in it   |
| :-------- | :---------------- |
| `default` | `::field` blocks  |
