One command shown for every package manager the site offers, with the reader's
choice remembered for the whole site.

## Usage

Write the command **without** the manager: npm's `install` and each manager's
`dlx` spelling are substituted.

::preview
:::package-managers{command="add -D @kirchdev/duxt"}
:::

#code
```mdc
::package-managers{command="add -D @kirchdev/duxt"}
::
```
::

## API

### Props

| Prop       | Type       | Default                | Notes                                  |
| :--------- | :--------- | :--------------------- | :------------------------------------- |
| `command`  | `string`   | required               | Without the manager — `add -D pkg`     |
| `managers` | `string[]` | `duxt.packageManagers` | Overrides the site's list for one block |

## Notes

The choice is a cookie, not browser storage, and deliberately: storage is read
after hydration, so the block would render one manager and then swap to another
in front of the reader. It is first-party, identifies nobody and carries a value
the reader picked — see
[`usePackageManager()`](/reference/composables/reading/use-package-manager).

A block may list fewer managers than the reader's choice covers; it falls back to
its own first tab rather than showing nothing.
