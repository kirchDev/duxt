Each command answers `--help` with its options, even on a site that was never
built. That output is the authoritative list, so this page only says what each
command is for.

| Command             | What it is for                                                            | Explained in                                                 |
| :------------------ | :------------------------------------------------------------------------ | :----------------------------------------------------------- |
| `duxt report`       | Prints sources, checks and redirects as Markdown, or as data with `--json` | [Build checks](/concepts/build-checks)                       |
| `duxt content pack` | Builds an immutable content bundle without compiling the app              | [Pack content bundles](/guides/pack-content-bundles)         |
| `duxt-cache-key`    | Prints the cache key and paths for remote Content sources                 | [Cache build work](/guides/cache-build-work)                 |
| `duxt-og-cache`     | Prints the rendered-image cache key, or reports what a build reused       | [Cache build work](/guides/cache-build-work)                 |

Run them through your package manager, for example `pnpm exec duxt report`. `duxt
report` needs a site that has been prepared or built, because it reads the layer
metadata that step records.
