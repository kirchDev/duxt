---
title: Changelog
description: A release log, published as pages — a timeline, a page per release, and a feed.
icon: lucide:tag
---

Point a source at the file your release tool writes and duxt builds a history out
of it — an overview with every release on a timeline, and a page per release with
a deep link, a search hit, a feed item and an `llms.txt` entry of its own.

It reads what release-please writes, and is deliberately tolerant beyond that: a
heading is a release when it begins with something that looks like a version, so
a hand-kept `## 1.4.0` and a Keep a Changelog file read too.
