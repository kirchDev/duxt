## Signature

```ts
const path = useDuxtPath();
```

## Returns

The current route path with the locale segment removed — the path as the
documentation knows it.

## Notes

Everything that reasons about pages reasons about this, not about `route.path`:
`/de/duxt/getting-started` and `/duxt/getting-started` are the same page.
