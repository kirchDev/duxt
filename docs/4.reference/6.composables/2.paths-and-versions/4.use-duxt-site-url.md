## Signature

```ts
const { origin, absolute } = useDuxtSiteUrl();
```

## Returns

| Value      | Type       | What it is                       |
| :--------- | :--------- | :------------------------------- |
| `origin`   | `string`   | The site configured origin       |
| `absolute` | `function` | A path, made absolute against it |

## Notes

Needed wherever a URL leaves the page — a feed item, a canonical tag, an OG
image. Inside the page, use a path.
