The inverse of [`useDuxtPath()`](/reference/composables/paths-and-versions/use-duxt-path).

## Signature

```ts
const localeLink = useDuxtLink();

localeLink('/getting-started');
```

## Returns

A function that puts the locale prefix back on a documentation path, and leaves
an absolute URL alone.

## Notes

Use it for every `to` a replaced component renders. A path written by hand in a
component is correct in one language and wrong in the other six.
