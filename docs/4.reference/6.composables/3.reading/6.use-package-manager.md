## Signature

```ts
const manager = usePackageManager();
```

## Notes

A cookie rather than browser storage, and deliberately: storage is read after
hydration, so a command block would render one manager and then swap to another
in front of the reader. It is first-party, identifies nobody and carries a value
the reader chose.
