---
title: useDuxtToast()
description: Notifications, wrapped so no component imports the library.
icon: lucide:bell
---

## Signature

```ts
const notify = useDuxtToast();

notify.success(t('duxt.code.copiedToast'));
```

## Returns

`{ success, info, warning, error, loading, dismiss }`.

## Notes

The wrapper is the seam: a consumer that wants a different notification system
replaces this one composable instead of every call site, and the layer own
components keep working.
