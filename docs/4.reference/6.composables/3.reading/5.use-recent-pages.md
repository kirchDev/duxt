---
title: useRecentPages()
description: The most recent pages this reader opened, up to the configured limit.
icon: lucide:history
---

## Signature

```ts
const { recent, remember, load } = useRecentPages(limit);
```

## Notes

Kept in the browser, not in a cookie: it is never needed during server rendering,
so it travels with no request.

`limit` defaults to five. The search dialog passes `duxt.search.recentPages`, so
a site can choose another bound; `0` hides the list and stores no newly visited
pages.
