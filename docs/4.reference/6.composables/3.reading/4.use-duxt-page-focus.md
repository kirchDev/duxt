---
title: useDuxtPageFocus()
description: Moves focus to the heading after a client-side navigation.
icon: lucide:focus
---

## Signature

```ts
useDuxtPageFocus();
```

## Notes

A client-side route change replaces the document without moving focus, so a
screen reader keeps reading the old page and a keyboard tab continues where the
last page left off. This puts focus on the new page heading.
