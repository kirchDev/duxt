---
title: <page>.md
description: Any page source, at its own URL plus .md.
icon: lucide:file-code
---

Append `.md` to any documentation URL and the response is the Markdown that page
was rendered from.

```
/duxt/getting-started      → the page
/duxt/getting-started.md   → its source
```

## Notes

It is a **middleware, not a route**, because `.md` is a suffix on the last
segment rather than a segment of its own — a route file cannot match it.

A reader never has to append it by hand. Every page advertises its own twin from
its head with `<link rel="alternate" type="text/markdown">`, next to a
`rel="describedby"` naming the `/llms.txt` that covers it — see
[Machine readers](/concepts/machine-readers).

This is what [`DuxtCopyPage`](/reference/components/page/duxt-copy-page) hands to
a model: the source, not the rendered page.
