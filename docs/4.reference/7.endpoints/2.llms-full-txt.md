duxt extension: every page of the default version, in full, concatenated. It is
available beside `/llms.txt`, but is not part of the llms.txt specification.

## Response

`text/plain`, one document.

## Notes

The index and the full text answer two different questions: an agent that can
fetch follows [`/llms.txt`](/reference/endpoints/llms-txt) page by page, and one
that cannot takes the whole thing at once.

The frontmatter is stripped from each page — what is served reads as the
documentation rather than as the files it came from.
