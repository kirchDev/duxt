A Model Context Protocol endpoint, so an agent can query the documentation
instead of scraping it.

## Tools

| Tool          | What it does                          |
| :------------ | :------------------------------------ |
| `list_pages`  | The table of contents                 |
| `search_docs` | Find a page by term                   |
| `read_page`   | The full text of one page             |

## Notes

Same collections as the pages, so the answers cannot drift from what is
published. The server name, description and instructions come from the module
options.
