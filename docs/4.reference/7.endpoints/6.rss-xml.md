## Response

`application/rss+xml`, built from the section `duxt.feed.path` names.

## Notes

It answers **empty rather than 404** before it is configured: a feed client should
be told there is nothing here, not that the feed is gone.

Off by default, because a feed is a list of things that happened, and a reference
page being edited is not an event.
