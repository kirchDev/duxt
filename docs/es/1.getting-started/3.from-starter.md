---
title: Empezar con el starter
description: Crea con Nuxi un sitio de documentación duxt listo para ejecutar.
icon: lucide:rocket
---

El [starter de duxt](https://github.com/kirchDev/duxt-starter) es un sitio de
documentación pequeño con una página de inicio y una sección de primeros pasos.
Nuxi lo copia, instala sus dependencias y crea su repositorio de Git:

```bash
npx nuxi@latest init my-docs -t github:kirchDev/duxt-starter --gitInit --packageManager pnpm
cd my-docs
pnpm dev
```

Abre la dirección que muestra Nuxt y después edita los archivos en `docs/`. La
navegación y la vista previa de la página de inicio se actualizan con tus
páginas. Para un proyecto que ya existe, usa [Instalación](/getting-started/installation).
