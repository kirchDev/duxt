## Escribir tu documentación

El Markdown va en `docs/`, en la raíz de tu repositorio — resuelto contra el
repositorio y no contra el directorio donde se ejecuta el sitio, de modo que un
sitio en una subcarpeta lo encuentra. Un archivo es una página, una carpeta es
una sección, y el frontmatter lleva el título, la descripción y el icono.

::file-tree{title="tu-proyecto/"}
---
tree:
  - name: docs/
    children:
      - name: index.md
      - name: 1.getting-started/
        children:
          - name: index.md
          - name: 1.installation.md
      - name: 2.guides/
        children:
          - name: 1.deploying.md
  - name: nuxt.config.ts
---
::

```md [docs/1.getting-started/index.md]
---
title: Introducción
description: Qué es este proyecto.
icon: lucide:rocket
---

Tu primera página.
```

Un prefijo numérico ordena el árbol y se elimina de la URL:
`1.getting-started/` se sirve en `/getting-started`. Reordenar una sección nunca
mueve una URL — solo renombrar la parte posterior al punto lo hace.

::callout{type="tip" title="Sin H1 en el cuerpo"}
El `title` de la página se representa como el `<h1>`. Un encabezado propio al
principio del archivo sería el segundo de la página.
::

## Qué necesita la compilación

- **Node 24.** La capa lee su base de datos mediante `node:sqlite`, así que no
  se instala ni hace falta ningún controlador nativo de SQLite.
- **Acceso de red a tus fuentes**, si alguna es otro repositorio, y un token
  para las privadas — Content lo lee del `auth` de la colección.

## Qué viene incluido

El paquete trae un comando, `duxt`, y extender la capa es todo lo que
hace falta para tenerlo:

```bash
pnpm exec duxt report            # en qué se convirtieron tus fuentes, como Markdown
pnpm exec duxt report --json     # lo mismo, sin representar
pnpm exec duxt report --help     # qué acepta y con qué código sale
```

Imprime las colecciones resueltas, todo lo que comprueba la compilación y las
redirecciones que declaran las páginas — sin servidor de desarrollo, así que se
ejecuta en CI y en una tubería. Véase
[Qué comprueba la compilación](/concepts/build-checks).

## Resultado

`nuxt dev` sirve el sitio. Todo lo que dibuja el tema son datos con un valor por
defecto, así que el siguiente paso es el único archivo que lo sobrescribe:
