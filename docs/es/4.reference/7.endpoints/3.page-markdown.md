Añade `.md` a cualquier URL de la documentación y la respuesta es el Markdown a
partir del cual se representó esa página.

```
/duxt/getting-started      → la página
/duxt/getting-started.md   → su código fuente
```

## Notas

Es un **middleware, no una ruta**, porque `.md` es un sufijo del último segmento
y no un segmento propio — un archivo de ruta no puede coincidir con él.

Quien lee nunca tiene que añadirlo a mano. Cada página anuncia su propio gemelo
desde su head con `<link rel="alternate" type="text/markdown">`, junto a un
`rel="describedby"` que nombra el `/llms.txt` que la cubre — ver
[Lectores automáticos](/concepts/machine-readers).

Esto es lo que [`DuxtCopyPage`](/reference/components/page/duxt-copy-page) le
entrega a un modelo: el código fuente, no la página representada.
