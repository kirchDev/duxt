## Notas

El índice y el texto completo responden a dos preguntas distintas: un agente que
puede descargar sigue [`/llms.txt`](/reference/endpoints/llms-txt) página a
página, y uno que no puede se lleva el conjunto entero de una vez.

El frontmatter se elimina de cada página — lo que se sirve se lee como la
documentación y no como los archivos de los que vino.
