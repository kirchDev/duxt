Una sola entrada, con su icono, su estado activo y — si es una rama — sus
hijos.

## Uso

```vue
<DuxtNavigationLink :item="item" />
```

## API

### Props

| Prop   | Tipo                     | Notas                              |
| :----- | :----------------------- | :--------------------------------- |
| `item` | `ContentNavigationItem`  | Obligatorio — un nodo del árbol     |

## Notas

Merece la pena reemplazarlo por su cuenta cuando lo único que falla es el
aspecto de una entrada: ensombrecer este deja el árbol, el estado activo y el
plegado a
[`DuxtNavigation`](/reference/components/navigation/duxt-navigation).
