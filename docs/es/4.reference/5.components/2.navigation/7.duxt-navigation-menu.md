---
title: DuxtNavigationMenu
description: El menú que abre una entrada de la barra, en cualquiera de sus filas.
icon: lucide:menu
---

Lo que se abre desde una entrada con `children`: un desplegable anidado tanto
como los datos o un panel de megamenú. La fila dibuja su propio activador en el
slot, porque las dos filas no se parecen.

## Uso

```vue
<DuxtNavigationMenu :link="entry" align="start">
  <button type="button">{{ entry.label }}</button>
</DuxtNavigationMenu>
```

## API

### Props

| Nombre | Tipo | Por defecto | Descripción |
| :-- | :-- | :-- | :-- |
| `link` | `DuxtLink` | | La entrada a la que pertenece este menú |
| `align` | `start` \| `center` \| `end` | `center` | Cómo se alinea un desplegable con su activador. Un megamenú siempre se centra en la página |

### Slot

`default`: El activador, como un único elemento.

## Notas

Cómo configurar un menú está en [Crear menús de la
barra](/guides/build-navbar-menus). Para cambiar el estilo de todas las entradas
a la vez, sustituye `DuxtNavigationMenuEntry`, que dibuja el contenido de una
entrada; `component` en el enlace hace lo mismo para una sola.
