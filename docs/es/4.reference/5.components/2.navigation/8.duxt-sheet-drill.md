Guarda el primer nivel del panel en su slot y dibuja cada menú abierto desde él
como un nivel encima, de modo que un menú de cualquier profundidad conserva todo
el ancho del panel.

## Uso

```vue
<DuxtSheetDrill ref="levels">
  <!-- El primer nivel -->
</DuxtSheetDrill>
```

## API

### Slot

`default`: El primer nivel.

### Expuesto

| Nombre | Tipo | Descripción |
| :-- | :-- | :-- |
| `drill` | `(link: DuxtLink, event: Event) => void` | Abre el menú de `link` como un nivel nuevo. Al volver, el foco regresa al elemento del que vino `event` |

## Notas

`DuxtHeader` lo dibuja dentro del panel y `DuxtSheetLinks` dibuja los enlaces de
un nivel. En el nivel de un megamenú, una columna no es otro nivel: está bajo su
nombre, como en el panel. Los niveles desaparecen al cerrarse el panel, así que
siempre se abre en el primero.
