Los encabezados de la página actual, siguiendo al lector mientras se desplaza,
más los enlaces `aside` configurados debajo.

## Uso

```vue
<DuxtToc :links="page?.body?.toc?.links ?? []" />
```

## API

### Props

| Prop    | Tipo        | Notas                                    |
| :------ | :---------- | :--------------------------------------- |
| `links` | `TocLink[]` | Obligatorio — los enlaces toc de Content  |

## Notas

Qué encabezado es el actual viene de
[`useActiveHeading()`](/reference/composables/reading/use-active-heading), que
observa los encabezados en lugar del desplazamiento — una última sección corta
se sigue anunciando como alcanzada.

El bloque `aside.links` de debajo se entrega **vacío**: un enlace al
repositorio, un gestor de incidencias o una comunidad son de quien gestiona el
sitio.
