La fila de secciones bajo la cabecera, solo en las páginas de documentación.

## Uso

```vue
<DuxtSections />
```

## API

Sin props. Lee `sections`; no representa nada cuando esa lista está vacía.

## Notas

Está con la documentación en lugar de en la cabecera global, porque la portada
no tiene secciones que mostrar.

Una sección rara vez es la página misma — es la rama en la que está la página.
Así que la coincidencia exacta anuncia `aria-current="page"` y un ancestro
anuncia `true`, que es la distinción para la que existe `aria-current`.
