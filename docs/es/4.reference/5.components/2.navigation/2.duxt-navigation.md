La lista anidada de páginas de la sección actual.

## Uso

```vue
<script setup lang="ts">
const { data: navigation } = await useDuxtNavigation();
const { items } = useDuxtSection(navigation);
</script>

<template>
  <DuxtNavigation :items="items" />
</template>
```

## API

### Props

| Prop    | Tipo                       | Notas                                       |
| :------ | :------------------------- | :------------------------------------------ |
| `items` | `ContentNavigationItem[]`  | Obligatorio — una rama del árbol de Content  |

## Notas

El árbol viene de [`useDuxtNavigation()`](/reference/composables/config-and-content/use-duxt-navigation),
que pregunta a la colección que sirve la ruta actual — así que un sitio
versionado obtiene el árbol de esa versión, no el de la versión por defecto.
