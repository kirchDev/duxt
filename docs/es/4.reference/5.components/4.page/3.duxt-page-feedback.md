El bloque al pie de cada página.

## Uso

```vue
<DuxtPageFeedback @feedback="(helpful) => track(helpful)" />
```

## API

### Emits

| Evento     | Payload             | Cuándo                     |
| :--------- | :------------------ | :------------------------- |
| `feedback` | `helpful: boolean`  | El lector responde          |

### Slots

| Slot      | Props                 | Qué sustituye             |
| :-------- | :-------------------- | :------------------------ |
| `default` | `{ answered, answer }` | La pregunta y los botones |

## Notas

Un slot con un evento y ningún backend, y ese es todo el diseño. La capa no
almacena nada y no envía nada: no le corresponde saber dónde vive la analítica
de quien la consume, y un tema de documentación que llama a casa por defecto no
es un tema que se pueda publicar. La respuesta vive en el estado propio del
componente mientras dura la visita y en ningún sitio más — un cambio de ruta la
reinicia, porque una página nueva es una pregunta nueva.

Conectarla tiene su propia guía:
[Recoger opiniones de página](/guides/collect-page-feedback).
