Un control dividido junto al título de la página: copiar el Markdown, verlo o
abrirlo en un modelo de chat.

## Uso

```vue
<DuxtCopyPage :path="path" :title="page?.title" :rawbody="page?.rawbody" />
```

## API

### Props

| Prop      | Tipo     | Notas                                              |
| :-------- | :------- | :-------------------------------------------------- |
| `path`    | `string` | Obligatorio — la ruta de la documentación           |
| `title`   | `string` | Se usa en el prompt que se entrega a un modelo      |
| `rawbody` | `string` | El código fuente Markdown, para el botón de copiar  |

## Notas

Un control dividido en lugar de cuatro botones — el caso habitual es
«copiarlo», y los otros tres son la misma intención por otra puerta.

Lo que todos ellos entregan es el **Markdown**, no la página representada: a un
modelo al que le das HTML le toca deshacer una maquetación para encontrar un
encabezado, y uno al que le das el código fuente lee lo que escribió quien la
redactó. El frontmatter se elimina, así que lo que se copia se lee como la
página y no como el archivo.

Los enlaces externos necesitan una URL absoluta, y el origen se lee del
navegador en el momento del clic en lugar de la configuración — el único valor
que seguro que es correcto, incluido un despliegue de vista previa cuyo dominio
nadie apuntó.
