El marco en el que se dibuja todo bloque delimitado: nombre de archivo, icono de
lenguaje, botón de copiar.

## Uso

Lo invoca [`ProsePre`](/reference/mdc-components/prose/prose-pre) en lugar de
escribirse a mano, pero se puede usar directamente:

```vue
<DuxtCodeBlock code="pnpm add -D @kirchdev/duxt" language="bash" />
```

## API

### Props

| Prop       | Tipo     | Notas                                                            |
| :--------- | :------- | :--------------------------------------------------------------- |
| `code`     | `string` | El código fuente en bruto, para el botón de copiar y como cuerpo  |
| `language` | `string` | Elige el icono                                                    |
| `filename` | `string` | La etiqueta de la cabecera                                        |

### Slots

| Slot      | Qué va dentro                             |
| :-------- | :---------------------------------------- |
| `default` | El marcado resaltado, cuando lo hay       |

## Notas

Sin nombre de archivo, el botón de copiar flota en la esquina y aparece al pasar
el ratón; con uno, se asienta en la cabecera, donde siempre está visible. Un
bloque que muestra siempre un botón en la esquina de la página es más ruidoso
que uno que lo enseña cuando el lector va a buscarlo.
