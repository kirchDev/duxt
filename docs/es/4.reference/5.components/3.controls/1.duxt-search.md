El campo de búsqueda y su diálogo, abiertos con el botón o con <kbd>⌘K</kbd>.

## Uso

```vue
<DuxtSearch />
```

## API

Sin props. Construido sobre
[`useDuxtSearch()`](/reference/composables/reading/use-duxt-search).

## Notas

Los resultados abarcan todas las fuentes y se clasifican juntos, así que un
término que aparece en dos repositorios se responde desde ambos. Cuando nada
coincide exactamente, la lista recae en las coincidencias aproximadas de
[`useFuzzySearch()`](/reference/composables/reading/use-fuzzy-search) y lo dice —
una errata debería devolver la página, no una caja vacía.
