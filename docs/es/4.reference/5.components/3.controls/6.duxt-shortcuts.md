La superposición que lista cada tecla que asigna el tema, abierta con
<kbd>?</kbd>.

## Uso

```vue
<DuxtShortcuts />
```

## API

Sin props.

## Notas

Su lista es `duxtShortcuts` — el mismo array contra el que comparan los
manejadores —, así que la hoja no puede llegar a anunciar una tecla que nada
asigna. Véase
[`useDuxtShortcuts()`](/reference/composables/reading/use-duxt-shortcuts).
