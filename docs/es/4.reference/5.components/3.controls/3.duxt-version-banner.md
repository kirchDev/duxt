Se muestra sobre la página cuando la versión que se está leyendo no es la
predeterminada.

## Uso

```vue
<DuxtVersionBanner />
```

## API

Sin props. Lee
[`useDuxtVersion()`](/reference/composables/paths-and-versions/use-duxt-version).

## Notas

La mitad visible del problema de las versiones. `canonical` y `noindex` le dicen
a un rastreador qué versión servir; al lector no le dicen nada. Quien llegó a la
v0.7.0 desde un resultado de búsqueda, o desde un enlace en una incidencia
antigua, ve una documentación que parece exactamente la actual. Cualquiera de
las dos mitades por separado deja a un público equivocado, así que las etiquetas
del head y este aviso se entregan juntos.

A una versión `upcoming` se le dice que su documentación aún puede cambiar, y
**no** se le dice que actualice — ese es el único estado al que nunca se debe
llegar adivinando.
