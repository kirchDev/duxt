## Firma

```ts
const { collection, source, sources } = useDuxtCollection();
```

## Devuelve

| Valor        | Tipo     | Qué es                                             |
| :----------- | :------- | :------------------------------------------------- |
| `collection` | `string` | El nombre de la colección que sirve la ruta actual  |
| `source`     | `object` | La fuente resuelta que hay detrás                   |
| `sources`    | `array`  | Todas las fuentes resueltas                         |

## Notas

`collection` es una **cadena**, no un tipo literal — los nombres de colección de
un sitio se generan a partir de sus propias fuentes, así que nada en la capa
puede nombrarlos. Pásalo a `queryCollection` en lugar de escribir `'docs'`.
