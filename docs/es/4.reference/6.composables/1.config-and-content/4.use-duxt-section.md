## Firma

```ts
const { section, items } = useDuxtSection(navigation);
```

## Devuelve

| Valor     | Tipo     | Qué es                                           |
| :-------- | :------- | :----------------------------------------------- |
| `section` | `object` | La sección configurada bajo la que cae la página  |
| `items`   | `array`  | La rama del árbol de esa sección                  |

## Notas

Sin `sections` configuradas vuelve el árbol entero, que es la forma correcta para
una documentación que no está dividida en partes.
