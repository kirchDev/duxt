## Firma

```ts
const { data: navigation } = await useDuxtNavigation();
```

## Devuelve

Un manejador de `useAsyncData` sobre el árbol de navegación de la colección que
sirve la ruta actual.

## Notas

Preguntar por ruta en lugar de una sola vez para todo el sitio es lo que hace
correcto un árbol versionado: leer `v0.7.0` obtiene las páginas de esa versión,
no las de la versión por defecto.
