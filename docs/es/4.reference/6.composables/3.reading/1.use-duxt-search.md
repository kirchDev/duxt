---
title: useDuxtSearch()
description: Busca en cada fuente activa e intercala sus resultados clasificados localmente.
icon: lucide:search
---

## Firma

```ts
const { search, init, labelled } = useDuxtSearch();
```

## Devuelve

| Valor      | Qué es                                                               |
| :--------- | :------------------------------------------------------------------- |
| `search`   | Ejecutar una consulta, en todas las fuentes                          |
| `init`     | Construir el índice; se llama cuando el diálogo abre por primera vez |
| `labelled` | Resultados que llevan la fuente de la que vinieron                   |

## Notas

El índice se construye en el primer uso, no al cargar la página: un lector que
nunca busca nunca paga por él.

Content clasifica cada colección por separado. Como las puntuaciones no son
comparables entre colecciones, el composable intercala las listas por posición
y pone primero en cada ronda la fuente que se está leyendo. `labelled` conserva
la procedencia con la que la interfaz explica esa mezcla.
