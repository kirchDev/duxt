---
title: useDuxtToast()
description: Notificaciones, envueltas para que ningún componente importe la biblioteca.
icon: lucide:bell
---

## Firma

```ts
const notify = useDuxtToast();

notify.success(t('duxt.code.copiedToast'));
```

## Devuelve

`{ success, info, warning, error, loading, dismiss }`.

## Notas

La envoltura es la costura: quien la consume y quiere otro sistema de
notificaciones sustituye este único composable en lugar de cada punto de
llamada, y los componentes propios de la capa siguen funcionando.
