---
title: useActiveHeading()
description: El encabezado que está ahora a la vista.
icon: lucide:heading
---

## Firma

```ts
const active = useActiveHeading(ids);
```

## Devuelve

El id del encabezado en el que está el lector ahora mismo.

## Notas

Observa los encabezados en lugar del desplazamiento, así que una última sección
corta se sigue anunciando como alcanzada — el fallo habitual de una tabla de
contenidos que va por posición de scroll.
