## Firma

```ts
const { shortcuts, keys, on } = useDuxtShortcuts();

on('help', () => open());
```

## Notas

El único sitio que sabe qué teclas están asignadas, así que la superposición en
`?` y los manejadores no pueden contradecirse. `shortcuts` es la lista que deja
viva la política `shortcuts.singleCharacter` del sitio, `keys()` dibuja una
asignación para el teclado del lector (`⌘` o `Ctrl`), y `on()` asigna una acción
con todas las guardas que necesita una asignación global — nunca mientras el
lector escribe, nunca dentro de un diálogo o un menú, nunca si algo más cercano
ya ha atendido la tecla y, para las teclas sin modificador, solo mientras el
contenido de la página tiene el foco.
