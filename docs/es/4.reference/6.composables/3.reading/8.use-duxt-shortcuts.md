## Firma

```ts
const shortcuts = useDuxtShortcuts();

onDuxtShortcut('k', () => open());
```

## Notas

El único sitio que sabe qué teclas están asignadas, así que la superposición en
`?` y los manejadores no pueden contradecirse. `onDuxtShortcut()`, a su lado,
asigna una tecla con las guardas que necesita toda asignación — incluida la de
no dispararse nunca mientras el lector está escribiendo.
