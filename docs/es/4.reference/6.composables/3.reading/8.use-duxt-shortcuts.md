## Firma

```ts
const { shortcuts, keys, hint, on } = useDuxtShortcuts();

on('help', () => open());
```

```ts
const { open, toggle } = useDuxtShortcutSheet();
```

## Notas

El único sitio que sabe qué teclas están asignadas, así que la superposición en
`?` y los manejadores no pueden contradecirse. `shortcuts` es la lista que deja
viva la política `shortcuts.singleCharacter` del sitio, `keys()` dibuja una
asignación para el teclado del lector (`⌘` o `Ctrl`), y `on()` asigna una acción
con todas las guardas que necesita una asignación global — nunca mientras el
lector escribe, nunca dentro de un diálogo o un menú, nunca si algo más cercano
ya ha atendido la tecla y, para las teclas sin modificador, solo mientras el
contenido de la página tiene el foco.

`hint()` es `keys()` para un control en lugar de para la hoja: toma una acción,
devuelve las teclas como una sola cadena —`⌘K`, `Ctrl+K`, `]`— y devuelve
`undefined` donde la política desvinculó esa acción, de modo que una plantilla
escribe `v-if` y no dibuja ninguna cápsula vacía. Es lo que imprimen el botón de
búsqueda y los enlaces a las páginas contiguas.

`useDuxtShortcutSheet()` es el estado abierto de la hoja, compartido en vez de
poseído por ella, porque `?` no es la única entrada: el disparador de la cabecera
abre el mismo diálogo, y en un sitio con `shortcuts.singleCharacter: false` es lo
único que puede hacerlo. Véase
[Atajos de teclado](/concepts/keyboard-shortcuts).
