---
title: useRecentPages()
description: Las páginas abiertas más recientemente, hasta el límite configurado.
icon: lucide:history
---

## Firma

```ts
const { recent, remember, load } = useRecentPages(limit);
```

## Notas

Se guarda en el navegador, no en una cookie: nunca hace falta durante el
renderizado en servidor, así que no viaja con ninguna petición.

El límite predeterminado es cinco. El diálogo usa `duxt.search.recentPages`; `0`
oculta la lista y no guarda páginas nuevas.
