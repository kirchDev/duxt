---
title: usePackageManager()
description: El gestor de paquetes que eligió un lector.
icon: lucide:package
---

## Firma

```ts
const manager = usePackageManager();
```

## Notas

Una cookie en lugar de almacenamiento del navegador, y a propósito: el
almacenamiento se lee después de la hidratación, así que un bloque de comando
representaría un gestor y luego cambiaría a otro delante del lector. Es propia,
no identifica a nadie y lleva un valor que eligió el lector.
