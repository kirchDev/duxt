## Firma

```ts
const { search } = useFuzzySearch(collection, {
  ignoredTags: ['table'], threshold: 0.35, minMatchCharLength: 3, limit: 20
});
```

## Devuelve

Una función de búsqueda que puntúa las coincidencias aproximadas.

## Notas

Solo se ejecuta cuando la búsqueda exacta no devuelve nada, y la interfaz lo
dice — un lector que cometió una errata debería obtener la página, pero también
debería saber que eso fue exactamente lo que pasó.

`collection` vale `docs` por defecto. `ignoredTags` llega a las secciones de
búsqueda de Content; umbral y longitud mínima ajustan Fuse y `limit` acota los
resultados. Los valores del sitio están en `duxt.search.fuzzy`.
