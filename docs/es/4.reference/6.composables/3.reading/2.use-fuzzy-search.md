icon: lucide:spell-check

## Firma

```ts
const { search } = useFuzzySearch(items);
```

## Devuelve

Una función de búsqueda que puntúa las coincidencias aproximadas.

## Notas

Solo se ejecuta cuando la búsqueda exacta no devuelve nada, y la interfaz lo
dice — un lector que cometió una errata debería obtener la página, pero también
debería saber que eso fue exactamente lo que pasó.
