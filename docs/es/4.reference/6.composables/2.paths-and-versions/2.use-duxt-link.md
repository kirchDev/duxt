El inverso de [`useDuxtPath()`](/reference/composables/paths-and-versions/use-duxt-path).

## Firma

```ts
const localeLink = useDuxtLink();

localeLink('/getting-started');
```

## Devuelve

Una función que vuelve a poner el prefijo de locale en una ruta de
documentación, y deja en paz una URL absoluta.

## Notas

Úsala para cada `to` que renderice un componente reemplazado. Una ruta escrita a
mano en un componente es correcta en un idioma y errónea en los otros seis.
