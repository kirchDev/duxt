## Firma

```ts
const version = useDuxtVersion();
```

## Devuelve

| Valor           | Qué responde                                   |
| :-------------- | :--------------------------------------------- |
| `sources`       | Todas las versiones del repositorio que se lee  |
| `current`       | La versión a la que pertenece esta página       |
| `preferred`     | La versión en la que debería estar un lector    |
| `isPreferred`   | Si esas dos son la misma                        |
| `status`        | Su ciclo de vida — upcoming, current, eol …     |
| `kind`          | Rama o etiqueta                                 |
| `shouldIndex`   | Si la página pide ser indexada                  |
| `shouldWarn`    | Si se muestra el aviso                          |
| `preferredPath` | Esta misma página, en la versión preferida      |

## Notas

Tres preguntas desde un solo sitio — qué muestra el selector, qué dice el aviso
y si la página pide ser indexada — porque son la misma pregunta sobre la misma
versión.
