## Firma

```ts
const { origin, absolute } = useDuxtSiteUrl();
```

## Devuelve

| Valor      | Tipo       | Qué es                             |
| :--------- | :--------- | :--------------------------------- |
| `origin`   | `string`   | El origen configurado del sitio    |
| `absolute` | `function` | Una ruta, hecha absoluta contra él |

## Notas

Necesario allí donde una URL sale de la página — un elemento de feed, una
etiqueta canonical, una imagen OG. Dentro de la página, usa una ruta.
