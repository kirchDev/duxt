---
title: Referencia de la API
description: Un documento OpenAPI, publicado como páginas de referencia con un cliente que envía peticiones reales.
icon: lucide:plug
---

Apunta una fuente a un documento OpenAPI y duxt construye una referencia a partir
de él — una visión general, una página por etiqueta, una página por operación —
con un cliente en cada página de operación que envía la petición desde el propio
navegador del lector.

Las páginas son una colección ordinaria, y ahí está todo el punto: la búsqueda las
encuentra, `llms.txt` las lista, el sitemap las lleva, el selector de versiones se
mueve entre ellas. Nada de esto es una segunda ruta de renderizado.
