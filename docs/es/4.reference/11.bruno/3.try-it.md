title: El cliente de peticiones
description: Apagado por defecto y dirigido solo a destinos declarados públicos.
icon: lucide:send-horizontal
---

```ts
options: { tryIt: { baseUrl: 'https://api.example.com', variables: { tenant: 'demo' } } }
```

Sin `baseUrl`, la página es estática. `/` usa el mismo origen que la
documentación. `variables` es una lista permitida; si queda una variable
desconocida en la URL no aparece el cliente. Los parámetros de ruta siguen
siendo editables. Los valores viven solo en el estado del componente y la
petición va directamente del navegador a la API.
