---
title: Obtener la colección
description: El archivo está fijado a la versión y el idioma; el enlace de Bruno no.
icon: lucide:download
---

El resumen enlaza un ZIP creado durante la build para la versión e idioma
visibles, sin `environments/`. Una fuente remota descargada por Content no
obtiene archivo porque su ubicación de caché no se vuelve a leer fuera de la
colección.

`options.fetch` añade **Fetch in Bruno** para una URL git pública. No carga
scripts de terceros, pero clona la rama predeterminada y no sustituye al archivo
versionado.
