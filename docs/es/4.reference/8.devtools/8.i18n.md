Siete idiomas y un archivo JSON por espacio de nombres hacen que la deriva sea
cuestión de tiempo — y vue-i18n responde a una clave que falta imprimiendo la
clave, así que un hueco aflora como un botón etiquetado `duxt.nav.open` en una
página que nadie abrió en ese idioma.

::devtools-panel{tab="i18n"}
::

## Columnas

| Columna           | Qué dice                                                         |
| :---------------- | :----------------------------------------------------------------- |
| `Directory`       | Una carpeta bajo `i18n/locales`; `base` marca la de comparación     |
| `Keys`            | Cuántas claves define en total                                      |
| `Missing vs base` | Claves que tiene la base y esta no                                  |
| `Not in base`     | Claves que tiene esta y la base no — normalmente un renombrado      |

## Notas

**Faltar es un hecho, no un veredicto.** Un archivo de idioma puede contener a
propósito solo sus desviaciones: `pt-BR` sobrescribe un puñado de cadenas y lee el
resto de `pt` por el fallback al idioma base, así que una lista larga en «missing»
ahí es el diseño funcionando.

**«Not in base» se lee dos veces.** Una clave que no tiene nadie más suele ser una
errata o un renombrado que se quedó a medias, y se imprimirá ella misma en la
página.

La línea sobre la tabla lista los idiomas que el sitio sirve de verdad, que es una
lista distinta de las carpetas en disco: varios idiomas pueden compartir una.
