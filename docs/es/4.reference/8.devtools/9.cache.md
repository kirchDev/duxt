---

Cada fuente remota se clona en `.data/content` y se queda ahí. Nada en una
compilación menciona ese directorio, así que nada lo sugiere cuando algo va mal.

::devtools-panel{tab="cache"}
::

## Por qué importa

Un directorio obsoleto costó aquí tiempo real una vez: se pidió una etiqueta como
si fuera una rama, la descarga falló, y la carpeta a medio escribir siguió
respondiendo para la configuración ya corregida hasta que alguien la borró a mano.
La compilación no dijo nada, porque para ella la fuente ya estaba descargada.

**Drop** elimina una entrada; la siguiente compilación la descarga de nuevo.

## Notas

Content indexa un directorio por repositorio **y** ref, así que una entrada de una
ref que has renombrado no se reutiliza nunca — y tampoco se limpia nunca. Este
panel es donde se encuentran.

::callout{type="warning"}
Tirar una entrada borra un directorio de tu disco. Siempre es solo la caché —
nunca una fuente de verdad —, pero es un borrado real, y es la razón por la que
esta pestaña no se registra en una compilación.
::
