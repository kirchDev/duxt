Una sección dentro de [`::accordion`](/reference/mdc-components/accordion).

## Uso

```mdc
:::accordion
  ::accordion-item{label="¿Por qué una capa y no un módulo?" icon="lucide:layers"}
  Un módulo no puede entregar páginas, un tema ni un valor por defecto de app.config.
  ::
:::
```

## API

### Props

| Prop    | Tipo     | Por defecto | Notas                                             |
| :------ | :------- | :---------- | :------------------------------------------------ |
| `label` | `string` | —           | El texto del trigger                              |
| `icon`  | `string` | —           | Cualquier nombre de Iconify, antes de la etiqueta |

### Slots

| Slot      | Qué va dentro               |
| :-------- | :-------------------------- |
| `default` | La respuesta, como Markdown |
