Varios bloques de código mostrados como un solo bloque, con una pestaña cada
uno. La etiqueta de cada pestaña es el propio nombre de archivo del bloque,
porque es entre eso entre lo que elige el lector y ya está escrito.

## API

Sin props. Un bloque sin nombre de archivo recibe su lenguaje como etiqueta.

### Slots

| Slot      | Qué va dentro                  |
| :-------- | :----------------------------- |
| `default` | Una serie de bloques de código |

## Notas

Los hijos se leen de los VNodes del slot por defecto en lugar de registrarse
desde un componente hijo: un bloque de código es un `ProsePre`, no algo a lo que
este bloque pueda pedirle que se anuncie, y su nombre de archivo es una prop de
ese nodo.

Para cualquier cosa que no sea código, usa
[Grupo de pestañas](/reference/mdc-components/tab-group).
