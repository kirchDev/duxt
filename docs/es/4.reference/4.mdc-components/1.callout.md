Un apunte al margen en una de cuatro variantes. El cuerpo es Markdown, así que
dentro funcionan enlaces, `code` y listas.

## Uso

::preview
:::callout{type="tip" title="No hace falta nada más"}
El cuerpo también es Markdown — dentro funcionan enlaces, `code` y listas.
:::

#code
```mdc
::callout{type="tip" title="No hace falta nada más"}
El cuerpo también es Markdown — dentro funcionan enlaces, `code` y listas.
::
```
::

## Tipos

::preview
:::callout{type="info"}
`info` — el predeterminado, para el contexto que la página da por sabido.
:::

:::callout{type="tip"}
`tip` — algo que facilita la tarea.
:::

:::callout{type="warning"}
`warning` — una forma de equivocarse con esto.
:::

:::callout{type="danger"}
`danger` — pérdida de datos, o un cambio que no se puede deshacer.
:::

#code
```mdc
::callout{type="info"}
`info` — el predeterminado, para el contexto que la página da por sabido.
::
```
::

## API

### Props

| Prop    | Tipo                                  | Por defecto | Notas                                            |
| :------ | :------------------------------------ | :---------- | :----------------------------------------------- |
| `type`  | `info` · `tip` · `warning` · `danger` | `info`      | Elige el color, el icono y el rol                 |
| `title` | `string`                              | —           | Primera línea en negrita; después sigue el cuerpo |
| `icon`  | `string`                              | según tipo  | Cualquier nombre de Iconify, sobrescribiendo el predeterminado |

### Slots

| Slot      | Qué va dentro            |
| :-------- | :----------------------- |
| `default` | El cuerpo, como Markdown |

## Notas

Un callout `danger` lleva `role="alert"`; los demás no. Una alerta interrumpe a
un lector de pantalla a mitad de frase, lo cual es correcto para «esto borra tus
datos» y erróneo para un consejo.
