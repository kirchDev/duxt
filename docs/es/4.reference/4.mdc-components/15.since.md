En línea. Marca la versión en la que llegó algo — usable dentro de un
encabezado.

## Uso

### Reintentos :since{version="v2.0.0"}

```mdc
### Reintentos :since{version="v2.0.0"}
```

## API

### Props

| Prop      | Tipo     | Por defecto | Notas                  |
| :-------- | :------- | :---------- | :--------------------- |
| `version` | `string` | —           | Se imprime tal cual    |

## Notas

Cuelga del modelo de versiones en vez de repetirlo: lo que dice el badge es la
versión en la que algo LLEGÓ, que es un hecho sobre la API y no sobre la página
en la que se documenta — así que sigue siendo correcto en cada versión de la
documentación que lleve la frase.

Para cualquier otra cosa, `:badge[…]` llama directamente al Badge del propio
tema; MDC resuelve por su nombre cualquier componente registrado globalmente.
