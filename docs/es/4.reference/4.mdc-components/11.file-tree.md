Un listado de directorio como árbol, con el icono de cada tipo de archivo leído
de su extensión.

## Uso

::preview
:::file-tree{title="tu-proyecto/"}
---
tree:
  - name: docs/
    children:
      - name: index.md
      - name: 1.getting-started/
        children:
          - name: index.md
          - name: 1.installation.md
  - name: app/
    children:
      - name: app.config.ts
  - name: nuxt.config.ts
---
:::

## API

### Props

| Prop    | Tipo      | Por defecto | Notas                                    |
| :------ | :-------- | :---------- | :--------------------------------------- |
| `tree`  | `Entry[]` | —           | Se da como YAML en el cuerpo del bloque  |
| `title` | `string`  | —           | La etiqueta raíz encima del árbol        |

Una entrada es `{ name, children? }`. Un nombre que termina en `/`, o que lleva
hijos, es un directorio.

## Notas

Construido sobre el árbol de reka-ui, así que tiene foco itinerante, navegación
con las flechas y los roles ARIA. Los nodos se indexan por ruta y no por nombre:
los nombres se repiten entre ramas, las rutas no.
