Tres componentes, un mismo comportamiento: `ProseH2`, `ProseH3` y `ProseH4`
renderizan los encabezados con los que se construye el índice de una página.

## Qué añaden

Un ancla de enlace permanente junto al encabezado, visible al pasar el ratón y
alcanzable con el teclado. El `id` es el slug del propio Content, así que el
ancla, el índice y la navegación dentro de la página coinciden.

## API

### Props

| Prop | Tipo     | Notas                                     |
| :--- | :------- | :---------------------------------------- |
| `id` | `string` | El slug que Content generó para el texto  |

### Slots

| Slot      | Qué va dentro           |
| :-------- | :---------------------- |
| `default` | El texto del encabezado |

## Notas

`ProseH1` no se sobrescribe, y es deliberado: el título de la página lo renderiza
la página, no el Markdown, así que un encabezado `#` de Markdown dentro del
cuerpo sería un segundo `h1` en la página.
