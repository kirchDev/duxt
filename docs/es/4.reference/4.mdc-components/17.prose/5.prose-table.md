Toda tabla de Markdown.

## Qué añade

Un contenedor de desplazamiento alrededor de la tabla, de modo que una tabla
ancha se desplaza dentro de su propia caja en vez de hacer que la página entera
se desplace de lado.

## API

### Slots

| Slot      | Qué va dentro |
| :-------- | :------------ |
| `default` | La tabla      |
