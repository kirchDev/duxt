Toda imagen de una página Markdown.

## Qué añade

**Dos variantes.** Una captura de un editor oscuro sobre una página blanca — o
al revés — es lo más feo que se ve habitualmente en una documentación, y el CSS
no puede arreglarlo porque lo que está mal son los píxeles, no el marco. Una
página puede nombrar un segundo archivo:

```md
![La barra lateral](/shots/sidebar.png){dark="/shots/sidebar-dark.png"}
```

**Clic para ampliar**, salvo que la imagen pida lo contrario:

```md
![Un diagrama](/diagram.svg){zoom="false"}
```

## API

### Props

| Prop   | Tipo      | Por defecto | Notas                                          |
| :----- | :-------- | :---------- | :--------------------------------------------- |
| `src`  | `string`  | —           | Tal como se escribió                           |
| `alt`  | `string`  | —           | Tal como se escribió                           |
| `dark` | `string`  | —           | Un segundo archivo, servido con el tema oscuro |
| `zoom` | `boolean` | `true`      | `false` deja la imagen inerte                  |

## Notas

La variante oscura se nombra explícitamente en lugar de adivinarse por
convención. Derivar `-dark` de un nombre de archivo hace que un archivo que falta
se convierta en una imagen rota, y quien la escribió no se entera nunca.
