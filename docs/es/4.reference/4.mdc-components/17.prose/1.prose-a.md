Todo enlace de una página Markdown pasa por este componente.

## Qué añade

Una ruta de documentación se reescribe para que lleve el prefijo de la fuente de
la que vino la página, más el locale del lector. Una URL externa se deja
intacta y recibe la pestaña nueva y la flecha.

## Por qué

Markdown no tiene ni idea de que se está sirviendo bajo un prefijo.
`/getting-started`, escrito en el `docs/` de este repositorio, es correcto en un
sitio con una fuente y un 404 en un sitio con dos, donde la misma página vive en
`/duxt/getting-started` — y quien escribió el Markdown, que puede ser otro
repositorio entero, no puede saber cuál de los dos.

Peor aún: el mismo archivo se sirve en varios prefijos a la vez cuando se
publica en más de una versión. Un enlace no se puede reescribir en tiempo de
compilación, porque no hay una única respuesta correcta. Se resuelve en cada
render, contra la fuente desde la que se está leyendo la página — así, un enlace
dentro de `v0.7.0` mantiene al lector en `v0.7.0`.

## API

### Props

| Prop     | Tipo      | Notas                                    |
| :------- | :-------- | :--------------------------------------- |
| `href`   | `string`  | Tal como se escribió en el Markdown      |
| `target` | `string`  | Se establece para un enlace externo      |
