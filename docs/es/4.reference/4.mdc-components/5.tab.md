Un panel dentro de [`::tab-group`](/reference/mdc-components/tab-group). Por sí
solo no significa nada.

## Uso

```mdc
:::tab-group
  ::tab{label="pnpm"}
  La capa es una dependencia de desarrollo.
  ::
:::
```

## API

### Props

| Prop    | Tipo     | Por defecto | Notas                              |
| :------ | :------- | :---------- | :--------------------------------- |
| `label` | `string` | —           | El texto del trigger de la pestaña |

### Slots

| Slot      | Qué va dentro           |
| :-------- | :---------------------- |
| `default` | El panel, como Markdown |

## Notas

El componente registra su propia etiqueta en el padre durante el setup, y eso es
lo que permite construir la lista de triggers a partir de hijos que MDC todavía
no ha renderizado.
