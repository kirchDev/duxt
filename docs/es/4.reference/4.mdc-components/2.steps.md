Envuelve una **lista ordenada** en una disposición por pasos. Numera la lista
que envuelva, así que el Markdown sigue siendo una lista corriente.

## Uso

::preview
:::steps
1. Añade la dependencia.
2. Extiende la capa.
3. Escribe Markdown.
:::

## API

Sin props. El bloque da estilo a su `<ol>` hijo.

### Slots

| Slot      | Qué va dentro                          |
| :-------- | :------------------------------------- |
| `default` | Una lista ordenada, elementos Markdown |

## Notas

Merece la pena recurrir a él en cuanto un paso lleva un bloque de código: en una
lista ordenada corriente el bloque aleja el texto de su propio número, y esta
disposición mantiene el número fijado a su lado.

Los marcadores son un contador CSS sobre los elementos de la lista, no contenido
— un lector que copie los pasos se lleva el texto sin la numeración dibujada dos
veces.
