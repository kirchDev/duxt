---
title: Grupo de campos
description: Una lista de campos como un único bloque.
icon: lucide:list-tree
---

Agrupa bloques [`::field`](/reference/mdc-components/field) para que se lean como
una sola lista con separadores en vez de como tarjetas sueltas.

## Uso

::preview
::::field-group
:::field{name="path" type="string" required}
Carpeta con el Markdown, relativa a la raíz del repositorio.
:::

:::field{name="history" type="boolean" default="false"}
Lee el historial git de esta fuente para «Última actualización» y las personas
que han contribuido.
:::
::::

#code
```mdc
:::field-group
  ::field{name="path" type="string" required}
  Carpeta con el Markdown, relativa a la raíz del repositorio.
  ::
:::
```
::

## API

Sin props.

### Slots

| Slot      | Qué va dentro     |
| :-------- | :---------------- |
| `default` | Bloques `::field` |
