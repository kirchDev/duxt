Una entrada de `navigation` o `sections` se convierte en menú cuando tiene
`children`. Todo lo demás es configuración sobre los mismos objetos de enlace:
cuánta profundidad tiene el menú, si es una lista o un panel y cómo se dibuja
cada entrada. La [demo](/demo) tiene un ejemplo de cada uno en su fila de secciones.

## Pasos

::steps

1. **Anida los enlaces.** Una entrada con `children` abre un desplegable, y un
   hijo con `children` abre otro menú a su lado, con tanta profundidad como tengan
   los datos:

   ```ts [app/app.config.ts]
   export default defineAppConfig({
     duxt: {
       navigation: [
         {
           label: 'Platform',
           icon: 'lucide:layers',
           children: [
             { label: 'Overview', to: '/platform' },
             {
               label: 'API',
               children: [
                 { label: 'REST', to: '/api/rest' },
                 { label: 'Webhooks', to: '/api/webhooks' }
               ]
             }
           ]
         }
       ]
     }
   });
   ```

2. **Conviértelo en un panel.** `menu: 'mega'` coloca los hijos en una
   cuadrícula de `columns`. Un hijo con hijos propios es una columna bajo su
   nombre; un hijo sin ellos es una celda propia:

   ```ts
   {
     label: 'Platform',
     menu: 'mega',
     columns: 3,
     divided: true,
     children: [
       {
         label: 'Highlights',
         hideLabel: true,
         children: [
           {
             label: 'Editor',
             to: '/editor',
             image: '/editor.svg',
             display: 'feature',
             description: 'Write and preview'
           }
         ]
       },
       {
         label: 'API',
         children: [
           { label: 'REST', to: '/api/rest' },
           { label: 'Webhooks', to: '/api/webhooks', badge: 'New' },
           { label: 'All of the API', to: '/api', display: 'more' }
         ]
       },
       { label: 'New here?', to: '/start', display: 'callout' }
     ]
   }
   ```

3. **Elige la disposición.** Las mismas opciones producen paneles muy distintos:

   | Quieres | Configura |
   | :-- | :-- |
   | Columnas de enlaces junto a una lista destacada | Una primera columna con `hideLabel` y entradas `display: 'feature'`, y `divided` en la segunda |
   | Una cuadrícula de productos | `columns: 3`, entradas con `icon`, `description` y `display: 'feature'`, y un `display: 'callout'` final |
   | Un panel ancho con introducción | `width: 'full'`, `columns: 6`, `divided` y una primera columna con `span: 2`, `image` y `description` |
   | Una imagen sobre cada columna | `width: 'full'` e `image` en cada columna |

4. **Añade tu propia celda si las formas no bastan.** `component` nombra un
   componente registrado globalmente, que sustituye el contenido de la entrada,
   ocupa su celda y recibe la entrada como `link`. Llama al archivo `.global.vue`,
   porque `app.config` solo puede referirse a él por su nombre. Un componente opaco
   oculta el resaltado que el menú pinta detrás de una entrada, así que dibuja el
   tuyo:

   ```vue [app/components/MenuPromo.global.vue]
   <script setup lang="ts">
   defineProps<{ link: DuxtLink }>();
   </script>

   <template>
     <span
       class="flex h-full p-3 in-data-highlighted:ring-2"
     >
       {{ link.label }}
     </span>
   </template>
   ```

5. **Usa la segunda fila igual.** `sections` tiene la misma forma. Una sección
   con menú pertenece al área de su primer enlace, y cuando dos entradas reclaman
   una página la primera sigue activa, así que las entradas simples van antes que
   los menús que repiten sus enlaces.

6. **Compruébalo en un teléfono.** Por debajo del punto de ruptura `lg`, el
   panel lateral muestra el primer nivel y cada menú entra deslizándose como un
   nivel propio bajo un botón de volver. Las columnas de un megamenú se quedan en
   un nivel, bajo sus nombres.

::

## Por qué funciona así

Un megamenú se centra en la página y no en su entrada. Un panel tan ancho no
tiene una posición sensata respecto a una entrada de la fila: colgado de ella,
el mismo menú aparecía en otro sitio para cada entrada y cada ancho de ventana.

El panel lateral cambia de nivel en lugar de sangrar, porque cada nivel anidado
quita ancho al anterior y un teléfono no tiene de sobra. Un nivel cada vez
también mantiene cada enlace a todo el ancho, sea cual sea la profundidad.

Todas las opciones están en la [referencia de
configuración](/reference/configuration), y los componentes son
[DuxtNavigationMenu](/reference/components/navigation/duxt-navigation-menu) y
[DuxtSheetDrill](/reference/components/navigation/duxt-sheet-drill).

## Lista de comprobación

- [ ] Cada entrada que abre un menú tiene `children`, y un `to` solo si su propia página debe encabezar ese menú
- [ ] Las `columns` de un megamenú cuadran con los valores `span` de las celdas
- [ ] Las entradas simples de `sections` van antes que los menús que repiten sus enlaces
- [ ] El menú se ha abierto con ancho de teléfono hasta su nivel más profundo
