Reglas que este proyecto se impone, escritas porque el código no puede
enunciarlas. Vinculan el trabajo dentro de este repositorio; nada de lo que hay
aquí restringe un sitio que extienda la capa.

Una regla dice qué se hace; una [decisión de arquitectura](/adr) dice por qué se
eligió frente a las alternativas, y sigue siendo legible cuando el razonamiento ya
no está en la cabeza de nadie. El registro de decisiones es de solo adición — por
eso queda al lado de estas páginas y no entre ellas: estas se editan cuando
cambian.
