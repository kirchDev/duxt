The [duxt starter](https://github.com/kirchDev/duxt-starter) is a small
documentation site with a landing page and a Getting started section. Nuxi
copies it, installs its dependencies, and creates its Git repository:

```bash
npx nuxi@latest init my-docs -t github:kirchDev/duxt-starter --gitInit --packageManager pnpm
cd my-docs
pnpm dev
```

Open the address Nuxt prints, then edit files in `docs/`. The navigation and
the landing-page preview update with your pages. For a project that already
exists, use [Installation](/getting-started/installation) instead.
